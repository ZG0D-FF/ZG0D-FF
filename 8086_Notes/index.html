1. INTRODUCTION TO MICROPROCESSORS & COMPUTERS

Overview of a Simple Microcomputer

A simple digital microcomputer consists of three primary functional components connected via three parallel sets of conductors called Buses:

Figure 1.1: Functional Block Diagram of a Simple Microcomputer (CPU, Memory, I/O Ports & System Buses)
  1. CPU (Central Processing Unit):
    Controls all system activity. Fetches binary-coded instructions from memory, decodes them, and carries out operations. Houses an Arithmetic Logic Unit (ALU) (ADD, SUB, AND, OR, XOR, Inversion), an address program counter, internal general-purpose temporary registers, and control bus timing circuitry.
  2. Memory:
    Mix of semiconductor RAM (read/write runtime memory) and ROM (permanent boot firmware). Dual purposes: (a) stores sequential instruction opcode streams, and (b) stores binary data operands.
  3. Input/Output (I/O) Section:
    Interfaces the computer with external peripherals (keyboards, displays, sensors). The physical IC buffers interfacing internal buses to peripherals are called I/O Ports.

The Three System Buses

  • Address Bus (Unidirectional):
    Lines along which the CPU transmits physical memory or I/O port addresses. With N address lines, the CPU addresses 2N distinct locations (e.g., 8086 with 20 address lines = 220 = 1,048,576 bytes = 1 MB).
  • Data Bus (Bidirectional):
    Transfers data operands between CPU and memory/ports. CPU both reads and writes over this bus. Multiple devices share it, but only one is enabled at a time.
  • Control Bus:
    Carries timing and control strobes (e.g., MEMR, MEMW, IOR, IOW) dispatched by the CPU to synchronize memory and I/O access.

Microprocessor vs Microcontroller

  • Microprocessor (MPU): Multipurpose, clock-driven, register-based LSI/VLSI silicon chip executing instructions fetched from external memory.
  • Microcontroller (MCU): Highly integrated single-chip microcomputer containing CPU core, on-chip RAM/ROM, timers, and programmable I/O ports.

2. 8086 ARCHITECTURE & PIPELINING

Salient Features of 8086

  • 16-bit CPU: 16-bit ALU, registers, and internal datapaths.
  • 16-bit Data Bus: Can transfer 8-bit bytes or 16-bit words in a single memory cycle.
  • 20-bit Address Bus: Directly addresses 220 = 1 Megabyte (1 MB) of physical memory (00000H to FFFFFH).
  • I/O Port Capability: Directly addresses up to 64K (65,536) 8-bit I/O ports.
  • Register Set: 14 distinct 16-bit internal registers.
  • Multiplexed Buses: Time-multiplexed address/data (AD0–AD15) and address/status (A16/S3 – A19/S6).
  • Clock Timing: Operates on an external clock with a 33% duty cycle.
  • Instruction Prefetch Queue: Built-in 6-byte FIFO queue implementing instruction pipelining.
  • Dual Operating Modes: Configurable via pin 33 (MN/MX) into Minimum Mode (single-CPU) or Maximum Mode (multiprocessor with 8288).
Figure 2.1: Internal Block Architecture of 8086 showing BIU (Adder, Segment Registers, 6-Byte Queue) and EU (ALU, GPRs, Flags)

Two Independent Functional Units: EU and BIU

1. The Execution Unit (EU)

  • Decoding & Execution: Extracts instruction bytes from the top of the FIFO queue, decodes them, and executes operations.
  • 16-bit ALU: Arithmetic (ADD, SUB, INC, DEC) and logical operations (AND, OR, XOR, NOT, shifts, rotations).
  • Flag Register: Contains status and machine control flip-flops reflecting ALU results.
  • Registers: AX, BX, CX, DX, SP, BP, SI, and DI.
  • Independent Timing: Operates with respect to internal clock periods (T-states), independent of external bus cycle latency.

2. The Bus Interface Unit (BIU)

  • Bus Transfers: Handles all physical transfers of data and addresses across external buses.
  • 20-bit Physical Address Adder (Σ): Combines 16-bit segment base addresses and 16-bit offset addresses into real 20-bit physical addresses.
  • Segment Registers & IP: Contains CS, DS, SS, ES, and the Instruction Pointer (IP).
  • Instruction Stream Queue: 6-byte FIFO storage holding pre-fetched instruction bytes.
  • Bus Control Logic: Generates bus read/write and memory/IO strobes.

Pipelining & The 6-Byte Instruction Queue

  • Pipelining Definition: Fetching the next sequential instruction while the current instruction is being executed.
  • Asynchronous Fetch Trigger: The BIU fills the queue as long as it has room, initiating a fetch whenever at least two bytes in the queue become vacant.
  • Branch Flushing: Branch instructions (JMP, CALL, RET) cause the queue to be flushed and reloaded starting from the target branch address.
  • Why 6 Bytes? The longest valid instruction in the 8086 set is 6 bytes long. A 6-byte queue guarantees that at least one full instruction can always be prefetched.

3. REGISTER ORGANIZATION OF 8086

Figure 3.1: 8086 Register Organization (General Data, Segment Registers, Flags/PSW, Pointers & Index Registers)

The 8086 contains 14 internal registers, each 16 bits wide, classified into four functional groups:

1. General Data Registers (AX, BX, CX, DX)

  • AX (Accumulator): Split into AH and AL. Favored for arithmetic, logic, multiply, divide, and standard port I/O.
  • BX (Base Register): Split into BH and BL. Holds base offset addresses for data segment memory lookups (e.g., MOV AX, [BX]).
  • CX (Count Register): Split into CH and CL. Default counter for LOOP instructions and multi-bit shifts/rotations via CL.
  • DX (Data Register): Split into DH and DL. Holds upper 16 bits in 32-bit MUL/DIV operations, and stores 16-bit I/O port numbers (IN AL, DX).

2. Segment Registers (CS, DS, SS, ES)

  • CS (Code Segment): Base address of the 64 KB segment containing executable program code.
  • DS (Data Segment): Base address of the 64 KB memory segment containing program variables.
  • SS (Stack Segment): Base address of the 64 KB segment reserved for the LIFO call/return stack.
  • ES (Extra Segment): Auxiliary data segment; default destination base for string instructions.

3. Pointers and Index Registers

  • IP (Instruction Pointer): 16-bit offset of the next instruction byte in Code Segment (CS).
  • SP (Stack Pointer): 16-bit offset into the Stack Segment (SS), pointing to the top of the stack.
  • BP (Base Pointer): 16-bit offset into Stack Segment (SS), used to access stack parameters.
  • SI (Source Index): 16-bit offset into Data Segment (DS), pointing to source operands in string instructions.
  • DI (Destination Index): 16-bit offset into Extra Segment (ES), pointing to destination operands in string instructions.

5. MEMORY SEGMENTATION & OVERLAPPING

Segmented Memory Organization & Formula

The 1 MB physical space is partitioned into logical segments of up to 64 KB starting on 16-byte boundaries (addresses ending in 0H).

Physical Address = (Segment Base Address × 10H) + Offset Address
Figure 5.1: (a) Non-overlapping Segments with Separate 64 KB Boundaries; (b) Overlapping Segments sharing common physical addresses

Overlapping Segments Principle

In overlapping segments, the physical address is identical across different segment:offset representations:

Physical Address = (CS1 × 10H) + IP1 = (CS2 × 10H) + IP2

10. MINIMUM MODE SYSTEM & TIMING DIAGRAMS

Minimum Mode System Architecture (MN/MX = +5V)

In minimum mode, the 8086 functions as a uniprocessor. It generates all system bus control signals directly without requiring an external bus controller.

Figure 10.1: Minimum Mode 8086 System Organization (8284 Clock Generator, 74373 Latches, 74245 Transceivers, RAM, ROM, and I/O)
  • 8284 Clock Generator: Generates the master CLK with a 33% duty cycle, synchronizes external RESET and READY inputs.
  • 74LS373 / 8282 Address Latches (3 units): D-type flip-flop latches that demultiplex the 20-bit address from AD0–AD15 and A16–A19 during the negative edge of ALE.
  • 74LS245 / 8286 Bidirectional Transceivers (2 units): Data bus amplifiers controlled by DEN (Data Enable) and DT/R (direction control: 1=Transmit, 0=Receive).

Data Transfer Control Signals

M/IO RD WR Transfer Operation
0 0 1 I/O Read (Input from port to CPU)
0 1 0 I/O Write (Output from CPU to port)
1 0 1 Memory Read (Fetch opcode or operand from memory)
1 1 0 Memory Write (Store operand into memory)

Timing Diagrams for Minimum Mode Bus Cycles

A basic bus cycle consists of four clock states (T1, T2, T3, T4). If an addressed memory or peripheral is slow, wait states (Tw) are inserted between T3 and T4.

1. Read Cycle Timing Diagram (Minimum Mode)

Figure 10.2: Minimum Mode Read Bus Cycle Timing (T1 to T4, showing ALE, M/IO, RD, DEN, and DT/R)
T1 State
CPU asserts ALE high; emits 20-bit address on AD0–AD15 and A16–A19; asserts M/IO and BHE. DT/R is driven LOW.
T2 State
Address is removed; bus is tristated; RD goes LOW; DEN goes LOW enabling transceiver output buffers.
T3 / Tw State
Addressed device places valid data on the bus; CPU samples READY line. If READY is LOW, wait states (Tw) are inserted.
T4 State
CPU latches data into registers; RD and DEN return HIGH; bus is floating for the next cycle.

2. Write Cycle Timing Diagram (Minimum Mode)

Figure 10.3: Minimum Mode Write Bus Cycle Timing (T1 to T4 with Tw wait state, showing WR, DEN, and DT/R)
T1 State
CPU emits address; asserts ALE; drives DT/R HIGH (Transmit mode); sets M/IO.
T2 State
Address removed; CPU places output data on AD0–AD15; asserts WR LOW at the beginning of T2; asserts DEN LOW.
T3 / Tw State
Data remains stable on the bus; CPU samples READY. If peripheral is slow, wait state Tw is inserted.
T4 State
WR goes HIGH in middle of T4; data remains valid until middle of T4; DEN deactivated HIGH.

11. MAXIMUM MODE SYSTEM & 8288 BUS CONTROLLER

Maximum Mode Configuration (MN/MX = GND)

In maximum mode, the 8086 is designed for multiprocessor configurations (e.g., 8086 paired with the 8087 Math Coprocessor or 8089 I/O Processor). The CPU pins 24–31 output status lines S2, S1, S0 and queue status bits, while an external 8288 Bus Controller decodes the status lines to generate bus control strobes.

12. INTEL 80286 & ARM PROCESSORS

Intel 80286 Microprocessor

  • Introduction: Introduced Feb 1, 1982. First 8086-family CPU with separate, non-multiplexed address and data buses.
  • Memory & Architecture: Contains an on-chip Memory Management Unit (MMU). Features 24-bit address bus addressing 16 MB physical memory, and up to 1 GB virtual memory per task.
  • Two Operating Modes:
    • Real Address Mode: 100% binary backward compatible with 8086/8088.
    • Protected Virtual Address Mode (PVAM): Hardware multitasking support with 4-level privilege protection rings.

ARM Microcontroller & 3-Stage Pipeline

  • Origins: Advanced RISC Machine, developed 1978 (Cambridge), produced 1985 (Acorn). 32-bit RISC core.
  • 3-Stage Pipeline: Fetch → Decode → Execute delivering 1 instruction per clock cycle throughput once primed.
  • Core Datapath: 32-bit ALU with integrated Barrel Shifter (shifts operands in 1 clock cycle) and high-speed Booth Multiplier.
  • Nomenclature: ARM[x][T][D][M][I][E][J][F][S] (T=Thumb 16-bit, D=Debug, M=Fast Multiplier, I=EmbeddedICE, E=Enhanced DSP, J=Jazelle Java, F=Floating Point, S=Synthesizable).
