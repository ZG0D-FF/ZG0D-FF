Section 12.1 Introduction

Why Waveguides? Fundamental Physics vs. Two-Conductor Lines

At lower RF frequencies (below $3\text{ GHz}$), two-conductor lines (coaxial, two-wire, microstrip) are convenient because they operate from DC ($f=0$) upwards and support the Transverse Electromagnetic ($\text{TEM}$) mode. However, at microwave frequencies ($3 - 300\text{ GHz}$), two-conductor transmission lines fail due to severe physical limitations:

Physical Metric Two-Conductor Transmission Line Hollow Rectangular Waveguide
Mode of Propagation Supports only $\text{TEM}$ mode ($E_z = 0, H_z = 0$). Supports $\text{TE}_{mn}$ and $\text{TM}_{mn}$ modes. Cannot support $\text{TEM}$ mode!
Frequency Spectrum Operates from DC ($f = 0\text{ Hz}$) to high RF. Operates strictly above cutoff $f > f_c$. Acts as a High-Pass Filter.
Ohmic Loss ($R_s$) Prohibitive skin effect losses in narrow center conductor. Very low attenuation $\alpha_c$ because large interior surface area conducts currents.
Dielectric Loss Solid dielectric spacer causes continuous power loss. Usually hollow (dry air or vacuum), resulting in zero dielectric loss ($\alpha_d \approx 0$).
Power Capacity Limited by dielectric breakdown across narrow gap. Extremely high power handling (megawatts in radar pulses).
⚠️ Universal Law: Hollow Waveguides Cannot Support TEM Waves
If a wave were $\text{TEM}$ ($E_z = 0 = H_z$), Maxwell's equations require that $\vec{E} = -\nabla_t \Phi$, where the transverse potential satisfies Laplace's equation $\nabla_t^2 \Phi = 0$. Since the entire single conducting wall of a hollow pipe forms an equipotential surface, $\Phi = \text{constant}$ everywhere inside, forcing $\vec{E} \equiv 0$ and $\vec{H} \equiv 0$. Thus, a hollow closed single conductor cannot support a $\text{TEM}$ wave!
Section 12.2 Helmholtz Solutions

Maxwell Helmholtz PDEs & Separation of Variables

Inside a lossless dielectric medium ($\sigma = 0, \mu, \varepsilon$), time-harmonic Maxwell equations reduce to the vector Helmholtz wave equations $\nabla^2 \vec{E}_s + k^2 \vec{E}_s = 0$ and $\nabla^2 \vec{H}_s + k^2 \vec{H}_s = 0$, where $k = \omega\sqrt{\mu\varepsilon}$.

Step 1: Scalar PDE for Longitudinal Component $E_{zs}(x, y, z)$: $$\frac{\partial^2 E_{zs}}{\partial x^2} + \frac{\partial^2 E_{zs}}{\partial y^2} + \frac{\partial^2 E_{zs}}{\partial z^2} + k^2 E_{zs} = 0$$ $$\text{Product Separation: } E_{zs}(x, y, z) = X(x) Y(y) Z(z)$$ $$\frac{X''}{X} + \frac{Y''}{Y} + \frac{Z''}{Z} = -k^2 \implies -k_x^2 - k_y^2 + \gamma^2 = -k^2$$ $$\bbox[5px, border:2px solid #0071e3]{h^2 = \gamma^2 + k^2 = k_x^2 + k_y^2}$$
Step 2: Expressing Transverse Fields $(E_x, E_y, H_x, H_y)$ from $(E_z, H_z)$: $$\text{From } \nabla \times \vec{E}_s = -j\omega\mu \vec{H}_s \quad \text{and} \quad \nabla \times \vec{H}_s = j\omega\varepsilon \vec{E}_s \quad \text{with } \frac{\partial}{\partial z} \to -\gamma:$$ $$E_{xs} = -\frac{\gamma}{h^2}\frac{\partial E_{zs}}{\partial x} - \frac{j\omega\mu}{h^2}\frac{\partial H_{zs}}{\partial y}$$ $$E_{ys} = -\frac{\gamma}{h^2}\frac{\partial E_{zs}}{\partial y} + \frac{j\omega\mu}{h^2}\frac{\partial H_{zs}}{\partial x}$$ $$H_{xs} = \frac{j\omega\varepsilon}{h^2}\frac{\partial E_{zs}}{\partial y} - \frac{\gamma}{h^2}\frac{\partial H_{zs}}{\partial x}$$ $$H_{ys} = -\frac{j\omega\varepsilon}{h^2}\frac{\partial E_{zs}}{\partial x} - \frac{\gamma}{h^2}\frac{\partial H_{zs}}{\partial y}$$
Section 12.3 TM Modes

Transverse Magnetic ($\text{TM}_{mn}$) Modes: Boundary Solutions

For $\text{TM}$ modes, $H_z = 0$ while $E_z \ne 0$. At the perfectly conducting waveguide walls, the tangential electric field must vanish identically:

Dirichlet Boundary Conditions: $$E_{zs} = 0 \quad \text{at } x = 0, \quad x = a, \quad y = 0, \quad y = b$$ $$\text{General Product Solution: } E_{zs} = (c_1\cos k_x x + c_2\sin k_x x)(c_3\cos k_y y + c_4\sin k_y y)e^{-\gamma z}$$ $$\text{At } x = 0 \implies c_1 = 0; \qquad \text{At } y = 0 \implies c_3 = 0$$ $$\text{At } x = a \implies \sin(k_x a) = 0 \implies k_x = \frac{m\pi}{a}, \quad m = 1, 2, 3, \dots$$ $$\text{At } y = b \implies \sin(k_y b) = 0 \implies k_y = \frac{n\pi}{b}, \quad n = 1, 2, 3, \dots$$ $$\bbox[5px, border:2px solid #0071e3]{E_{zs} = E_0 \sin\left(\frac{m\pi x}{a}\right)\sin\left(\frac{n\pi y}{b}\right)e^{-\gamma z}}$$
💡 Lucid Understanding: Why Neither $m$ nor $n$ Can Be Zero for TM Modes

If $m = 0$, $\sin(0) = 0 \implies E_{zs} \equiv 0$. By the transverse gradient formulas, $E_{xs} = 0, E_{ys} = 0, H_{xs} = 0, H_{ys} = 0$. Every field component vanishes! The same occurs if $n = 0$. Therefore, $\text{TM}_{01}$ and $\text{TM}_{10}$ cannot exist. The lowest-order TM mode is $\text{TM}_{11}$.

Section 12.4 TE Modes

Transverse Electric ($\text{TE}_{mn}$) Modes: Dominant $\text{TE}_{10}$ Physics

For $\text{TE}$ modes, $E_z = 0$ while $H_z \ne 0$. The tangential $\vec{E}$-field boundary conditions ($E_x = 0$ at $y=0,b$ and $E_y = 0$ at $x=0,a$) transform via Maxwell's relations into Neumann boundary conditions on $H_z$:

Neumann Boundary Conditions: $$\frac{\partial H_{zs}}{\partial x} = 0 \quad \text{at } x = 0, a; \qquad \frac{\partial H_{zs}}{\partial y} = 0 \quad \text{at } y = 0, b$$ $$\bbox[5px, border:2px solid #0071e3]{H_{zs} = H_0 \cos\left(\frac{m\pi x}{a}\right)\cos\left(\frac{n\pi y}{b}\right)e^{-\gamma z}}$$ $$k_x = \frac{m\pi}{a}, \quad k_y = \frac{n\pi}{b}, \qquad m, n = 0, 1, 2, \dots \quad (m, n \ne 0, 0)$$
Dominant Mode $\text{TE}_{10}$ Field Equations ($m=1, n=0$ with $a > b$): $$H_{zs} = H_0 \cos\left(\frac{\pi x}{a}\right)e^{-j\beta z}$$ $$E_{ys} = -j\frac{\omega\mu a}{\pi}H_0 \sin\left(\frac{\pi x}{a}\right)e^{-j\beta z} = -j E_0 \sin\left(\frac{\pi x}{a}\right)e^{-j\beta z}$$ $$H_{xs} = j\frac{\beta a}{\pi}H_0 \sin\left(\frac{\pi x}{a}\right)e^{-j\beta z} = -\frac{E_{ys}}{\eta_{TE}}$$ $$E_{xs} = 0, \quad E_{zs} = 0, \quad H_{ys} = 0$$ $$\bbox[5px, border:2px solid #0071e3]{f_{c, 10} = \frac{u'}{2a}, \qquad \lambda_{c, 10} = 2a}$$
Section 12.5 Velocities

Waveguide Dispersion, Superluminal Phase Velocity ($v_p$) & Group Velocity ($v_g$)

Inside a waveguide, a guided mode is geometrically composed of uniform plane waves reflecting back and forth between the metallic sidewalls along a zigzag path at an incidence angle $\theta = \tan^{-1}\left(\frac{\pi}{\beta a}\right)$:

The Velocity Hierarchy & Einstein Relativity Invariance: $$u' = \frac{1}{\sqrt{\mu\varepsilon}} = \frac{c}{\sqrt{\mu_r \varepsilon_r}} \quad (\text{Intrinsic Velocity in Unbounded Dielectric})$$ $$u_p = \frac{\omega}{\beta} = \frac{u'}{\cos\theta} = \frac{u'}{\sqrt{1 - (f_c/f)^2}} \ge u' \quad (\text{Phase Velocity: Always }> c \text{ in air!})$$ $$u_g = \frac{d\omega}{d\beta} = u'\cos\theta = u'\sqrt{1 - \left(\frac{f_c}{f}\right)^2} \le u' \quad (\text{Group/Energy Velocity: Always }< c!)$$ $$\bbox[5px, border:2px solid #0071e3]{u_p \cdot u_g = {u'}^2 = \frac{c^2}{\mu_r \varepsilon_r}}$$
💡 Lucid Understanding: Why $u_p > c$ Does NOT Violate Special Relativity

The phase velocity $u_p$ measures the speed at which points of constant mathematical phase (zero-crossings) travel along the guide axis. Like the point of intersection of two closing scissor blades, a geometric phase intersection can sweep faster than light. However, no physical information, energy, or mass travels at $u_p$. Signal information and energy propagate strictly at the group velocity $u_g$, which is always less than $c$.

Section 12.6 Power & Losses

Power Transmission & Wall Attenuation Constants

1. Time-Average Power Transmitted Across Cross-Section: $$P_{\text{ave}} = \int_0^a \int_0^b \frac{|E_{ys}|^2}{2\eta_{TE}} dy\,dx = \frac{E_0^2 ab}{4\eta_{TE}} = \frac{\omega^2 \mu^2 a^3 b H_0^2}{4\pi^2 \eta_{TE}} \quad (\text{for }\text{TE}_{10})$$ $$\eta_{TE} = \frac{\eta'}{\sqrt{1 - (f_c/f)^2}}, \qquad \eta_{TM} = \eta'\sqrt{1 - \left(\frac{f_c}{f}\right)^2}, \qquad \eta_{TE}\eta_{TM} = {\eta'}^2$$
2. Conductor Wall Ohmic Attenuation $\alpha_c$ for $\text{TE}_{10}$: $$\alpha_c = \frac{P_L}{2P_{\text{ave}}} = \frac{2 R_s}{b \eta'\sqrt{1 - (f_c/f)^2}}\left[0.5 + \frac{b}{a}\left(\frac{f_c}{f}\right)^2\right] \text{ Np/m}$$ $$R_s = \sqrt{\frac{\pi f \mu}{\sigma_c}} = \frac{1}{\sigma_c \delta} \quad (\text{Wall Surface Resistivity in }\Omega)$$ $$\text{Dielectric Loss: } \quad \alpha_d = \frac{\sigma \eta'}{2\sqrt{1 - (f_c/f)^2}} \text{ Np/m}$$
Section 12.8 Resonators

Rectangular Cavity Resonators & Quality Factor ($Q$)

A rectangular resonant cavity is formed by capping both ends of a rectangular waveguide at $z = 0$ and $z = c$. The wave reflects back and forth, establishing a 3-dimensional standing wave:

Resonant Frequency & Modes: $$f_{r, mnp} = \frac{u'}{2}\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2 + \left(\frac{p}{c}\right)^2}$$ $$\text{For TM modes to } z: \quad m \ge 1, \quad n \ge 1, \quad p \ge 0 \implies \text{Lowest is } \text{TM}_{110}$$ $$\text{For TE modes to } z: \quad m \ge 0, \quad n \ge 0, \quad p \ge 1 \quad (m \text{ or } n \ne 0) \implies \text{If } a > b < c, \text{ Dominant Mode is } \mathbf{\text{TE}_{101}}$$
Quality Factor ($Q$) for Dominant $\text{TE}_{101}$ Mode: $$Q = 2\pi \frac{\text{Time-Average Energy Stored}}{\text{Energy Loss per Cycle}} = \omega_r \frac{W}{P_L} = \frac{(a^2 + c^2)abc}{\delta \left[2b(a^3 + c^3) + ac(a^2 + c^2)\right]}$$ $$\text{For a Cubical Cavity } (a = b = c): \quad \mathbf{Q = \frac{a}{3\delta}}$$
Section 12.9 Optical Fiber

Optical Fibers: Numerical Aperture & Mode Volume

Refraction & Guiding Equations: $$\text{Critical Angle: } \sin\theta_c = \frac{n_2}{n_1} \quad (n_1 > n_2)$$ $$\text{Numerical Aperture (NA): } \quad \mathbf{\text{NA} = \sin\theta_a = \sqrt{n_1^2 - n_2^2}}$$ $$\text{Normalized Frequency (V-Number): } \quad V = \frac{\pi d}{\lambda}\sqrt{n_1^2 - n_2^2} = \frac{\pi d}{\lambda}\text{NA}$$ $$\text{Total Propagating Modes in Step-Index Fiber: } \quad \mathbf{N \approx \frac{V^2}{2}}$$ $$\text{Optical Attenuation: } \quad \alpha \ell = 10\log_{10}\left(\frac{P(0)}{P(\ell)}\right) \text{ dB}$$

Sadiku Example 12.1 ✓ Verified
A rectangular waveguide with $a = 2.5\text{ cm}, b = 1\text{ cm}$ operates below $15.1\text{ GHz}$, filled with dielectric $\sigma = 0, \varepsilon_r = 4, \mu_r = 1$. How many TE and TM modes propagate? Calculate their cutoff frequencies.
$$u' = \frac{c}{\sqrt{\mu_r \varepsilon_r}} = \frac{3\times 10^8}{2} = 1.5\times 10^8\text{ m/s}$$ $$f_{c, mn} = \frac{u'}{2}\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2} = \frac{1.5\times 10^8}{2}\sqrt{\frac{m^2}{(0.025)^2} + \frac{n^2}{(0.01)^2}} = 3\sqrt{m^2 + 6.25n^2}\text{ GHz}$$
  • $n=0$: $\text{TE}_{10} (3\text{ GHz}), \text{TE}_{20} (6\text{ GHz}), \text{TE}_{30} (9\text{ GHz}), \text{TE}_{40} (12\text{ GHz}), \text{TE}_{50} (15\text{ GHz})$ [5 modes]
  • $n=1$: $\text{TE}_{01} (7.5\text{ GHz}), \text{TE}_{11}/\text{TM}_{11} (8.078\text{ GHz}), \text{TE}_{21}/\text{TM}_{21} (9.6\text{ GHz}), \text{TE}_{31}/\text{TM}_{31} (11.72\text{ GHz}), \text{TE}_{41}/\text{TM}_{41} (14.14\text{ GHz})$ [9 modes]
  • $n=2$: $\text{TE}_{02} (15.0\text{ GHz})$ [1 mode]
Total transmitted modes: 11 TE modes + 4 TM modes = 15 modes.
Sadiku Example 12.4 ✓ Verified
An air-filled standard WR-340 waveguide ($a = 8.636\text{ cm}, b = 4.318\text{ cm}$) is fed by a $4\text{ GHz}$ carrier. Determine if $\text{TE}_{10}$ propagates. Calculate $u_p$ and $u_g$.
$$f_{c, 10} = \frac{c}{2a} = \frac{3\times 10^8}{2(0.08636)} = \mathbf{1.737\text{ GHz}}$$ $$\text{Since } f = 4\text{ GHz} > f_c, \text{ the mode propagates!}$$ $$u_p = \frac{c}{\sqrt{1 - (f_c/f)^2}} = \frac{3\times 10^8}{\sqrt{1 - (1.737/4)^2}} = \frac{3\times 10^8}{0.9008} = \mathbf{3.33\times 10^8\text{ m/s} \quad (> c)}$$ $$u_g = c\sqrt{1 - (f_c/f)^2} = \frac{c^2}{u_p} = \frac{9\times 10^{16}}{3.33\times 10^8} = \mathbf{2.702\times 10^8\text{ m/s} \quad (< c)}$$ $$\text{Verification: } u_p \cdot u_g = (3.33\times 10^8)(2.702\times 10^8) = 8.998\times 10^{16} \approx c^2 \quad \checkmark$$
Sadiku Example 12.8 ✓ Verified
An air-filled resonant cavity with $a = 5\text{ cm}, b = 4\text{ cm}, c = 10\text{ cm}$ is made of copper ($\sigma_c = 5.8\times 10^7\text{ S/m}$). Find: (a) The five lowest-order modes, (b) The quality factor $Q$ for the dominant $\text{TE}_{101}$ mode.
$$f_{r, mnp} = 15\sqrt{0.04m^2 + 0.0625n^2 + 0.01p^2}\text{ GHz}$$ $$\text{1. } \text{TE}_{101} = 15\sqrt{0.04 + 0 + 0.01} = \mathbf{3.354\text{ GHz} \quad (\text{Dominant Mode})}$$ $$\text{2. } \text{TE}_{011} = 15\sqrt{0 + 0.0625 + 0.01} = \mathbf{4.040\text{ GHz}}$$ $$\text{3. } \text{TE}_{102} = 15\sqrt{0.04 + 0 + 0.04} = \mathbf{4.243\text{ GHz}}$$ $$\text{4. } \text{TM}_{110} = 15\sqrt{0.04 + 0.0625 + 0} = \mathbf{4.800\text{ GHz}}$$ $$\text{5. } \text{TE}_{111} \text{ and } \text{TM}_{111} = 15\sqrt{0.04 + 0.0625 + 0.01} = \mathbf{5.031\text{ GHz} \quad (\text{Degenerate Pair})}$$

(b) Quality Factor Calculation:

$$\delta = \frac{1}{\sqrt{\pi f_{101} \mu_0 \sigma_c}} = \frac{1}{\sqrt{\pi (3.354\times 10^9)(4\pi \times 10^{-7})(5.8\times 10^7)}} = 1.141\times 10^{-6}\text{ m}$$ $$Q = \frac{(5^2 + 10^2)(5 \times 4 \times 10)\times 10^{-6}}{\delta [2(4)(5^3 + 10^3) + (5)(10)(5^2 + 10^2)]\times 10^{-4}} = \frac{125 \times 200 \times 10^{-2}}{\delta [8(1125) + 50(125)]} = \frac{250}{15250\,\delta} = \frac{1}{61\,\delta} = \mathbf{14,358}$$
Sadiku Example 12.9 ✓ Verified
A step-index fiber has core diameter $d = 80\ \mu\text{m}$, core index $n_1 = 1.62$, and $\text{NA} = 0.21$. Calculate: (a) Acceptance angle $\theta_a$, (b) Cladding refractive index $n_2$, (c) Number of propagating modes $N$ at $\lambda = 0.8\ \mu\text{m}$.
$$\theta_a = \sin^{-1}(\text{NA}) = \sin^{-1}(0.21) = \mathbf{12.12^\circ}$$ $$n_2 = \sqrt{n_1^2 - \text{NA}^2} = \sqrt{(1.62)^2 - (0.21)^2} = \sqrt{2.6244 - 0.0441} = \mathbf{1.606}$$ $$V = \frac{\pi d}{\lambda}\text{NA} = \frac{\pi (80\times 10^{-6})(0.21)}{0.8\times 10^{-6}} = 65.973$$ $$N \approx \frac{V^2}{2} = \frac{(65.973)^2}{2} = \mathbf{2,176\text{ propagating modes}}$$

Critical Academic Traps & Waveguide Invariants

⚠️ Trap 1: $\text{TM}_{10}$ and $\text{TM}_{01}$ Modes Do Not Exist
In rectangular waveguides, setting $m=0$ or $n=0$ in the TM boundary solutions causes the $\sin(m\pi x/a)$ or $\sin(n\pi y/b)$ factor to vanish, extinguishing every transverse field component. The lowest order TM mode is always $\text{TM}_{11}$. In contrast, $\text{TE}_{10}$ and $\text{TE}_{01}$ exist and thrive!
⚠️ Trap 2: Guide Wavelength is LONGER, Not Shorter ($\lambda_g > \lambda_0$)
Because phase velocity is superluminal ($u_p > c$), the spatial wave cycle along the guide axis is stretched: $\lambda_g = \lambda_0 / \sqrt{1-(f_c/f)^2} > \lambda_0$. At cutoff ($f = f_c$), $\lambda_g \to \infty$ (infinite guide wavelength).
⚠️ Trap 3: Wave Impedances Duality ($\eta_{TE} > \eta' > \eta_{TM}$)
As frequency decreases toward cutoff $f_c$, the TE wave impedance diverges toward infinity ($\eta_{TE} \to \infty$), while the TM wave impedance collapses to zero ($\eta_{TM} \to 0$). Their product is invariant: $\eta_{TE} \cdot \eta_{TM} = {\eta'}^2 = \mu / \varepsilon$.
