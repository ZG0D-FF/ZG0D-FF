Transmission Line Foundations & Telegrapher's Equations

Transmission lines guide electromagnetic energy from a source (generator, transmitter, oscillator) to a load (antenna, oscilloscope, network terminal) with minimal loss. Classic geometries include coaxial cable, twisted pair, parallel-plate (planar) line, wire above ground, and planar microstrip line.

$$-\frac{\partial V(z,t)}{\partial z} = R\,I(z,t) + L\,\frac{\partial I(z,t)}{\partial t}$$ $$-\frac{\partial I(z,t)}{\partial z} = G\,V(z,t) + C\,\frac{\partial V(z,t)}{\partial t}$$

Where distributed parameters per unit length are: $R$ (series resistance, $\Omega/\text{m}$), $L$ (series loop inductance, $\text{H/m}$), $G$ (shunt dielectric conductance, $\text{S/m}$), and $C$ (shunt capacitance, $\text{F/m}$).

Characteristic Impedance ($Z_0$)

The characteristic impedance $Z_0$ is defined as the ratio of positively traveling voltage wave to current wave at any point on an infinite or reflectionless line:

$$Z_0 = \frac{V_0^+}{I_0^+} = -\frac{V_0^-}{I_0^-} = \frac{R + j\omega L}{\gamma} = \frac{\gamma}{G + j\omega C} = \sqrt{\frac{R + j\omega L}{G + j\omega C}} = R_0 + jX_0$$
💡 Lucid Understanding: Lossless Transmission Line ($R = 0 = G$) Expand

A line is lossless when conductor conductivity is infinite ($\sigma_c \to \infty \implies R = 0$) and the dielectric medium is perfect insulator ($\sigma \to 0 \implies G = 0$). Under this condition:

$$\alpha = 0, \quad \gamma = j\beta = j\omega\sqrt{LC}$$ $$u_p = \frac{\omega}{\beta} = \frac{1}{\sqrt{LC}} = f\lambda$$ $$X_0 = 0, \quad Z_0 = R_0 = \sqrt{\frac{L}{C}}\ \Omega \quad (\text{Purely Resistive!})$$

Because $Z_0$ has zero imaginary part and phase velocity $u_p$ is independent of frequency, pulses propagate without attenuation or dispersion.

The Distortionless Line & Summary Matrix

A signal consists of a spectrum of frequencies. In a lossy line, different harmonics attenuate unequally if attenuation $\alpha(\omega)$ depends on frequency (amplitude distortion), and travel at different phase velocities if $\beta(\omega)$ is non-linear with $\omega$ (phase / dispersion distortion).

Oliver Heaviside's Distortionless Condition (1887)
A lossy line produces zero waveform distortion if the distributed parameters satisfy: $$\frac{R}{L} = \frac{G}{C} \iff RC = GL$$

Under the Heaviside condition:

$$\gamma = \sqrt{(R + j\omega L)(G + j\omega C)} = \sqrt{RG\left(1 + \frac{j\omega L}{R}\right)\left(1 + \frac{j\omega C}{G}\right)} = \sqrt{RG}\left(1 + \frac{j\omega C}{G}\right) = \sqrt{RG} + j\omega\sqrt{LC}$$ $$\alpha = \sqrt{RG}\text{ (Constant, Independent of Frequency!)}$$ $$\beta = \omega\sqrt{LC}\text{ (Strictly Linear in Frequency!)}$$ $$u_p = \frac{\omega}{\beta} = \frac{1}{\sqrt{LC}}\text{ (Constant Phase Velocity)}, \quad Z_0 = \sqrt{\frac{R}{G}} = \sqrt{\frac{L}{C}}\ \Omega$$
Case Propagation Constant $\gamma = \alpha + j\beta$ Characteristic Impedance $Z_0 = R_0 + jX_0$ Phase Velocity $u_p$
General Lossy Line $\sqrt{(R + j\omega L)(G + j\omega C)}$ $\sqrt{\frac{R + j\omega L}{G + j\omega C}}$ $\frac{\omega}{\beta}$ (Frequency-dependent)
Lossless Line ($R = G = 0$) $0 + j\omega\sqrt{LC}$ $\sqrt{\frac{L}{C}} + j0$ $\frac{1}{\sqrt{LC}}$ (Constant)
Distortionless Line ($RC = GL$) $\sqrt{RG} + j\omega\sqrt{LC}$ $\sqrt{\frac{L}{C}} + j0$ $\frac{1}{\sqrt{LC}}$ (Constant)
Engineering Insight: Telephone Lines vs. Power Lines
A lossless line is always distortionless, but a distortionless line is not necessarily lossless (it has finite attenuation $\alpha = \sqrt{RG} > 0$). In power transmission, losslessness is paramount ($R \approx 0$). In long-distance telephony, distortionlessness is paramount to preserve speech intelligibility—achieved historically by inserting lumped series loading coils (Pupin coils) to increase $L$ so that $R/L = G/C$.

Voltage Standing Wave Ratio (VSWR), Reflection Coefficient & Transit Time

1 · Load Reflection Coefficient ($\Gamma_L$)

The voltage reflection coefficient at the load termination ($z = l$) is defined as:

$$\Gamma_L = \frac{V_0^- e^{\gamma l}}{V_0^+ e^{-\gamma l}} = \frac{Z_L - Z_0}{Z_L + Z_0} = |\Gamma_L|\,e^{j\theta_\Gamma}$$

Normalized load impedance: $z_n = \frac{Z_L}{Z_0} \implies \Gamma_L = \frac{z_n - 1}{z_n + 1}$.

2 · Voltage Standing Wave Ratio ($s$)

Superposition of forward and reverse traveling waves sets up a standing wave with interference maxima and minima:

$$s = \frac{V_{max}}{V_{min}} = \frac{I_{max}}{I_{min}} = \frac{1 + |\Gamma_L|}{1 - |\Gamma_L|}, \quad |\Gamma_L| = \frac{s - 1}{s + 1}$$

Boundary bounds: $1 \le s \le \infty$.

  • Matched Load ($Z_L = Z_0$): $\Gamma_L = 0 \implies s = 1$ (Flat line, zero reflection, 100% power absorption).
  • Short Circuit ($Z_L = 0$): $\Gamma_L = -1 \implies s = \infty$ (Total reflection, standing wave nodes on load).
  • Open Circuit ($Z_L = \infty$): $\Gamma_L = +1 \implies s = \infty$ (Total reflection, standing wave antinodes on load).
3 · Extremal Input Impedances Along the Line
$$Z_{in,max} = \frac{V_{max}}{I_{min}} = s\,Z_0, \quad Z_{in,min} = \frac{V_{min}}{I_{max}} = \frac{Z_0}{s}$$

Quarter-wave geometric mean property: $\sqrt{Z_{in,max} \cdot Z_{in,min}} = Z_0$.

4 · Transit Time Effect in Transmission Lines

Signals propagate with finite phase velocity $v_p$, requiring finite transit delay:

$$t_{transit} = \frac{l}{v_p}$$
The $\lambda/20$ Distributed Boundary Criterion
Transit time delay becomes critical and lumped Kirchhoff circuit analysis (KVL/KCL) fails whenever line length $l \ge \frac{\lambda}{20}$ (or delay $t_{transit} \ge \frac{T}{20}$). Distributed parameter wave analysis (Telegrapher's equations) must be employed.

Rectangular Waveguides, Cutoff Frequencies & Boundary Conditions

A waveguide is a hollow metallic conduit (usually rectangular or circular in cross-section) that confines and routes microwave signals through internal total reflections off conducting walls.

Why Hollow Waveguides Do NOT Support TEM Mode
In TEM mode, $\mathbf{E}$ and $\mathbf{H}$ are purely transverse ($E_z = 0, H_z = 0$). In the transverse plane, $\nabla_t^2 \Phi = 0$ (Laplace's equation). By the maximum principle, a single closed equipotential conducting boundary enforces a constant potential throughout its interior ($\Phi = \text{const} \implies \mathbf{E} = -\nabla \Phi = 0$). Hence, at least two isolated conductors are required for TEM (e.g. coaxial cable or two-wire line). A hollow single-conductor pipe supports only TE ($E_z = 0, H_z \ne 0$) and TM ($H_z = 0, E_z \ne 0$) modes.

Cutoff Frequency Formulation ($f_c$)

For a rectangular waveguide of inner cross-section dimensions $a \times b$ (with broad wall $a > b$):

$$f_c = \frac{\omega_c}{2\pi} = \frac{1}{2\pi\sqrt{\mu\varepsilon}}\sqrt{\left(\frac{m\pi}{a}\right)^2 + \left(\frac{n\pi}{b}\right)^2} = \frac{c}{2\sqrt{\mu_r\varepsilon_r}}\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}$$ $$\lambda_c = \frac{c}{f_c\sqrt{\mu_r\varepsilon_r}} = \frac{2}{\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}}$$
Operational Regime Frequency Condition Wave Behavior
Propagation Band $f > f_c \iff \lambda_0 < \lambda_c$ Propagation constant $\beta = \omega\sqrt{\mu\varepsilon}\sqrt{1 - (f_c/f)^2}$ is real; wave propagates freely with low loss.
Cutoff Boundary $f = f_c \iff \lambda_0 = \lambda_c$ $\beta = 0, \lambda_g \to \infty$; wave oscillates in place without forward transport.
Evanescent Stopband $f < f_c \iff \lambda_0 > \lambda_c$ $\gamma = \alpha = \omega\sqrt{\mu\varepsilon}\sqrt{(f_c/f)^2 - 1}$ is purely real; field decays exponentially along guide ($e^{-\alpha z}$), zero real power transmitted (High-pass filter behavior).
💡 Lucid Understanding: Dominant Mode & Degenerate Modes Expand

Dominant Mode ($\text{TE}_{10}$): Defined as the mode with the lowest cutoff frequency. For $a > b$, setting $m=1, n=0$ yields:

$$f_{c,\text{TE}_{10}} = \frac{c}{2a\sqrt{\mu_r\varepsilon_r}} \implies \lambda_c = 2a$$ $$\text{Condition for propagation: } a > \frac{\lambda_0}{2}$$

Degenerate Modes: Distinct field distributions that share identical cutoff frequencies. For example, in a rectangular guide, $\text{TE}_{mn}$ and $\text{TM}_{mn}$ (for $m \ge 1, n \ge 1$) are degenerate modes. If $a = b$ (square guide), $\text{TE}_{10}$ and $\text{TE}_{01}$ are degenerate.

Conducting Wall Boundary Conditions: Tangential $\mathbf{E}$ must vanish ($E_t = 0$), and normal $\mathbf{B}$ must vanish ($B_n = 0$).

Guide Wavelength ($\lambda_g$) & Relativistic Velocities ($v_p, v_g$)

Inside a waveguide, electromagnetic energy does not travel straight down the pipe; it zigzags between opposite walls at an angle $\theta$. This geometric bouncing produces distinct phase and group velocities.

1 · Guide Wavelength ($\lambda_g$)

The guide wavelength $\lambda_g$ is the distance between two equal-phase wavefronts along the longitudinal guide axis:

$$\lambda_g = \frac{\lambda_0}{\sqrt{1 - \left(\frac{\lambda_0}{\lambda_c}\right)^2}} = \frac{\lambda_0}{\sqrt{1 - \left(\frac{f_c}{f}\right)^2}}$$

Because $\sqrt{1 - (f_c/f)^2} < 1$, $\lambda_g > \lambda_0$ always!
Case 1: As $f \to f_c$ ($\lambda_0 \to \lambda_c$), $\lambda_g \to \infty$.
Case 2: As $f \gg f_c$ ($\lambda_0 \ll \lambda_c$), $\lambda_g \to \lambda_0$.

2 · Phase Velocity ($v_p$) vs Group Velocity ($v_g$)

Phase velocity $v_p$ measures the speed of apparent crest movement along the wall, whereas group velocity $v_g$ measures the physical speed of energy and information transport:

$$v_p = \frac{\omega}{\beta} = \frac{c}{\sqrt{1 - \left(\frac{f_c}{f}\right)^2}} > c \quad (\text{Exceeds Speed of Light!})$$ $$v_g = \frac{d\omega}{d\beta} = c\sqrt{1 - \left(\frac{f_c}{f}\right)^2} < c \quad (\text{Subluminal Energy Transport})$$
3 · Fundamental Relativistic Identity
$$v_p \cdot v_g = c^2$$

Notice $v_p > c$ does NOT violate Einstein's special relativity because phase velocity carries zero information. Modulation, pulses, and electromagnetic Poynting energy flow at group velocity $v_g$, which is strictly bounded below $c$.

Complete Analytical Solutions for the 6 Mandatory Derivations

Derivation 1 Transmission Line Wave Equations from Distributed Parameters ($R, L, G, C$)

Proof: Consider an incremental slice of line $\Delta z$. Applying KVL to the outer loop: $$V(z,t) - R\Delta z\,I(z,t) - L\Delta z\,\frac{\partial I(z,t)}{\partial t} - V(z+\Delta z, t) = 0$$ Dividing by $\Delta z$ and taking the limit $\Delta z \to 0$: $$-\frac{\partial V}{\partial z} = R\,I + L\,\frac{\partial I}{\partial t} \quad \xrightarrow{\text{Phasor}} \quad -\frac{dV_s}{dz} = (R + j\omega L)I_s \quad \text{--- (1)}$$ Applying KCL to the shunt node: $$I(z,t) - G\Delta z\,V(z+\Delta z,t) - C\Delta z\,\frac{\partial V(z+\Delta z,t)}{\partial t} - I(z+\Delta z, t) = 0$$ Dividing by $\Delta z$ and letting $\Delta z \to 0$: $$-\frac{\partial I}{\partial z} = G\,V + C\,\frac{\partial V}{\partial t} \quad \xrightarrow{\text{Phasor}} \quad -\frac{dI_s}{dz} = (G + j\omega C)V_s \quad \text{--- (2)}$$ Differentiating (1) with respect to $z$ and substituting (2): $$-\frac{d^2V_s}{dz^2} = (R + j\omega L)\frac{dI_s}{dz} = -(R + j\omega L)(G + j\omega C)V_s$$ $$\frac{d^2V_s}{dz^2} - \gamma^2 V_s = 0, \quad \frac{d^2I_s}{dz^2} - \gamma^2 I_s = 0, \quad \text{where } \gamma = \sqrt{(R+j\omega L)(G+j\omega C)} \quad \blacksquare$$

Derivation 2 Relationship Between Wavelength ($\lambda$), Velocity ($v$), and Frequency ($f$)

Proof: The instantaneous traveling wave is $V(z,t) = V_0 \cos(\omega t - \beta z)$. A spatial cycle of length $\lambda$ corresponds to a phase shift of $2\pi$ radians: $$\beta\lambda = 2\pi \implies \lambda = \frac{2\pi}{\beta}$$ By d'Alembert phase invariance $d(\omega t - \beta z) = 0 \implies v = \frac{dz}{dt} = \frac{\omega}{\beta}$. Substituting $\omega = 2\pi f$ and $\beta = \frac{2\pi}{\lambda}$: $$v = \frac{2\pi f}{2\pi / \lambda} = f\lambda \implies \mathbf{v = f\lambda} \quad \blacksquare$$

Derivation 3 Voltage Standing Wave Ratio (VSWR) in Terms of Reflection Coefficient ($\Gamma_L$)

Proof: At any distance $d = l - z$ from the load, total voltage is: $$V_s(d) = V_0^+ e^{j\beta d}\left[1 + \Gamma_L e^{-j2\beta d}\right] = V_0^+ e^{j\beta d}\left[1 + |\Gamma_L|e^{j(\theta_\Gamma - 2\beta d)}\right]$$ Maximum voltage occurs when incident and reflected phasors are in-phase ($e^{j(\theta_\Gamma - 2\beta d)} = +1$): $$V_{max} = |V_0^+|\left(1 + |\Gamma_L|\right)$$ Minimum voltage occurs when they are in phase opposition ($e^{j(\theta_\Gamma - 2\beta d)} = -1$): $$V_{min} = |V_0^+|\left(1 - |\Gamma_L|\right)$$ Taking the ratio: $$s \equiv \frac{V_{max}}{V_{min}} = \frac{|V_0^+|(1 + |\Gamma_L|)}{|V_0^+|(1 - |\Gamma_L|)} = \mathbf{\frac{1 + |\Gamma_L|}{1 - |\Gamma_L|}} \quad \blacksquare$$

Derivation 4 Voltage Transmission / Transmittance Coefficient ($T$) in Terms of $Z_L$ and $Z_0$

Proof: Transmittance $T$ is the ratio of total voltage at the load to incident voltage: $$T = \frac{V_L}{V_{inc}} = \frac{V_0^+ + V_0^-}{V_0^+} = 1 + \frac{V_0^-}{V_0^+} = 1 + \Gamma_L$$ Substituting $\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0}$: $$T = 1 + \frac{Z_L - Z_0}{Z_L + Z_0} = \frac{(Z_L + Z_0) + (Z_L - Z_0)}{Z_L + Z_0} = \mathbf{\frac{2Z_L}{Z_L + Z_0}} \quad \blacksquare$$

Derivation 5 Proof that Phase Velocity ($v_p$) in a Waveguide Always Exceeds the Velocity of Light ($c$)

Proof: The longitudinal dispersion relation in a lossless waveguide is: $$k^2 = k_c^2 + \beta^2 \implies \beta = \sqrt{k^2 - k_c^2} = \omega\sqrt{\mu\varepsilon}\sqrt{1 - \left(\frac{\omega_c}{\omega}\right)^2} = \frac{\omega}{c}\sqrt{1 - \left(\frac{f_c}{f}\right)^2}$$ By definition, phase velocity is $v_p = \frac{\omega}{\beta}$: $$v_p = \frac{\omega}{\frac{\omega}{c}\sqrt{1 - (f_c/f)^2}} = \frac{c}{\sqrt{1 - (f_c/f)^2}}$$ For propagating waves, $f > f_c \implies 0 < \left(\frac{f_c}{f}\right)^2 < 1$. Consequently, the radical denominator is strictly less than unity: $$\sqrt{1 - \left(\frac{f_c}{f}\right)^2} < 1 \implies \mathbf{v_p = \frac{c}{\sqrt{1 - (f_c/f)^2}} > c} \quad \blacksquare$$

Derivation 6 Expression for Guide Wavelength ($\lambda_g$) and Relation with Free-Space Wavelength ($\lambda_0$)

Proof: Guide wavelength is defined by $\beta = \frac{2\pi}{\lambda_g}$, free-space wavelength by $k = \frac{2\pi}{\lambda_0}$, and cutoff wavelength by $k_c = \frac{2\pi}{\lambda_c}$. Substituting into the separation equation $k^2 = k_c^2 + \beta^2$: $$\left(\frac{2\pi}{\lambda_0}\right)^2 = \left(\frac{2\pi}{\lambda_c}\right)^2 + \left(\frac{2\pi}{\lambda_g}\right)^2$$ Dividing through by $4\pi^2$: $$\mathbf{\frac{1}{\lambda_0^2} = \frac{1}{\lambda_c^2} + \frac{1}{\lambda_g^2}} \iff \frac{1}{\lambda_g^2} = \frac{1}{\lambda_0^2} - \frac{1}{\lambda_c^2} = \frac{\lambda_c^2 - \lambda_0^2}{\lambda_0^2\lambda_c^2}$$ Inverting and taking the square root: $$\mathbf{\lambda_g = \frac{\lambda_0}{\sqrt{1 - \left(\frac{\lambda_0}{\lambda_c}\right)^2}}} \quad \blacksquare$$
