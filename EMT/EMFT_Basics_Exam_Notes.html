2. Coordinate Systems

Cartesian coordinates

dℓ = dx ax + dy ay + dz az
dv = dx dy dz
dS = dy dz ax
      dx dz ay
      dx dy az

cylindrical coordinates

dℓ = dρ aρ + ρ dϕ aϕ + dz az
dv = ρ dρ dϕ dz
dS = ρ dϕ dz aρ
      dρ dz aϕ
      ρ dρ dϕ az

spherical coordinates

dℓ = dr ar + r dθ aθ + r sin θ dϕ aϕ
dv = r² sin θ dr dθ dϕ
dS = r² sin θ dθ dϕ ar
      r sin θ dr dϕ aθ
      r dr dθ aϕ

4. DEL Operator

The del operator is the vector differential operator

Cartesian coordinates

∇ = ∂/∂x ax + ∂/∂y ay + ∂/∂z az

cylindrical coordinates

∇ = aρ ∂/∂ρ + aϕ (1/ρ) ∂/∂ϕ + az ∂/∂z

spherical coordinates

∇ = ar ∂/∂r + aθ (1/r) ∂/∂θ + aϕ (1/(r sin θ)) ∂/∂ϕ

1. The gradient of a scalar V, written as ∇V

2. The divergence of a vector A, written as ∇ · A

3. The curl of a vector A, written as ∇ × A

4. The Laplacian of a scalar V, written as ∇²V

5. Gradient

The length and direction of the arrow indicates if the slope is positive or negative, and by how much amount

Cartesian coordinates

∇V = (∂V/∂x)ax + (∂V/∂y)ay + (∂V/∂z)az

cylindrical coordinates

∇V = (∂V/∂ρ)aρ + (1/ρ)(∂V/∂ϕ)aϕ + (∂V/∂z)az

spherical coordinates

∇V = (∂V/∂r)ar + (1/r)(∂V/∂θ)aθ + (1/(r sin θ))(∂V/∂ϕ)aϕ

6. Divergence

The divergence of A at a given point P is the outward flux per unit volume as the volume shrinks about P.

div A = ∇ · A = limΔv→0 [ ∮S A · dS / Δv ]

Cartesian coordinates

∇ · A = ∂Ax/∂x + ∂Ay/∂y + ∂Az/∂z

cylindrical coordinates

∇ · A = (1/ρ) ∂/∂ρ (ρAρ) + (1/ρ) ∂Aϕ/∂ϕ + ∂Az/∂z

spherical coordinates

∇ · A = (1/r²) ∂/∂r (r²Ar) + (1/(r sin θ)) ∂/∂θ (Aθ sin θ) + (1/(r sin θ)) ∂Aϕ/∂ϕ

7. Divergence Theorem

The divergence theorem states that the total outward flux of a vector field A through the closed surface S is the same as the volume integral of the divergence of A

∮S A · dS = ∫v (∇ · A) dv

8. Worked Examples from the Lecture

Gradient example

Find the gradient of the following scalar fields:

(a) V = e−z sin 2x cosh y

(b) U = ρ2z cos 2ϕ

(c) W = 10r sin2 θ cos ϕ

(a) Solution

∇V = ∂V/∂x ax + ∂V/∂y ay + ∂V/∂z az

= 2e−z cos 2x cosh y ax + e−z sin 2x sinh y ay − e−z sin 2x cosh y az

(b) Solution

∇U = ∂U/∂ρ aρ + (1/ρ) ∂U/∂ϕ aϕ + ∂U/∂z az

= 2ρz cos 2ϕ aρ − 2ρz sin 2ϕ aϕ + ρ2 cos 2ϕ az

(c) Solution

∇W = ∂W/∂r ar + (1/r) ∂W/∂θ aθ + (1/(r sin θ)) ∂W/∂ϕ aϕ

= 10 sin2 θ cos ϕ ar + 10 sin 2θ cos ϕ aθ − 10 sin θ sin ϕ aϕ
Divergence example

Determine the divergence of these vector fields:

(a) P = x2yz ax + xz az

(b) Q = ρ sin ϕ aρ + ρ2z aϕ + z cos ϕ az

(c) T = (1/r2) cos θ ar + r sin θ cos ϕ aθ + cos θ aϕ

(a) Solution

∇ · P = ∂Px/∂x + ∂Py/∂y + ∂Pz/∂z

= ∂/∂x (x2yz) + ∂/∂y (0) + ∂/∂z (xz)

= 2xyz + x

(b) Solution

∇ · Q = (1/ρ) ∂/∂ρ (ρQρ) + (1/ρ) ∂Qϕ/∂ϕ + ∂Qz/∂z

= (1/ρ) ∂/∂ρ (ρ2 sin ϕ) + (1/ρ) ∂/∂ϕ (ρ2z) + ∂/∂z (z cos ϕ)

= 2 sin ϕ + cos ϕ

(c) Solution

∇ · T = (1/r²) ∂/∂r (r²Tr) + (1/(r sin θ)) ∂/∂θ (Tθ sin θ) + (1/(r sin θ)) ∂Tϕ/∂ϕ

= (1/r²) ∂/∂r (cos θ) + (1/(r sin θ)) ∂/∂θ (r sin2 θ cos ϕ) + (1/(r sin θ)) ∂/∂ϕ (cos θ)

= 0 + (1/(r sin θ)) 2r sin θ cos θ cos ϕ + 0

= 2 cos θ cos ϕ
Flux through a cylinder

If G(r) = 10e−2z(ρaρ + az), determine the flux of G out of the entire surface of the cylinder ρ = 1, 0 ≤ z ≤ 1. Confirm the result by using the divergence theorem.

Ψ = ∮S G · dS = Ψt + Ψb + Ψs

For Ψt, z = 1, dS = ρ dρ dϕ az

Ψt = ∬ G · dS = ∫ρ=01 ∫ϕ=02π 10e−2ρ dρ dϕ = 10πe−2

For Ψb, z = 0 and dS = ρ dρ dϕ (−az). Hence,

Ψb = ∬ G · dS = ∫ρ=01 ∫ϕ=02π 10ρ dρ dϕ = −10π

For Ψs, ρ = 1 and dS = ρ dz dϕ aρ. Hence,

Ψs = ∬ G · dS = ∫z=01 ∫ϕ=02π 10e−2zρ² dz dϕ = 10π(1 − e−2)
Ψ = 0

Using the divergence theorem:

Ψ = ∮S G · dS = ∫v (∇ · G) dv
∇ · G = (1/ρ) ∂/∂ρ (ρGρ) + (1/ρ) ∂Gϕ/∂ϕ + ∂Gz/∂z

= (1/ρ) ∂/∂ρ (ρ²10e−2z) − 20e−2z

= (1/ρ)(20ρe−2z) − 20e−2z = 0
Ψ = 0
