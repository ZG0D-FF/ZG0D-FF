01 — Definition

What is TinyML?

01

Tiny Machine Learning

An emerging field at the intersection of Machine Learning and Embedded Systems — bringing AI intelligence directly to small, constrained computing devices.

02

Embedded Systems

Small computing devices that operate on extremely low power — measured in milliwatts. Some can run for years on a single button-cell battery.

03

The Core Goal

Bring AI to tiny processors so they can process sensor data — images, speech, motion — right at the source, without needing cloud connectivity.

04

The Critical Nugget

Bridging the gap between an application's needs and hardware limitations. Example: smart glasses that translate in real-time without a 5-second delay.

08 — Architecture

Cloud Centers
vs Edge Devices

☁️

The Cloud (Data Centers)

High Power: Gigawatts of energy for massive server racks.
High Bandwidth: Requires uploading massive amounts of data.
High Latency: Noticeable delay sending data far away and waiting for a response.

⌚

The Edge (TinyML)

Low Power: Runs on small batteries for days or years (~140 μW).
Low Bandwidth: No need to rely on network connectivity.
Low Latency: Immediate, local processing for instant interactivity.

12 — Architecture

Embedded
Systems

🧠

Compute (CPU)

The "brain" or processor (including ALU, Registers, and Control Logic) where the actual processing and decision-making occurs.

⚡

Memory (RAM)

Read-Write Memory. Short-term, volatile storage used for temporary workspace data while the system is actively running.

💾

Storage (ROM)

Read-Only Memory. Permanent, non-volatile storage that retains boot instructions and code even when the power is turned off.

🔌

I/O & Peripherals

Interfacing with the physical world through Timer synchronizations, serial interfaces, ADCs, and PWMs.

13 — Hardware Comparison

MPU vs MCU

MPU

Microprocessor

Primary Use: General-purpose computing (laptops, servers).
Integration: Needs external memory and storage chips.
Specs: 1–4 GHz, GBs of Memory, TBs of Storage, Watts of Power.
Flexibility: Highly configurable.

MCU

Microcontroller

Primary Use: Fixed-function systems (blood pressure monitors).
Integration: Monolithic "System on a Chip" (SoC).
Specs: 1–400 MHz, KBs of Memory, MBs of Storage, μW of Power.
Flexibility: Preset configurations from a family of chips.

14 — Lecture 03 (Part B)

Software
Abstractions

📱

General Computing

Features a robust stack: High-Level Apps, Libraries for portability, and a heavy OS (Windows/Android/Linux) abstracting all hardware complexity.

🪫

Embedded Reality

Lacks a general OS. Adding FreeRTOS eats precious memory. Hardware is highly specialized, resulting in low code portability across different chips.

FPU

Floating Point Unit

Math with decimals is slow in software (emulation). PCs use physical FPUs on-chip, but a 50-cent MCU often can't afford the cost, power, or transistor space.

754

IEEE 754 Standard

The technical standard for 32-bit single-precision math. Uses 1 bit for Sign, 8 bits for Exponent (magnitude), and 23 bits for Fraction (precision).

17 — Lecture 03 (Part C)

The ML
Paradigm

💻

Explicit Coding (Traditional)

Rules + Data = Answers. The programmer manually writes every rule. Hits a complexity limit (diminishing returns) for things like activity detection where rules are too complex to pre-calculate.

🤖

Machine Learning

Answers + Data = Rules. The computer acts as a "rule-discovery" engine. It finds subtle distinguishing factors in the data to build a Model that can predict future rules.

18 — Optimization

The Learning
Loop

1
Guess
Initialize with a random guess (e.g., random network weights like w=10.0).
2
Measure (Loss)
Calculate error. MSE: $Loss = \frac{1}{n} \sum (y - \hat{y})^2$
3
Optimize
Use Gradient (direction) and Learning Rate (step size) to adjust weights.
MSE

Mean Squared Error

Simply summing errors causes the "Cancellation Trap" (-1 + 1 = 0). Squaring them makes all misses positive, revealing the true error magnitude.

CURVE

Moving Down the Curve

Loss is a U-shaped parabola. The goal is to reach the bottom (Convergence) where steps become tiny and the optimal rules are found.

19 — Neural Networks

Neurons &
Code Logic

🧠

The Computational Neuron

The fundamental building block. Solves the linear equation: Y = wX + b. Uses Gradient Tape to track math operations and compute derivatives.

🎲

Stochastic Approximations

ML systems operate on probabilities, not exact certainties. Instead of exactly Y = 2X - 1, the model might converge on Y = 1.98X - 0.94.

Def
Sequential Model
input_shape=[1]
Crucial for TinyML memory limits. Tells the first layer exactly how many data points to expect, allocating the minimum amount of RAM.
Fit
Training
model.fit()
Executes the Guess → Measure → Optimize loop across a set number of epochs (e.g., 500) to find the underlying mathematical rule.
Out
Inference
model.predict()
Passes novel data through the trained, optimized parameters (weights & biases) to generate a stochastic guess for the output.

20 — Lecture 04

Introduction to
Classification

📈

Regression vs Classification

Regression predicts a specific number (like 19.0). Classification guesses a probability across multiple output neurons to categorize data (e.g., Cat vs Dog).

🏷️

Labeling Vectors

To teach a model, categories are turned into arrays (vectors). A Cat might be [1, 0] and a Dog [0, 1]. For digits 0-9, you use an array of 10 numbers.

SMAX

Softmax Activation

Used in the Output Layer. It scales raw neuron scores so they sum to exactly 1 (100%), turning them into mutually exclusive probabilities (e.g., 99% sure it's a 7).

RELU

ReLU Activation

Used in Hidden Layers. It converts any negative value to 0 to prevent neurons from canceling each other out, allowing the network to learn non-linear patterns.
