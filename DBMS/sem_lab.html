💡 Mechanical Syntax Breakdown: ALTER TABLE MENU_ITEM ADD (is_veg NUMBER(1) CHECK (is_veg IN (0,1))); ▼
ALTER TABLE MENU_ITEM → DDL schema modification instruction targeting MENU_ITEM metadata in Oracle data dictionary. Requires exclusive table lock.
ADD (...) → Instructs Oracle kernel to allocate new attribute descriptor and column ID without copying whole table segment.
is_veg NUMBER(1) → Oracle SQL lacks native BOOLEAN column type. Single-digit integer (precision 1, scale 0) represents boolean flag (0=Non-Veg, 1=Veg).
CHECK (is_veg IN (0,1)) → Domain integrity constraint. Kernel validates every future INSERT/UPDATE row tuple; throws ORA-02290 if any other value (e.g. 2, -1) is supplied.

Task 15 Oral Rule: DROP COLUMN modifies table definition by removing metadata descriptors, whereas TRUNCATE deallocates data extents from the tablespace while keeping the column structure intact.

ORA-01400 cannot insert NULL → Entity Integrity Violation. In INSERT INTO STUD_MEMBER (name, dept_id), roll_no was omitted from column list, defaulting to NULL. Oracle kernel rejects before buffer write because PK implicitly asserts NOT NULL.
NOT IN (subquery IS NOT NULL) → 3-Valued Logic Defense. If the subquery in NOT IN returns even a single NULL, the comparison x != NULL evaluates to UNKNOWN, causing the entire outer query to return zero rows! Adding WHERE dept_id IS NOT NULL neutralizes this trap.

💡 Mechanical Syntax Breakdown: Oracle Date Functions (MONTHS_BETWEEN, NEXT_DAY, LAST_DAY) ▼
MONTHS_BETWEEN(SYSDATE, hiredate) → Calculates elapsed months. If day-of-month matches or both are last days of respective months, yields exact integer; otherwise computes fractional 31-day month divisor. Wrapped in ROUND() for whole integers.
NEXT_DAY(hiredate, 'MONDAY') → Finds the date of the first specified weekday chronologically following the given date. Trap: Day string depends on session NLS_DATE_LANGUAGE.
LAST_DAY(hiredate) → Determines the final calendar date of the month containing the date (e.g. 28/29 in Feb, 30 in Apr, 31 in Dec). Preserves time component.
CREATE OR REPLACE VIEW → Creates virtual stored query. Simple views with 1-to-1 table mappings pass DML (INSERT/UPDATE/DELETE) straight to the underlying physical table (EMP_20).

Tasks 50 to 53: Department Aggregations & WHERE vs HAVING Order COUNT / AVG / HAVING 
-- 50. Number of employees and average salary per department
SELECT 
    d.deptno, 
    d.dname, 
    COUNT(e.empno) AS emp_count, 
    NVL(ROUND(AVG(e.sal), 2), 0) AS avg_sal
FROM DEPT_20 d
LEFT JOIN EMP_20 e ON d.deptno = e.deptno
GROUP BY d.deptno, d.dname
ORDER BY d.deptno;

-- 51. Total salary payable
SELECT deptno, SUM(sal) AS total_sal FROM EMP_20 GROUP BY deptno;

-- 52 & 53. WHERE filter (sal > 5000) followed by HAVING filter (avg > 6500)
SELECT deptno, COUNT(*) AS emp_cnt, ROUND(AVG(sal), 2) AS dept_avg
FROM EMP_20
WHERE sal > 5000
GROUP BY deptno
HAVING AVG(sal) > 6500;

WHERE vs HAVING Lifecycle: WHERE evaluates before grouping, filtering individual row tuples. HAVING evaluates after grouping, filtering the computed aggregate bucket metrics.

💡 Mechanical Syntax Breakdown: WHERE vs HAVING Execution Pipeline ▼
1. FROM + JOIN → Forms candidate Cartesian/join product in SGA buffer cache.
2. WHERE sal > 5000 → Pre-aggregation row filter. Discards low-salary individual employee rows BEFORE grouping structures are allocated.
3. GROUP BY deptno → Hash/sort aggregator partitions qualifying tuples into distinct department hash buckets in PGA memory.
4. HAVING AVG(sal) > 6500 → Post-aggregation group filter. Discards entire department summary buckets whose computed average falls below 6500.
5. SELECT deptno, COUNT(*) → Projects requested columns and scalar aggregators (COUNT(*), ROUND(AVG(sal), 2)) for transmission to client cursor.

Top 10 Viva Voce Traps & Mechanics

1. CHECK(ename = UPPER(ename)) Behavior

Any insert with lowercase letters evaluates the predicate to FALSE, triggering ORA-02290. String literals must be uppercase.

2. Empty String ('') in Oracle

Oracle treats empty strings '' as NULL. Testing WHERE col = '' returns zero tuples; write WHERE col IS NULL.

3. TRUNCATE with Foreign Key References

Fails with ORA-02266 if an active foreign key references the table, even if the child table contains zero rows. Disable FK constraint first.

4. NVL vs NVL2 Semantics

NVL(a, b) returns $b$ if $a$ is null. NVL2(a, b, c) returns $b$ if $a$ is not null, and $c$ if $a$ is null.

5. High Water Mark (HWM)

DELETE removes rows but leaves the HWM unchanged, meaning full table scans still read all historical blocks. TRUNCATE resets HWM back to block 0.

6. NOT IN with NULL in Subquery

A NULL inside a NOT IN list causes the comparison to evaluate to UNKNOWN, returning 0 rows. Always filter WHERE col IS NOT NULL in subqueries.

7. ROWNUM Evaluation Order

ROWNUM is assigned after a row passes WHERE filtering. Testing ROWNUM = 2 always fails because candidate row 1 is discarded, resetting the counter.

8. Internal DATE Format

Oracle DATE is a 7-byte binary structure storing Century, Year, Month, Day, Hour, Minute, and Second. It always retains time.
