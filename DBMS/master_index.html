Module 1

Foundations, ER & Relational

Chapter 3: SQL Fundamentals

DDL definitions, scalar datatypes, the three-clause query structure, multi-relation Cartesian products, natural joins, set operations, three-valued null logic, grouping, and subqueries.

Module 3

Chapter 4: Intermediate SQL

Advanced join expressions (ON vs WHERE), outer joins (LEFT, RIGHT, FULL), virtual views vs. materialized views, view updatability criteria, ACID transactions, and role-based authorization (GRANT/REVOKE).

Internals & Oracle Lab

Physical file storage, block structures, blocking factor (bfr) formulas, single-level sparse/dense indexes, dynamic B+ Trees, step-by-step Oracle SQL DDL workshops, and query drills.

Course Outcomes (COs)

CO1: Database Architecture & ModelingThorough understanding of enterprise database systems, 3-schema data independence, and conceptual E-R design.
CO2: Relational Theory & SQL MasteryLogical database design utilizing relational algebra and calculus, extending into declarative SQL query mastery.
CO3: Relational Schema RefinementUnderstanding schema design, functional dependencies, canonical covers, and normalization algorithms (1NF through BCNF/5NF).
CO4: Systems Internals & StorageDeep comprehension of ACID transaction schedules, concurrency recovery protocols, and physical block index architectures (B+ Trees).
