Oracle SQL DDL Lab

Lucid, exam/viva-ready notes on Data Definition Language — the commands that shape a database's structure (tables, columns, constraints) rather than its data.

01 Create EMP Table

Code

CREATE TABLE EMP_XX (
    Empno NUMBER(4) PRIMARY KEY,
    Ename VARCHAR2(10) CHECK (Ename = UPPER(Ename)),
    Job VARCHAR2(9),
    Mgr NUMBER(4),
    Hiredate DATE,
    Sal NUMBER(7,2),
    Comm NUMBER(7,2),
    CONSTRAINT chk_sal_XX CHECK (Sal BETWEEN 1500 AND 50000)
);

Replace XX with your roll number.

Why this code exists

Every database needs a place to store employee details. This command creates that table and adds rules so invalid data cannot be entered.

What it can do

  • Creates an employee table.
  • Prevents duplicate employee numbers.
  • Forces employee names to be uppercase.
  • Allows only valid salary values.
  • Stores manager, hiring date, and commission information.

04 Create Department Table

Code

CREATE TABLE DEPT (
    Deptno NUMBER(2) PRIMARY KEY,
    Dname VARCHAR2(10) CHECK (Dname = UPPER(Dname)),
    Location VARCHAR2(9)
        CHECK (Location IN ('KOL','MUM','DEL')),
    City VARCHAR2(30)

Why this code exists

Instead of writing department names repeatedly for every employee, we create one department table.

05 Add Foreign Key

Code

ALTER TABLE EMP_XX
ADD CONSTRAINT fk_deptno_XX
FOREIGN KEY (DEPTNO)
REFERENCES DEPT(Deptno);

Why this code exists

Every employee should belong to a real department. Without this rule, an employee could reference a department number that doesn't exist. The foreign key prevents this.

How it works

DEPT table contains Deptno 10 and 20. An employee can reference 10 or 20, but not 30 if it's absent.

General structure

ALTER TABLE child_table
ADD CONSTRAINT constraint_name
FOREIGN KEY(column)
REFERENCES parent_table(column);

Expected output

Table altered.

DROP vs TRUNCATE

One of the most common viva questions.

FeatureDROPTRUNCATE
Deletes dataYesYes
Deletes structureYesNo
Table remains?NoYes
Can insert again immediately?No (table gone)Yes

After TRUNCATE, the table stays but is empty. After DROP, the table itself no longer exists.

Assignment Reset Commands

DROP TABLE EMP_XX CASCADE CONSTRAINTS;
DROP TABLE DEPT CASCADE CONSTRAINTS;
DROP TABLE DUP_DEPT CASCADE CONSTRAINTS;
DROP TABLE MENU_ITEM CASCADE CONSTRAINTS;
DROP TABLE RESTAURANT CASCADE CONSTRAINTS;

Why CASCADE CONSTRAINTS?

Some tables depend on others through foreign keys — MENU_ITEM depends on RESTAURANT, and EMP_XX depends on DEPT. Without CASCADE CONSTRAINTS, Oracle blocks the deletion.

Table dropped.
(Repeated for each table.)

Total Schema Wipe

BEGIN
   FOR t IN (SELECT table_name FROM user_tables) LOOP
      EXECUTE IMMEDIATE
      'DROP TABLE ' || t.table_name ||
      ' CASCADE CONSTRAINTS';
   END LOOP;
END;
/

Why this exists

Deletes every table owned by your current Oracle account.

How it works

  • Reads all table names.
  • Picks one table.
  • Drops it.
  • Repeats until none remain.
