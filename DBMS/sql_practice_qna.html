Common query patterns — filtering, joins, aggregation, and ordering — with the question, the answer, and a line-by-line breakdown of why each clause is there.

01 African Cities

Q: Query the names of all cities where the CONTINENT is 'Africa'.

SELECT CITY.NAME
FROM CITY
JOIN COUNTRY ON CITY.COUNTRYCODE = COUNTRY.CODE
WHERE COUNTRY.CONTINENT = 'Africa';
  • SELECT CITY.NAME — retrieves only the NAME column from CITY.
  • FROM CITY — sets CITY as the starting table.
  • JOIN COUNTRY ON CITY.COUNTRYCODE = COUNTRY.CODE — links COUNTRY to CITY by matching country codes.
  • WHERE COUNTRY.CONTINENT = 'Africa' — keeps only rows where the continent is Africa.

02 Japanese Cities' Names

Q: Query the names of all the Japanese cities in the CITY table.

SELECT NAME
FROM CITY
WHERE COUNTRYCODE = 'JPN';
  • SELECT NAME — retrieves only the city names.
  • FROM CITY — specifies CITY as the data source.
  • WHERE COUNTRYCODE = 'JPN' — filters to rows with the Japanese country code.

03 Higher Than 75 Marks

Q: Query the Name of any student in STUDENTS who scored higher than 75 Marks. Order by the last three characters of each name; if names tie on those three characters, sort secondarily by ascending ID.

SELECT Name
FROM STUDENTS
WHERE Marks > 75
ORDER BY SUBSTR(Name, -3) ASC, ID ASC;
  • SELECT Name — retrieves only the Name column.
  • FROM STUDENTS — specifies STUDENTS as the data source.
  • WHERE Marks > 75 — filters out anyone scoring 75 or below.
  • ORDER BY SUBSTR(Name, -3) ASC — sorts by the last three characters of the name.
  • , ID ASC — secondary sort by ID when the last three characters tie.

04 Employee Names

Q: Print a list of employee names from the Employee table in alphabetical order.

SELECT name
FROM Employee
ORDER BY name;
  • SELECT name — retrieves the name column.
  • FROM Employee — specifies Employee as the data source.
  • ORDER BY name — sorts results alphabetically, ascending.

05 Revising Aggregations — Count Function

Q: Query a count of the number of cities in CITY having a Population larger than 100000.

SELECT COUNT(ID)
FROM CITY
WHERE POPULATION > 100000;
  • SELECT COUNT(ID) — counts the number of rows returned.
  • FROM CITY — specifies CITY as the data source.
  • WHERE POPULATION > 100000 — restricts the count to cities above that population.

06 Revising the Select Query I

Q: Query all columns for all American cities in the CITY table with populations larger than 100000.

SELECT *
FROM CITY
WHERE COUNTRYCODE = 'USA' AND POPULATION > 100000;
  • SELECT * — retrieves every column for matching rows.
  • FROM CITY — specifies CITY as the data source.
  • WHERE COUNTRYCODE = 'USA' — filters for American cities.
  • AND POPULATION > 100000 — adds the population condition.

07 Select All

Q: Query all columns (attributes) for every row in the CITY table.

SELECT *
FROM CITY;
  • SELECT * — returns all columns.
  • FROM CITY — pulls every row from CITY, no filter applied.

08 Select By ID

Q: Query all columns for a city in CITY with the ID 1661.

SELECT *
FROM CITY
WHERE ID = 1661;
  • SELECT * — retrieves all columns for the matching record.
  • FROM CITY — specifies CITY as the data source.
  • WHERE ID = 1661 — filters to the single row with that ID.

09 Weather Observation Station 1

Q: Query a list of CITY and STATE from the STATION table.

SELECT CITY, STATE

  • SELECT CITY, STATE — retrieves only these two columns.
  • FROM STATION — specifies STATION as the data source.

10 Weather Observation Station 3

Q: Query a list of CITY names from STATION for cities with an even ID number. Print results in any order, excluding duplicates.

SELECT DISTINCT CITY
FROM STATION
WHERE MOD(ID, 2) = 0;
  • SELECT DISTINCT CITY — retrieves city names, removing duplicates.
  • FROM STATION — specifies STATION as the data source.
  • WHERE MOD(ID, 2) = 0 — keeps only even-numbered IDs.
