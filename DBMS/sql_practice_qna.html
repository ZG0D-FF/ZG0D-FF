01 African Cities

Source: african-cities-English.pdf (p. 1)

Q: Given the CITY and COUNTRY tables, query the names of all cities where the CONTINENT is 'Africa'. Note: CITY.CountryCode and COUNTRY.Code are matching key columns.

SCHEMA:
• CITY (ID NUMBER, NAME VARCHAR2(17), COUNTRYCODE VARCHAR2(3), DISTRICT VARCHAR2(20), POPULATION NUMBER)
• COUNTRY (CODE VARCHAR2(3), NAME VARCHAR2(44), CONTINENT VARCHAR2(13), REGION VARCHAR2(25), SURFACEAREA NUMBER, INDEPYEAR VARCHAR2(5), POPULATION NUMBER, LIFEEXPECTANCY VARCHAR2(4), GNP NUMBER, GNPOLD VARCHAR2(9), LOCALNAME VARCHAR2(44), GOVERNMENTFORM VARCHAR2(44), HEADOFSTATE VARCHAR2(32), CAPITAL VARCHAR2(4), CODE2 VARCHAR2(2)) 
SELECT CITY.NAME
FROM CITY
JOIN COUNTRY ON CITY.COUNTRYCODE = COUNTRY.CODE
WHERE COUNTRY.CONTINENT = 'Africa';
  • SELECT CITY.NAME — retrieves only the NAME column from CITY.
  • FROM CITY — sets CITY as the starting table.
  • JOIN COUNTRY ON CITY.COUNTRYCODE = COUNTRY.CODE — links COUNTRY to CITY by matching country codes.
  • WHERE COUNTRY.CONTINENT = 'Africa' — keeps only rows where the continent is Africa.

03 Higher Than 75 Marks

Source: more-than-75-marks-English.pdf (p. 1)

Q: Query the Name of any student in STUDENTS who scored higher than 75 Marks. Order output by the last three characters of each name. Secondary sort by ascending ID.

SCHEMA: STUDENTS (ID Integer, Name String, Marks Integer)
SAMPLE INPUT: (1, 'Ashley', 81), (2, 'Samantha', 75), (4, 'Julia', 76), (3, 'Belvet', 84)
ORDERING VERIFICATION: Only Ashley, Julia, Belvet have Marks > 75. Slices: 'Ashley' → 'ley', 'Julia' → 'lia', 'Belvet' → 'vet'. Lexicographic sort: 'ley' < 'lia' < 'vet'. Output: Ashley, Julia, Belvet. 
SELECT NAME
FROM STUDENTS
WHERE MARKS > 75
ORDER BY SUBSTR(NAME, -3), ID ASC;
  • WHERE MARKS > 75 — strict inequality excludes boundary score 75.
  • SUBSTR(NAME, -3) — standard SQL negative-offset string extraction for terminal 3 characters.
  • ID ASC — deterministic secondary tie-breaker.

06 Revising the Select Query I

Source: revising-the-select-query-English.pdf (p. 1)

Q: Query all columns for all American cities in the CITY table with populations larger than 100000. CountryCode for America is USA.

SCHEMA: CITY (ID NUMBER, NAME VARCHAR2(17), COUNTRYCODE VARCHAR2(3), DISTRICT VARCHAR2(20), POPULATION NUMBER) 
SELECT *
FROM CITY
WHERE COUNTRYCODE = 'USA'
  AND POPULATION > 100000;
  • SELECT * — retrieves every column for matching rows.
  • FROM CITY — specifies CITY as data source.
  • WHERE COUNTRYCODE = 'USA' — filters for American cities.
  • AND POPULATION > 100000 — compound predicate enforcing population condition.

11 University Schema DDL & Multi-Table Relational Queries

Source: Assignment.pdf (p. 2, Q7) — Verified from Scanned University Coursework

Q: Create tables with necessary primary & foreign key constraints, then author SQL queries for student level, course enrollment, and faculty relationships.

1. DDL SPECIFICATION WITH CONSTRAINTS: 
CREATE TABLE Faculty (
    fid INT PRIMARY KEY,
    fname VARCHAR(50) NOT NULL,
    deptid INT
);

CREATE TABLE Class (
    name VARCHAR(50) PRIMARY KEY,
    meets_at VARCHAR(30),
    room VARCHAR(20),
    fid INT,
    FOREIGN KEY (fid) REFERENCES Faculty(fid) ON DELETE SET NULL
);

CREATE TABLE Student (
    snum INT PRIMARY KEY,
    sname VARCHAR(50) NOT NULL,
    major VARCHAR(30),
    level VARCHAR(10),
    age INT CHECK (age > 0)
);

CREATE TABLE Enrolled (
    snum INT,
    cname VARCHAR(50),
    PRIMARY KEY (snum, cname),
    FOREIGN KEY (snum) REFERENCES Student(snum) ON DELETE CASCADE,
    FOREIGN KEY (cname) REFERENCES Class(name) ON DELETE CASCADE
);

Sub-Query (i): Find names of all students belonging to level 'Junior' enrolled in a class taught by faculty 'XYZ':

SELECT S.sname
FROM Student S
JOIN Enrolled E ON S.snum = E.snum
JOIN Class C ON E.cname = C.name
JOIN Faculty F ON C.fid = F.fid
WHERE S.level = 'Junior'
  AND F.fname = 'XYZ';

Sub-Query (ii): Find age of oldest student who is also a History major:

SELECT MAX(age) AS max_history_age
FROM Student
WHERE major = 'History';

Sub-Query (iii): Find names of all classes that meet in room 'R1' OR have 5 or more students enrolled:

SELECT name
FROM Class
WHERE room = 'R1'
UNION
SELECT cname
FROM Enrolled
GROUP BY cname
HAVING COUNT(snum) >= 5;
