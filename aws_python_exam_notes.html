1. Cloud basics

AWS mid-sem. Highlighted = most likely exam answers.

  • Cloud = on-demand IT over the internet with pay-as-you-go pricing.
  • Trade CAPEX for OPEX: pay on demand without owning hardware.
  • Region = cluster of data centers (e.g. us-east-1). Most services are region-scoped.
  • Availability Zone (AZ) = one or more isolated data centers. 3 to 6 AZs per region, linked by low-latency network.
  • Edge location = 400+ points of presence that deliver content closer to users.
  • Choose a region by: compliance, proximity, available services, pricing.

One AZ fails, the other two keep running. That is high availability.
Exam trap: data transfer IN is free, data transfer OUT is paid. AUP (Acceptable Use Policy) prohibits illegal, harmful, or abusive workloads.

3. IAM: Identity and Access Management

IAM is a global service.

  • Root account: created by default. Use only for initial setup, never share it.
  • Users: one physical person = one AWS user. Groups: hold only users, not other groups.
  • Policies: JSON documents attached to users or groups. Follow least privilege.
  • Roles: let AWS services act on your behalf (EC2, Lambda, CloudFormation).
  • MFA = password you know + device you own. MFA protects accounts even if a password is stolen.

4. Amazon S3

Objects (files) live inside buckets.

  • Bucket name must be globally unique, but the bucket lives in one region.
  • Naming: 3 to 63 characters, no uppercase, no underscores.
  • Key = prefix + object name. There are no real folders.
  • Max object size 5 TB. Over 5 GB needs multi-part upload.
  • Durability is 11 nines (99.999999999%) for every class. Availability differs.

Question 14 / 50Tricky
class A:
    def greet(self): return "A"

class B(A):
    def greet(self): return "B"

class C(A):
    def greet(self): return "C"

class D(B, C):
    pass

print(D().greet())
  • ✓ B
  • B A
  • C C
  • D Error
Explanation — Method Resolution Order (MRO)

Think of class D(B, C) as a kid asking parents for help. Python forces the kid to ask the left parent first.

The search chain:

1. D — empty (pass), move up.
2. B (listed first) — has greet()! Returns "B". Stop.
3. C — never checked.
4. A — never checked.

If the code were class D(C, B), the output would be "C". Left-to-right priority.

You can verify: print(D.__mro__)

Question 19 / 50Tricky
values = [1, 2, 3, 4, 5]
result = [y := x**2 for x in values if x % 2 == 0]
print(result, y)
  • ✓ [4, 16] 16
  • B [4, 16] 4
  • C [4, 16] Error (y not defined)
  • D [1, 4, 9, 16, 25] 25
Explanation — Walrus Operator Scope Leak

Normal comprehension variables (like x) stay trapped inside the brackets and vanish. But the walrus operator := breaks that rule — it leaks the variable out into the enclosing scope.

• Filter: only even x pass → 2, 4.
• Step 1 (x=2): y := 4 — list gets 4, and y is permanently set to 4.
• Step 2 (x=4): y := 16 — list gets 16, and y is updated to 16.

After the comprehension closes, y survives with its last value: 16.

🎰 Analogy — Vegas Rule: Normal list comprehensions act like Las Vegas — what happens inside the brackets stays inside. The walrus operator breaks the Vegas rule and smuggles y out.

Default argument values are evaluated once, at the moment the function is defined — not when called.

Question 31 / 50Tricky
a = [1, 2, 3]
b = a[:]
print(a == b, a is b)
  • ✓ True False
  • B False True
  • C True True
  • D False False
Explanation — Photocopy vs. Original

a[:] is Python's "photocopy" command — scans everything inside and prints it onto a brand new, separate list.

1. == (Checks Contents): "Do both have the same numbers?" → Yes, both say [1,2,3]. → True

2. is (Checks Physical Memory): "Are they literally the same piece of paper?" → No, one is original, one is photocopy. → False

If the code were b = a (no [:]), Python just puts a second sticky note on the original — both == and is would be True.
