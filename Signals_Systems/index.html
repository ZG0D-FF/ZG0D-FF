Chapter 01

Classification of Signals & Systems

A signal is an information-bearing function of one or more independent variables. A system is a mathematical transformation or physical operator mapping an excitation input $x(t)$ (or $x[n]$) into an output response $y(t)$ (or $y[n]$): $y = \mathcal{T}\{x\}$.

1.1 Standard Continuous-Time & Discrete-Time Singularity Functions

Function Continuous-Time Formulation $x(t)$ Discrete-Time Formulation $x[n]$ Key Mathematical & Sifting Properties
Unit Impulse (Dirac / Kronecker) $\delta(t) = 0 \text{ for } t \neq 0, \quad \int_{-\infty}^{\infty} \delta(t)dt = 1$ $\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}$ Sifting Property: $\int_{-\infty}^\infty x(t)\delta(t - t_0)dt = x(t_0)$
Scaling: $\delta(at) = \frac{1}{|a|}\delta(t)$
Unit Step (Heaviside) $u(t) = \begin{cases} 1, & t \ge 0 \\ 0, & t < 0 \end{cases}$ $u[n] = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}$ $\delta(t) = \frac{du(t)}{dt} \quad \Longleftrightarrow \quad u(t) = \int_{-\infty}^t \delta(\tau)d\tau$
$\delta[n] = u[n] - u[n-1]$
Unit Ramp $r(t) = t \cdot u(t)$ $r[n] = n \cdot u[n]$ $r(t) = \int_{-\infty}^t u(\tau)d\tau, \quad u(t) = \frac{dr(t)}{dt}$
Unit Parabola $p(t) = \frac{t^2}{2}u(t)$ $p[n] = \frac{n(n+1)}{2}u[n]$ $p(t) = \int_{-\infty}^t r(\tau)d\tau, \quad r(t) = \frac{dp(t)}{dt}$

1.2 Energy vs. Power Signals & Parseval Metrics

A signal is classified based on its total energy $E$ and average power $P$ over infinite duration:

Continuous Energy: $E = \int_{-\infty}^\infty |x(t)|^2 dt \quad \Big( \text{Discrete: } E = \sum_{n=-\infty}^\infty |x[n]|^2 \Big)$
Continuous Average Power: $P = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 dt \quad \Big( \text{Periodic: } P = \frac{1}{T_0} \int_{0}^{T_0} |x(t)|^2 dt \Big)$
Classification Energy $E$ Boundary Power $P$ Boundary Representative Waveforms Time-Scaling & Shifting Behavior
Energy Signal $0 < E < \infty$ $P = 0$ Aperiodic decaying pulses: $e^{-at}u(t)$ ($a>0$), rectangular pulse $\text{rect}(t/T)$. $E[x(t - t_0)] = E[x(t)]$;
$E[x(at)] = \frac{1}{|a|} E[x(t)]$.
Power Signal $E = \infty$ $0 < P < \infty$ Periodic signals: $A\cos(\omega_0 t + \theta)$, complex exponentials $e^{j\omega_0 t}$, unit step $u(t)$ ($P = 0.5$). $P[A\cos(\omega_0 t)] = \frac{A^2}{2}$;
$P[x(t - t_0)] = P[x(t)]$; $P[x(at)] = P[x(t)]$.
Neither Energy nor Power (NENP) $E = \infty$ $P = \infty$ Growing signals: $r(t) = t \cdot u(t)$, $e^{at}u(t)$ ($a>0$), $t^2$. Non-integrable over infinite bounds without convergence factor.

1.3 System Classification Axioms

  • Linearity (Superposition): $\mathcal{T}\{a x_1(t) + b x_2(t)\} = a \mathcal{T}\{x_1(t)\} + b \mathcal{T}\{x_2(t)\}$. Requires Additivity ($\mathcal{T}\{x_1+x_2\} = y_1+y_2$) and Homogeneity ($\mathcal{T}\{c \cdot x\} = c \cdot y$). Must satisfy zero-input response $\mathcal{T}\{0\} = 0$.
  • Time-Invariance (Stationarity): If $x(t) \to y(t)$, then $x(t - t_0) \to y(t - t_0)$ for all $t_0$. Operators with explicit time dependencies ($t \cdot x(t)$) or time-scaling ($x(2t)$) are strictly Time-Variant.
  • Causality (Non-anticipative): The output $y(t_0)$ depends only on current and past input values $x(t)$ for $t \le t_0$. A system is strictly non-causal if $y(t_0)$ depends on $x(t)$ for $t > t_0$.
  • BIBO Stability (Bounded-Input Bounded-Output): If $|x(t)| \le M_x < \infty$ for all $t$, then $|y(t)| \le M_y < \infty$. For an LTI system, this requires absolute integrability of impulse response: $\int_{-\infty}^\infty |h(t)| dt < \infty$.
  • Memory (Static vs. Dynamic): A static (memoryless) system depends solely on the current input sample $x(t)$. A dynamic system stores past/future energy (capacitors, inductors, sample delays $z^{-1}$).
⚠️ Exam Trap: Linearity vs. Affine Offsets

A system governed by $y(t) = 2x(t) + 3$ is NOT linear. Test: If $x(t) = 0$, $y(t) = 3 \neq 0$. Scaling input by $k$ yields $y'(t) = 2kx(t) + 3 \neq k[2x(t) + 3] = 2kx(t) + 3k$. This is an affine system, failing the homogeneity axiom. It can be modeled as an incrementally linear system, but fails strict superposition.

Chapter 02

Continuous & Discrete LTI Systems & Convolution

A Linear Time-Invariant (LTI) system is completely and uniquely characterized by its response to a unit impulse, denoted by $h(t)$ in continuous time and $h[n]$ in discrete time. Any arbitrary input excitation can be decomposed into an infinite continuum of scaled, shifted impulses.

2.1 The Convolution Integral & Convolution Sum

Continuous-Time Convolution Integral: $$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau) h(t - \tau) d\tau = \int_{-\infty}^{\infty} h(\tau) x(t - \tau) d\tau$$ Discrete-Time Convolution Sum: $$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k] = \sum_{k=-\infty}^{\infty} h[k] x[n - k]$$

2.2 Algebraic Properties of the Convolution Operator

  • Commutative: $x(t) * h(t) = h(t) * x(t)$. (Input and system impulse response can be swapped without altering response).
  • Distributive (Parallel Interconnections): $x(t) * [h_1(t) + h_2(t)] = x(t) * h_1(t) + x(t) * h_2(t)$.
  • Associative (Cascade Interconnections): $x(t) * [h_1(t) * h_2(t)] = [x(t) * h_1(t)] * h_2(t)$. Total equivalent impulse response of two cascaded stages is $h_{eq}(t) = h_1(t) * h_2(t)$.
  • Identity Element: $x(t) * \delta(t) = x(t)$. Convolving with a shifted impulse shifts the signal: $x(t) * \delta(t - t_0) = x(t - t_0)$.
  • Shift Property: If $x_1(t) * x_2(t) = y(t)$, then $x_1(t - t_1) * x_2(t - t_2) = y(t - t_1 - t_2)$.
  • Differentiation Property: $\frac{d}{dt}[x(t) * h(t)] = \frac{dx(t)}{dt} * h(t) = x(t) * \frac{dh(t)}{dt}$.
  • Integration (Step Response): $s(t) = x(t) * u(t) = \int_{-\infty}^t h(\tau) d\tau \quad \Longleftrightarrow \quad h(t) = \frac{ds(t)}{dt}$.
💡 Mechanical & Intuitive Breakdown: The 4 Graphical Convolution Steps

Evaluating $y(t) = \int_{-\infty}^\infty x(\tau)h(t - \tau)d\tau$ mechanically follows 4 immutable geometric operations:

  1. Fold (Time-Reversal): Reflect $h(\tau)$ about the vertical axis to form $h(-\tau)$.
  2. Shift (Time-Displacement): Displace the folded function along the $\tau$-axis by $t$ to form $h(t - \tau) = h(-(\tau - t))$.
  3. Multiply: Take the point-by-point product of the stationary signal $x(\tau)$ and the moving window $h(t - \tau)$.
  4. Integrate: Compute the net area under the product curve over all overlap intervals $\tau \in (-\infty, \infty)$.

2.3 LTI System Stability & Causality Theorems

LTI System Property Continuous-Time Impulse Response Condition Discrete-Time Impulse Response Condition Transform-Domain Criterion
Causal $h(t) = 0 \quad \text{for all } t < 0$ $h[n] = 0 \quad \text{for all } n < 0$ ROC of $H(s)$ is a right-half plane $\text{Re}(s) > \sigma_{\max}$. ROC of $H(z)$ is exterior of circle $|z| > r_{\max}$.
BIBO Stable $\int_{-\infty}^\infty |h(t)| dt < \infty$ $\sum_{n=-\infty}^\infty |h[n]| < \infty$ ROC of $H(s)$ must enclose the imaginary axis $j\omega$. ROC of $H(z)$ must enclose the unit circle $|z| = 1$.
Causal & Stable $h(t) = 0 \text{ for } t < 0 \text{ and } \int_0^\infty |h(t)|dt < \infty$ $h[n] = 0 \text{ for } n < 0 \text{ and } \sum_0^\infty |h[n]| < \infty$ All poles of $H(s)$ strictly in Open Left Half-Plane ($\text{Re}(p_i) < 0$). All poles of $H(z)$ strictly inside Unit Circle ($|p_i| < 1$).
Chapter 03

Continuous-Time Fourier Series (CTFS)

Fourier Series represents any arbitrary periodic signal $x(t) = x(t + T_0)$ as a linear combination of harmonically related orthogonal basis functions (sinusoids or complex exponentials) with fundamental angular frequency $\omega_0 = \frac{2\pi}{T_0}$.

3.1 Exponential & Trigonometric Representations

Exponential Fourier Series (Compact Form): $$x(t) = \sum_{n=-\infty}^{\infty} C_n e^{j n \omega_0 t} \quad \text{where} \quad C_n = \frac{1}{T_0} \int_{T_0} x(t) e^{-j n \omega_0 t} dt$$ Trigonometric Fourier Series: $$x(t) = a_0 + \sum_{n=1}^{\infty} \Big[ a_n \cos(n \omega_0 t) + b_n \sin(n \omega_0 t) \Big]$$ $$a_0 = C_0 = \frac{1}{T_0}\int_{T_0} x(t) dt, \quad a_n = \frac{2}{T_0}\int_{T_0} x(t)\cos(n\omega_0 t)dt, \quad b_n = \frac{2}{T_0}\int_{T_0} x(t)\sin(n\omega_0 t)dt$$ Coefficient Bridge: $C_n = \frac{a_n - j b_n}{2}, \quad C_{-n} = C_n^* = \frac{a_n + j b_n}{2} \quad (\text{for real } x(t))$.

3.2 Waveform Symmetries & Spectral Harmonic Elimination

Exploiting waveform symmetry allows engineers to immediately set entire subsets of Fourier coefficients to zero without evaluating integrals.

Symmetry Type Mathematical Condition Trigonometric Coefficients Impact Exponential $C_n$ Property Harmonic Content
Even (Mirror) Symmetry $x(-t) = x(t)$ $b_n = 0$ (all sine terms vanish); $a_n = \frac{4}{T_0}\int_0^{T_0/2} x(t)\cos(n\omega_0 t)dt$ $C_n$ is purely real and even: $C_n = C_{-n} = \text{Re}(C_n)$ DC component + Cosine harmonics only.
Odd (Point) Symmetry $x(-t) = -x(t)$ $a_0 = 0$, $a_n = 0$ (all cosines vanish); $b_n = \frac{4}{T_0}\int_0^{T_0/2} x(t)\sin(n\omega_0 t)dt$ $C_n$ is purely imaginary and odd: $C_n = -C_{-n} = j\text{Im}(C_n)$ Zero DC + Sine harmonics only.
Half-Wave Symmetry (HWS) $x(t \pm \frac{T_0}{2}) = -x(t)$ $a_0 = 0$; all even harmonics vanish: $a_{2k} = 0, b_{2k} = 0$ $C_n = 0$ for all even integers $n = 0, \pm 2, \pm 4 \dots$ Odd harmonics only ($n = 1, 3, 5, \dots$).
Quarter-Wave Even $x(-t) = x(t)$ and HWS $b_n = 0$, $a_{\text{even}} = 0$; $a_n = \frac{8}{T_0}\int_0^{T_0/4} x(t)\cos(n\omega_0 t)dt$ $C_n$ purely real; non-zero only for odd $n$ Odd cosine harmonics only.
Quarter-Wave Odd $x(-t) = -x(t)$ and HWS $a_n = 0$, $b_{\text{even}} = 0$; $b_n = \frac{8}{T_0}\int_0^{T_0/4} x(t)\sin(n\omega_0 t)dt$ $C_n$ purely imaginary; non-zero only for odd $n$ Odd sine harmonics only.

3.3 Parseval's Power Theorem for Periodic Signals

Parseval's relation dictates conservation of energy/power between time and frequency domains. The total average power $P_{avg}$ in periodic signal $x(t)$ equals the sum of the average powers of all its individual harmonic components:

$$P_{avg} = \frac{1}{T_0} \int_{T_0} |x(t)|^2 dt = \sum_{n=-\infty}^{\infty} |C_n|^2 = a_0^2 + \sum_{n=1}^{\infty} \frac{a_n^2 + b_n^2}{2} = a_0^2 + \sum_{n=1}^\infty \frac{A_n^2}{2}$$ Where $A_n = \sqrt{a_n^2 + b_n^2} = 2|C_n|$ represents the peak amplitude of the $n$-th harmonic sinusoid.
💡 Dirichlet Conditions for Fourier Series Convergence

A periodic signal $x(t)$ can be represented by a Fourier series that converges to $x(t)$ at all points of continuity (and to the midpoint $\frac{x(t^+) + x(t^-)}{2}$ at jump discontinuities) if it satisfies the Dirichlet Conditions over one period $T_0$:

  1. $x(t)$ is absolutely integrable over the period: $\int_{T_0} |x(t)| dt < \infty$.
  2. $x(t)$ has a finite number of maxima and minima within any single period.
  3. $x(t)$ has a finite number of finite discontinuities within any single period (no infinite asymptotes).

Chapter 04

Continuous-Time Fourier Transform (CTFT)

By taking the limiting condition of the Fourier series as the fundamental period tends to infinity ($T_0 \to \infty$), the discrete line spectrum merges into a continuous spectral density function $X(\omega)$, extending frequency-domain analysis to aperiodic energy signals.

4.1 The CTFT Synthesis & Analysis Pair

Forward Fourier Transform (Analysis): $$X(\omega) = \mathcal{F}\{x(t)\} = \int_{-\infty}^{\infty} x(t) e^{-j \omega t} dt$$ Inverse Fourier Transform (Synthesis): $$x(t) = \mathcal{F}^{-1}\{X(\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(\omega) e^{j \omega t} d\omega$$

4.2 Canonical Fourier Transform Properties

Operational Property Time Domain $x(t)$ Frequency Domain $X(\omega)$ Physical Meaning / Engineering Utility
Linearity $a x_1(t) + b x_2(t)$ $a X_1(\omega) + b X_2(\omega)$ Superposition of frequency bands.
Time Shifting $x(t - t_0)$ $e^{-j \omega t_0} X(\omega)$ Linear phase delay without altering magnitude $|X(\omega)|$.
Frequency Shifting (Modulation) $e^{j \omega_0 t} x(t)$ $X(\omega - \omega_0)$ Heterodyne upconversion; basis of RF communication mixers.
Time Scaling $x(at)$ $\frac{1}{|a|} X\left(\frac{\omega}{a}\right)$ Reciprocal scaling: time compression $\implies$ spectral expansion.
Duality (Symmetry) $X(t)$ $2\pi x(-\omega)$ If $\text{rect}(t) \leftrightarrow \text{sinc}(\omega)$, then $\text{sinc}(t) \leftrightarrow \text{rect}(\omega)$.
Time Differentiation $\frac{d^n x(t)}{dt^n}$ $(j\omega)^n X(\omega)$ High-pass filtering effect; amplifies high frequencies.
Time Integration $\int_{-\infty}^t x(\tau) d\tau$ $\frac{X(\omega)}{j\omega} + \pi X(0)\delta(\omega)$ Low-pass filtering effect; accumulation adds DC impulse.
Convolution in Time $x_1(t) * x_2(t)$ $X_1(\omega) \cdot X_2(\omega)$ Converts differential/convolution equations into algebraic multiplication.
Multiplication in Time (Modulation) $x_1(t) \cdot x_2(t)$ $\frac{1}{2\pi} \Big[ X_1(\omega) * X_2(\omega) \Big]$ Windowing and amplitude modulation spectral convolution.

4.3 Parseval's Energy Theorem & Spectral Densities

The total energy $E$ contained in an aperiodic signal $x(t)$ can be integrated directly across its Energy Spectral Density (ESD) $\psi(\omega) = |X(\omega)|^2$:

$$E = \int_{-\infty}^{\infty} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |X(\omega)|^2 d\omega = \int_{-\infty}^{\infty} |X(f)|^2 df$$ Area Relations: $$X(0) = \int_{-\infty}^\infty x(t) dt \quad \Big( \text{Total area under time waveform equals DC spectral value} \Big)$$ $$x(0) = \frac{1}{2\pi} \int_{-\infty}^\infty X(\omega) d\omega \quad \Big( \text{Total area under frequency spectrum equals } 2\pi x(0) \Big)$$
⚠️ Exam Trap: Fourier Transform of the Unit Step Function $u(t)$

Because $u(t)$ is not absolutely integrable ($\int_0^\infty 1 dt = \infty$), treating it as $\lim_{a \to 0} e^{-at}u(t)$ without distribution theory yields $\frac{1}{j\omega}$, which is incorrect because it omits the DC energy. $$\mathcal{F}\{u(t)\} = \frac{1}{j\omega} + \pi \delta(\omega)$$ The term $\pi \delta(\omega)$ accounts for the infinite-duration DC component ($a_0 = 1/2$). Neglecting this impulse yields wrong answers when analyzing step responses of LTI integrators.

Chapter 05

The Sampling Theorem & Reconstruction Theory

The Nyquist-Shannon Sampling Theorem bridges the continuous physical domain and discrete computational domain, establishing the strict mathematical boundaries under which a continuous bandlimited signal can be perfectly reconstructed without loss of information.

5.1 Mathematical Formulation of Ideal Impulse Sampling

Ideal sampling of continuous signal $x(t)$ with a periodic Dirac impulse train $p(t) = \sum_{n=-\infty}^\infty \delta(t - n T_s)$ where $T_s$ is the sampling period ($f_s = 1/T_s$, $\omega_s = 2\pi/T_s$):

$$x_s(t) = x(t) \cdot \sum_{n=-\infty}^{\infty} \delta(t - n T_s) = \sum_{n=-\infty}^{\infty} x(n T_s) \delta(t - n T_s)$$ In the frequency domain, multiplication becomes convolution with $\mathcal{F}\{p(t)\} = \omega_s \sum_k \delta(\omega - k\omega_s)$: $$X_s(\omega) = \frac{1}{2\pi} \Big[ X(\omega) * \omega_s \sum_{k=-\infty}^\infty \delta(\omega - k\omega_s) \Big] = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(\omega - k \omega_s)$$ Sampling replicates the baseband spectrum $X(\omega)$ infinitely along the frequency axis at integer multiples of $\omega_s$, scaled by $1/T_s$.

5.2 The Nyquist Criterion & Aliasing Regimes

Sampling Regime Mathematical Condition Spectral Separation Reconstruction Feasibility & Physical Consequence
Oversampling $\omega_s > 2 \omega_m \quad (f_s > 2 f_m)$ Guard band exists: $(\omega_s - \omega_m) > \omega_m$ Exact reconstruction achievable. Relaxed practical analog anti-aliasing filter roll-off slopes.
Critical (Nyquist) Sampling $\omega_s = 2 \omega_m \quad (f_s = 2 f_m)$ Zero guard band: adjacent spectral replicas touch at $\omega = \pm \omega_m$ Exact theoretical recovery requires an impossible "brick-wall" ideal filter ($H_{LPF}(\omega) = T_s \text{ for } |\omega| \le \omega_m$).
Undersampling (Aliasing) $\omega_s < 2 \omega_m \quad (f_s < 2 f_m)$ Spectral overlap: adjacent replicas collide and fold into baseband Irreversible information destruction. High frequencies falsely disguise themselves as low frequencies ($f_{alias} = |f - k f_s|$).
💡 Whittaker-Shannon Sinc Interpolation Formula

Feeding the ideally sampled signal $x_s(t)$ into an ideal low-pass filter with frequency response $H(\omega) = T_s \cdot \text{rect}\left(\frac{\omega}{2\omega_c}\right)$ with cutoff $\omega_c = \omega_s/2$ achieves exact continuous time reconstruction: $$x(t) = x_s(t) * h(t) = \sum_{n=-\infty}^{\infty} x(n T_s) \cdot \text{sinc}\left( \frac{t - n T_s}{T_s} \right) = \sum_{n=-\infty}^\infty x(n T_s) \frac{\sin\left(\frac{\pi(t - nT_s)}{T_s}\right)}{\frac{\pi(t - nT_s)}{T_s}}$$ Each discrete sample acts as the weight of an orthogonal $\text{sinc}$ basis function centered at that instant.

⚠️ Exam Shortcut: Nyquist Rates for Arithmetic Signal Combinations

Let $x_1(t)$ have max frequency $f_1$ and $x_2(t)$ have max frequency $f_2$.

  • Sum: $y(t) = x_1(t) + x_2(t) \implies f_{m} = \max(f_1, f_2) \implies f_s = 2 \max(f_1, f_2)$.
  • Product: $y(t) = x_1(t) \cdot x_2(t) \implies Y(\omega) = \frac{1}{2\pi}[X_1 * X_2] \implies f_{m} = f_1 + f_2 \implies f_s = 2(f_1 + f_2)$.
  • Convolution: $y(t) = x_1(t) * x_2(t) \implies Y(\omega) = X_1(\omega)X_2(\omega) \implies f_{m} = \min(f_1, f_2) \implies f_s = 2 \min(f_1, f_2)$.
  • Power Operations: $y(t) = x_1^n(t) \implies f_m = n \cdot f_1 \implies f_s = 2n \cdot f_1$.
  • Sinc Functions: $x(t) = \text{sinc}(a t) = \frac{\sin(\pi a t)}{\pi a t} \implies f_m = \frac{a}{2} \implies f_s = a\text{ Hz}$. For $\text{sinc}^2(a t) \implies f_m = a \implies f_s = 2a\text{ Hz}$.

Chapter 06

Laplace Transform, Z-Transform & ROC Dynamics

The Laplace and Z-Transforms generalize Fourier analysis by introducing real damping factors ($\sigma$ and $r$), allowing rigorous mathematical treatment of unstable systems, transient responses, and differential/difference equations with non-zero initial boundary conditions.

6.1 Definitions & Convergence Mechanics

Bilateral Laplace Transform: $$X(s) = \mathcal{L}\{x(t)\} = \int_{-\infty}^{\infty} x(t) e^{-s t} dt \quad \text{where } s = \sigma + j\omega$$ $$X(s) = \mathcal{F}\{x(t) e^{-\sigma t}\} \implies \text{Fourier transform with exponential decay envelope } e^{-\sigma t}$$ Bilateral Z-Transform: $$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n] z^{-n} \quad \text{where } z = r e^{j\omega}$$ $$X(z) = \mathcal{F}\{x[n] r^{-n}\} \implies \text{DTFT scaled by radial factor } r^{-n}$$ Mapping Relation: $z = e^{s T_s} = e^{(\sigma + j\omega) T_s} = e^{\sigma T_s} e^{j\omega T_s}$.
• Imaginary axis in $s$-plane ($\sigma = 0$) maps directly to the Unit Circle in $z$-plane ($|z| = 1$).
• Left Half of $s$-plane ($\sigma < 0$) maps to the Interior of Unit Circle ($|z| < 1$).
• Right Half of $s$-plane ($\sigma > 0$) maps to the Exterior of Unit Circle ($|z| > 1$).

6.2 Region of Convergence (ROC) Core Properties

The algebraic expression of $X(s)$ or $X(z)$ does not uniquely define a time-domain signal without specifying its Region of Convergence (ROC).

Time Domain Signal Nature Laplace Transform ROC Shape ($s$-plane) Z-Transform ROC Shape ($z$-plane) Poles Boundary Rule
Right-Sided (Causal: $t \ge 0$, $n \ge 0$) Right-Half Plane strip: $\text{Re}(s) > \sigma_{\max}$ Exterior of a circle: $|z| > r_{\max}$ ROC extends outward from the rightmost / outermost pole to infinity.
Left-Sided (Anti-causal: $t \le 0$, $n \le 0$) Left-Half Plane strip: $\text{Re}(s) < \sigma_{\min}$ Interior of a circle: $|z| < r_{\min}$ ROC extends inward from the leftmost / innermost pole to zero.
Two-Sided (Non-causal) Vertical strip: $\sigma_1 < \text{Re}(s) < \sigma_2$ Annular ring: $r_1 < |z| < r_2$ ROC is bounded by two poles; contains zero poles.
Finite Duration Entire $s$-plane Entire $z$-plane except possibly $z=0$ or $z=\infty$ Contains no poles in finite complex plane.

6.3 Initial and Final Value Theorems

Theorem Continuous-Time Formulation (Laplace) Discrete-Time Formulation (Z-Transform) Strict Validity Condition
Initial Value Theorem (IVT) $x(0^+) = \lim_{s \to \infty} s X(s)$ $x[0] = \lim_{z \to \infty} X(z)$ Signal must be strictly causal ($x(t) = 0$ for $t < 0$) with no impulses at origin.
Final Value Theorem (FVT) $\lim_{t \to \infty} x(t) = \lim_{s \to 0} s X(s)$ $\lim_{n \to \infty} x[n] = \lim_{z \to 1} (z - 1) X(z)$ Critical: The limit must exist! All poles of $sX(s)$ must lie strictly in the open left-half $s$-plane (or inside unit circle for $(z-1)X(z)$).
⚠️ Exam Trap: False Application of Final Value Theorem

Consider the oscillator signal $x(t) = \sin(\omega_0 t)u(t) \leftrightarrow X(s) = \frac{\omega_0}{s^2 + \omega_0^2}$. Blindly applying the FVT formula yields: $$\lim_{s \to 0} s X(s) = \lim_{s \to 0} \frac{s \omega_0}{s^2 + \omega_0^2} = 0 \quad \text{(COMPLETELY FALSE)}$$ In reality, $\lim_{t \to \infty} \sin(\omega_0 t)$ does not exist; it oscillates eternally between $-1$ and $+1$. The FVT fails because $s X(s)$ has poles at $s = \pm j\omega_0$ on the imaginary axis, violating the stability precondition.
