1 · Error control coding

Exam answer

Error control coding adds structured redundancy so a receiver can detect and often correct channel errors. Code rate \(R=k/n\); lower rate means more protection and less throughput. A code with minimum Hamming distance \(d_{min}\) detects up to \(d_{min}-1\) errors and corrects up to \(\lfloor (d_{min}-1)/2\rfloor\).

Hamming distance

Count the positions where two equal-length words differ. 10110 vs 10011 differ in positions 3 and 5, so \(d=2\). \(d_{min}\) is the smallest distance over all pairs of distinct codewords.

Each corner is a 3-bit word and each edge flips one bit. Highlighted: 000 and 111, the two codewords of the repetition code, at distance 3.

With codewords 000 and 111, a received 001 is distance 1 from 000 and 2 from 111, so it decodes to 000.

\(d_{min}\)234567
Detect123456
Correct011223

Detection needs only that no valid word is reached; correction needs the received word to be strictly closer to the sent word than to any other, hence the division by 2.

2 · Cyclic codes

Exam answer

A cyclic code is a linear block code in which every cyclic shift of a codeword is a codeword. It is generated by \(g(x)\) of degree \(n-k\) that divides \(x^n-1\). Encoding: \(c(x)=m(x)g(x)\), or \(c=mG\) with \(G\) a \(k\times n\) matrix of shifted copies of \(g\).

GF(2) arithmetic

Coefficients are 0 or 1, addition is XOR (\(1+1=0\)), subtraction equals addition, so equal powers cancel: \(x^3+x^3=0\). Squaring simply doubles exponents: \((a+b)^2=a^2+b^2\).

Generator matrix, (7,4) with \(g(x)=x^3+x+1\)

Coefficients low to high: \([1,1,0,1]\). Degree \(3=n-k=7-4\). Put them in row 1 and shift right once per row, \(k=4\) rows:

\[G=\begin{bmatrix}1&1&0&1&0&0&0\\0&1&1&0&1&0&0\\0&0&1&1&0&1&0\\0&0&0&1&1&0&1\end{bmatrix}\]
Encode m = 1011 (Q9)

Low to high, \(m=[1\,1\,0\,1]\), so XOR rows 1, 2 and 4:

\[1101000\oplus0110100\oplus0001101=1010001\ \text{(low→high)}\]

Reversed to highest degree first: 1000101. Check by polynomials: \((x^3+x+1)^2=x^6+x^2+1\).

Systematic form

Row-reduce with XOR until \(G=[I_k\,|\,P]\). Same code, but the message bits appear unchanged in the codeword, followed by parity.

Notes example: \(g(x)=x^4-1\), \(n=4\)

In GF(2) this is \(x^4+1\), degree 4, so \(k=n-\deg g=0\). A (4,0) code holds only the zero word and needs zero rows. Do not reproduce the 4×4 matrix as an answer. Method to write instead: coefficients of \(g\), degree, \(k=n-\deg g\), \(k\) shifted rows, check \(g\mid x^n-1\).

3 · BCH codes

Exam answer

BCH codes are cyclic codes designed to correct a chosen \(t\) errors. For any \(m,t\): \(n=2^m-1\), at most \(mt\) parity bits. \(g(x)\) is the LCM of the minimal polynomials of \(\alpha,\alpha^2,\dots,\alpha^{2t}\) over GF(\(2^m\)). Hamming codes are the \(t=1\) case.

Systematic encoding: \(c(x)=m(x)x^{n-k}+\big[m(x)x^{n-k}\bmod g(x)\big]\), so \(c(x)\) is divisible by \(g(x)\).

Worked example: M = 1111011, g(x) = x⁸+x⁷+x⁶+x⁴+1

\(m(x)=x^6+x^5+x^4+x^3+x+1\). \(\deg g=8\), so \(n-k=8\) and \(k=7\), \(n=15\). Divisor bits \(x^8\dots x^0\): 111010001. Dividend: 111101100000000.

5 · Cryptography

Exam answer

A one-way hash maps any-length input to a fixed-length digest. Pre-image resistance: given \(h\), infeasible to find \(m\) with \(H(m)=h\). Second pre-image resistance: given \(m_1\), infeasible to find \(m_2\ne m_1\) with the same hash. Collision resistance: infeasible to find any \(m_1\ne m_2\) with \(H(m_1)=H(m_2)\).

RSA

Pick primes \(p,q\); \(n=pq\); \(\varphi(n)=(p-1)(q-1)\); choose \(e\) with \(\gcd(e,\varphi)=1\); \(d\equiv e^{-1}\pmod{\varphi}\). Public \((e,n)\), private \((d,n)\). \(C=M^e\bmod n\), \(M=C^d\bmod n\).

Example: \(p=3,q=11\): \(n=33,\varphi=20\), \(e=7\), \(d=3\) since \(21\equiv1\). \(M=2\): \(C=2^7\bmod33=128-99=29\); \(29^3=24389=33\cdot739+2\), so \(M=2\). ✓

7 · BCH in depth

Extra material for section 3: where the parameters come from, and why the encoding method works.

Exam answer

BCH stands for Bose–Chaudhuri–Hocquenghem. It lets the designer choose the number of correctable errors \(t\) first and then builds a cyclic code guaranteeing \(d_{min}\ge 2t+1\). Hamming codes are the \(t=1\) case.

From \(t\) to minimum distance

Correcting \(t\) errors requires \(t=\lfloor (d_{min}-1)/2\rfloor\), which gives

\[d_{min}\ge 2t+1\]
Correct1 error2 errors3 errors4 errors
\(d_{min}\) at least3579

Parameters

SymbolMeaning
\(m\)Integer that fixes the length: \(n=2^m-1\)
\(t\)Designed number of correctable errors
\(n-k\)Parity bits, at most \(mt\)

Example: \(m=4\) gives \(n=15\). With \(t=2\), parity is at most \(4\times2=8\), so \(k=15-8=7\) and the code is \((15,7)\), the one in the worked example above. Its \(d_{min}\) is 5, so \(t=2\).

Where \(g(x)\) comes from

These are construction ideas, not something to compute in the exam numerical.

TermMeaning
\(GF(2^m)\)An extended field with \(2^m\) elements, used only while building the code. It is not the alphabet of the transmitted bits.
Primitive element \(\alpha\)An element whose powers \(\alpha^1,\dots,\alpha^{2^m-1}\) run through every non-zero element of the field, then return to 1.
Minimal polynomialThe lowest-degree polynomial with coefficients in GF(2) that has a given field element as a root.
LCMLeast common multiple, taken over polynomials instead of numbers.

\(g(x)\) is the LCM of the minimal polynomials of \(\alpha,\alpha^2,\dots,\alpha^{2t}\). For \(t=2\) that is four consecutive powers. Those roots are what guarantee the distance.

What remains, 11001, has degree 4, below 8, so the division stops. Padded to 8 bits: \(r(x)=\) 00011001. Codeword: 111101100011001.

Why appending the remainder works

Division gives \(m(x)x^8=q(x)g(x)+r(x)\). Then

\[c(x)=m(x)x^8+r(x)=q(x)g(x)+r(x)+r(x)=q(x)g(x)\]

because \(r(x)+r(x)=0\) in GF(2). The codeword is an exact multiple of \(g(x)\), which is the defining property of a valid codeword.

8 · Convolutional codes in depth

Complete mechanics of convolutional encoders: shift registers, state spaces, 8-transition FSM, Trellis lattice, tail-bit termination physics, and full numerical verification.

Exam summary

Unlike block codes (cyclic, BCH) that map isolated blocks \(m \to c\), a convolutional encoder processes a continuous bit stream \(u_n\) with internal memory stages. Output bits depend on both the current bit and previous bits stored in flip-flops. Code rate \(R=k/n\), constraint length \(K=m+1\) (bits influencing each output cycle), and state count \(=2^m\) with state vector \(\mathbf{s}=(s_{n-1}, s_{n-2})\). Transitions update as \(\text{Next state}=(u_n, s_{n-1})\). Terminating the sequence requires \(m\) flush zeros to force the encoder back to state \(00\), fixing boundary conditions for Viterbi decoding.

8.1 Continuous stream processing vs block codes

Block codes partition information into disjoint blocks of \(k\) bits and encode each block independently without remembering preceding inputs. A convolutional encoder treats information as a continuous sequence, updating an internal history across successive clock cycles.

FeatureBlock codes (Cyclic / BCH)Convolutional codes
Input processingFixed-size blocks of \(k\) bitsContinuous serial stream of bits
MemoryMemoryless between blocksShift register stores \(m\) past inputs
Codeword structure\(n\) bits per independent block\(n\) parity bits generated per \(k\) input bits
Decoding approachSyndrome calculation / algebraic rootsTrellis maximum-likelihood (Viterbi)

8.2 Shift register mechanics & delay operator \(D\)

Memory is implemented using a tapped shift register of flip-flops. The delay operator \(D\) represents a latency of one bit interval (\(z^{-1}\)), and \(D^2\) represents two bit intervals. On each clock tick, input \(u_n\) enters the first stage, old \(s_{n-1}\) moves to the second stage \(s_{n-2}\), and the oldest bit leaves.

8.3 Constraint length \(K\), code rate \(R\) & algebraic state formulation

Code rate measures transmission efficiency:

\[R = \frac{k}{n}\]

For standard single-input encoders (\(k=1\)) yielding two output bits (\(n=2\)), \(R = 1/2\).

Constraint length \(K\) defines the total number of input bits that directly influence each output cycle:

\[\boxed{K = m + 1 = 1 + \text{number of memory elements}}\]

The \(+1\) accounts for the current input bit \(u_n\). When \(m=2\), the output is influenced by three bits: \(\{u_n, s_{n-1}, s_{n-2}\}\), so \(K = 3\).

With \(m\) memory elements, the encoder has \(2^m\) distinct internal states:

Memory elements \(m\)12345
Constraint length \(K\)23456
Internal states \(2^m\)2481632

Algebraically, the state update is expressed as a matrix transition over GF(2):

\[\mathbf{s}_{n+1} = \begin{bmatrix} s_n \\ s_{n-1} \end{bmatrix} = \begin{bmatrix} 0 & 0 \\ 1 & 0 \end{bmatrix} \begin{bmatrix} s_{n-1} \\ s_{n-2} \end{bmatrix} \oplus \begin{bmatrix} 1 \\ 0 \end{bmatrix} u_n\]

8.8 Flush bits & termination physics

After encoding message 1011, the encoder sits in state 11. Appending \(m=2\) zeros forces the shift register to empty:

\[11 \xrightarrow{\text{input } 0} 01 \xrightarrow{\text{input } 0} 00\]

Why required: In Viterbi decoding, the decoder determines the most likely transmitted path by comparing survivor metrics at the final time step. Terminating at a known state (conventionally \(00\)) eliminates ambiguity: the decoder needs to compare metrics only for paths ending at \(00\), improving error performance.

Rate overhead: Appending \(m\) flush zeros expands an \(L\)-bit message to \(L+m\) bits, slightly reducing the effective code rate:

\[R_{\text{eff}} = \frac{L}{n(L + m)} = \frac{4}{2(4 + 2)} = \frac{4}{12} = \frac{1}{3} \approx 0.333\]

For long packets (\(L \gg m\)), \(R_{\text{eff}} \to k/n = 1/2\).

9 · Cryptography (Hash & RSA) in depth

Complete foundations: one-way hash mechanics, pre-image & collision resistance, asymmetric RSA algebra, totient function derivations, and full step-by-step numerical verification.

Core exam summary

Cryptography ensures confidentiality, data integrity, and authenticity. A one-way hash function \(H(m)\) maps arbitrary-length messages to a fixed-length digest; it is characterized by pre-image resistance (cannot invert digest), second pre-image resistance (cannot find alternative input with equal hash), and collision resistance (cannot find any two inputs with identical hashes). RSA is an asymmetric cryptosystem based on the integer factorization problem: key generation chooses primes \(p,q\), computes modulus \(n=pq\) and totient \(\phi(n)=(p-1)(q-1)\), selects public exponent \(e\) coprime to \(\phi(n)\), and calculates private exponent \(d\equiv e^{-1}\pmod{\phi(n)}\). Encryption evaluates \(C=M^e\bmod n\) and decryption recovers \(M=C^d\bmod n\) via Euler's Totient Theorem.

9.1 The cryptographic paradigm & asymmetric security

Unlike error-control coding (which protects against stochastic channel noise), cryptography defends against intelligent adversarial manipulation. Classical symmetric cryptography relies on a single shared secret key for both encryption and decryption. Asymmetric (public-key) cryptography decouples this into two distinct keys:

Key typeAccessibilityPrimary functionMathematical role

9.2 One-way hash functions & the compression principle

A cryptographic hash function \(H\) is a deterministic mathematical mapping:

\[h = H(m)\]

It possesses two structural properties:

1. Arbitrary input length: Accepts inputs \(m \in \{0, 1\}^*\) ranging from a single character to gigabytes of data.

2. Fixed output length: Produces a digest \(h \in \{0, 1\}^L\) of predetermined bit-length \(L\) (e.g., 256 bits for SHA-256).

One-Wayness: Computing \(h\) from \(m\) is computationally trivial (low polynomial time \(\mathcal{O}(|m|)\)), but given only \(h\), discovering any valid pre-image \(m\) is computationally infeasible. Hashing is fundamentally distinct from encryption: there is no private decryption key that reverses a hash.

9.3 Security properties: Pre-image vs Collision resistance

The security of hash functions rests on three mathematically distinct resistance levels:

PropertyKnown to attackerAttacker's targetBrute-force complexity
Pre-image resistance (One-way)A specific hash digest \(h\)Find any message \(m\) such that \(H(m) = h\)\(\approx 2^L\) trials
Second pre-image resistance (Weak collision)A known message \(m_1\)Find \(m_2 \ne m_1\) such that \(H(m_2) = H(m_1)\)\(\approx 2^L\) trials
Collision resistance (Strong collision)Only the hash algorithm \(H\)Find any two distinct messages \(m_1 \ne m_2\) with \(H(m_1) = H(m_2)\)\(\approx 2^{L/2}\) trials (Birthday Paradox)
Exam memory rule

• Pre-image: Given digest, find input.

• Second pre-image: Given one input, find a twin input matching its hash.

• Collision: Find any matching pair from scratch (much easier due to the Birthday Bound \(\mathcal{O}(2^{L/2})\)).

9.6 RSA key generation: Six rigorous steps

Step 1: Choose two distinct prime numbers

\[p = 3, \quad q = 11\]

Step 2: Compute the modulus \(n\)

\[n = p \times q = 3 \times 11 = 33\]

The modulus \(n\) is shared across both public and private keys. All arithmetic operates within the integer residue ring \(\mathbb{Z}_n\), requiring plaintext messages to satisfy \(0 \le M < n\).

Step 3: Compute Euler's Totient Function \(\phi(n)\)

\[\phi(n) = (p - 1)(q - 1) = (3 - 1)(11 - 1) = 2 \times 10 = \mathbf{20}\]
Why \(\phi(n) = (p-1)(q-1)\)? (Derivation)

Euler's totient function \(\phi(n)\) counts integers in \(\{1, 2, \dots, n\}\) that are coprime to \(n\) (\(\gcd(k, n) = 1\)). Out of \(pq\) integers, multiples of \(p\) are \(\{p, 2p, \dots, qp\}\) (\(q\) multiples), and multiples of \(q\) are \(\{q, 2q, \dots, pq\}\) (\(p\) multiples). Only \(pq\) is counted twice. Therefore:

\[\phi(pq) = pq - p - q + 1 = (p - 1)(q - 1)\]

Step 4: Select public exponent \(e\)

Conditions: \(1 < e < \phi(n)\) and \(\gcd(e, \phi(n)) = 1\).

With \(\phi(n) = 20\), choose \(e = 7\). Factors of 7: \(\{1, 7\}\); factors of 20: \(\{1, 2, 4, 5, 10, 20\}\). \(\gcd(7, 20) = 1\). Valid!

Step 5: Compute private exponent \(d\) (Modular Inverse)

\[d \times e \equiv 1 \pmod{\phi(n)} \implies 7d \equiv 1 \pmod{20}\]

Step 6: Assemble key pairs

9.7 Step-by-step RSA encryption & decryption numerical

A. Encryption: Plaintext message \(M = 2\), Public key \((e, n) = (7, 33)\):

\[C = M^e \bmod n = 2^7 \bmod 33\] \[2^7 = 128 = 33 \times 3 + 29 \implies \boxed{C = 29}\]

B. Decryption: Ciphertext \(C = 29\), Private key \((d, n) = (3, 33)\):

\[M = C^d \bmod n = 29^3 \bmod 33\] \[29^3 = 24389 = 33 \times 739 + 2 \implies \boxed{M = 2}\]

The decrypted plaintext matches the original input message \(M=2\) exactly.

Figure 9.4: 3D RSA Modular Orbit (\(n = 33\)). Perspective 3D circular lattice representing residue classes modulo 33. The luminous trajectory traces encryption \(M = 2 \longrightarrow C = 29\) via \(e = 7\), followed by private-key decryption \(29 \longrightarrow 2\) via \(d = 3\).

Why RSA decryption works (Euler's Totient Theorem)

By construction, \(ed \equiv 1 \pmod{\phi(n)} \implies ed = 1 + k\phi(n)\). By Euler's Totient Theorem, for any \(M\) coprime to \(n\):

\[M^{\phi(n)} \equiv 1 \pmod n\]

Therefore:

\[M' = C^d \equiv (M^e)^d = M^{ed} = M^{1 + k\phi(n)} = M \cdot (M^{\phi(n)})^k \equiv M \cdot (1)^k \equiv M \pmod n\]

9.9 Examination practice problem Q8

Question: Why is pre-image resistance alone not enough for digital signatures?

Model exam solution

Pre-image resistance guarantees that given a hash \(h\), an adversary cannot recover the original message \(m\). However, in digital signatures, the signer signs the hash \(H(m_1)\) of a legitimate contract \(m_1\) (e.g., "Pay ₹100").

If the hash function lacks collision resistance, an attacker can discover two entirely different documents \(m_1 \ne m_2\) (where \(m_2\) is "Pay ₹900") that evaluate to the identical hash \(H(m_1) = H(m_2)\). The attacker tricks the victim into signing legitimate document \(m_1\), then attaches that valid signature to fraudulent document \(m_2\). Because \(H(m_1) = H(m_2)\), the cryptographic verification algorithm accepts the forged document as valid. Thus, collision resistance is strictly required.

10 · Error control coding fundamentals in depth

First-principles mechanics: noisy channel models, structured redundancy, code rate trade-offs, Hamming distance derivations, and nearest-codeword decision spheres.

Core exam summary

Error control coding introduces structured mathematical redundancy to protect data against noisy channel corruption. Defined by code rate \(R=k/n\), Hamming distance \(d(\mathbf{x},\mathbf{y})\) (number of differing positions), and minimum distance \(d_{\min}\). A linear block code detects up to \(d_{\min}-1\) errors and corrects up to \(t = \lfloor(d_{\min}-1)/2\rfloor\) errors via nearest-codeword decoding.

10.1 The physical communication channel failure model

Consider transmitting message 1011 across an imperfect physical channel (wireless RF link, optical fiber, or copper cable). Channel noise or thermal interference flips the third bit from 1 to 0:

\[\text{Transmitted: } 1011 \xrightarrow{\text{Channel Noise}} \text{Received: } 1001\]

Without redundancy, the receiver cannot know whether 1001 was the intended transmission or a corrupted sequence. Error control coding embeds structural rules that render corrupt patterns detectably invalid.

10.2 Structured redundancy & repetition code intuition

Redundancy represents intentional extra information. In a 3-bit repetition code, sending a single bit 1 transmits 111. If the channel corrupts one bit to yield 101, majority voting reliably restores 1.

10.3 Code rate \(R = k/n\) & bandwidth trade-off

Code rate quantifies transmission throughput efficiency:

\[\boxed{R = \frac{k}{n} = \frac{\text{Useful information bits}}{\text{Total transmitted bits}}}\]

For a message of \(k=4\) bits encoded with 4 parity bits into \(n=8\) bits, \(R = 4/8 = 1/2 = 0.5\). Each input bit generates two transmitted bits.

The Hamming distance \(d(\mathbf{x}, \mathbf{y})\) between two binary words of equal length is the count of bit positions where their symbols differ:

10.5 Minimum Hamming distance \(d_{\min}\) & nearest-codeword geometry

The minimum distance \(d_{\min}\) is the smallest Hamming distance between any pair of distinct valid codewords in code \(\mathcal{C}\):

\[d_{\min} = \min_{\mathbf{c}_i \ne \mathbf{c}_j} d(\mathbf{c}_i, \mathbf{c}_j)\]

For valid codewords 000 and 111, \(d_{\min}=3\). A received vector 001 has \(d(001, 000)=1\) and \(d(001, 111)=2\). Nearest-codeword decoding maps 001 to 000.

10.6 Detection vs correction mathematical limits

• Maximum detectable errors: \(\mathbf{d_{\min} - 1}\). A transmission requires at least \(d_{\min}\) bit inversions to transform one valid codeword into a different valid codeword. Any pattern of \(\le d_{\min}-1\) errors lands outside valid code space and is caught.

• Maximum correctable errors: \(\mathbf{t = \lfloor(d_{\min} - 1)/2\rfloor}\). To unambiguously correct errors, the Hamming spheres of radius \(t\) centered on valid codewords must not overlap: \(2t + 1 \le d_{\min}\).

11 · Cyclic codes in depth

Complete mechanical & algebraic breakdown: cyclic shift rotation, generator polynomial g(x), GF(2) arithmetic cancellation, step-by-step generator matrix construction, and systematic encoding.

Core exam summary

A cyclic code is a linear block code where every cyclic shift of a valid codeword is also a valid codeword. Characterized by generator polynomial \(g(x)\) of degree \(n-k\) dividing \(x^n-1\) over GF(2). Encoded via \(c(x)=m(x)g(x)\) or matrix equation \(\mathbf{c}=\mathbf{m}\mathbf{G}\). Systematic generator matrices take the partitioned form \(\mathbf{G}=[\mathbf{I}_k \mid \mathbf{P}]\), preserving plaintext bits directly in the codeword.

11.1 The physical cyclic shift property

A cyclic shift rotates bits end-around without dropping symbols. For codeword 10110, shifting right by 1 position wraps the trailing 0 to the front:

\[10110 \xrightarrow{\text{Cyclic right shift}} 01011\]

In a cyclic code, this rotated sequence is guaranteed to be a valid codeword belonging to the same code space.

Figure 11.1: 3D Cyclic Shift Rotor & Codeword Manifold. The 7 bit positions form a closed 3D circular rotor. Rotating the rotor continuously maps valid codewords onto valid cyclic shifts across the 3D subspace, physically illustrating \(x^n \equiv 1\).

11.2 Generator polynomial \(g(x)\) foundations

Binary polynomial coefficients map directly to bit strings. For \(g(x) = x^3 + x + 1\), explicit powers are:

\[g(x) = 1\cdot x^0 + 1\cdot x^1 + 0\cdot x^2 + 1\cdot x^3 \iff \text{Coefficients (low to high): } [1, 1, 0, 1]\]

• Degree: The highest power of \(x\) with non-zero coefficient: \(\deg(g) = n - k = \text{number of parity bits}\).

• Divisibility condition: \(g(x) \mid (x^n - 1)\). Because shifting by one position corresponds to polynomial multiplication by \(x\), wrapping position \(n\) back to position 0 requires \(x^n \equiv 1 \pmod{x^n-1}\). Exact divisibility guarantees all cyclic shifts stay inside the code.

11.3 GF(2) arithmetic & identical-power cancellation

Galois Field GF(2) uses binary symbols \(\{0, 1\}\) under modulo-2 arithmetic:

\[0 \oplus 0 = 0, \quad 0 \oplus 1 = 1, \quad 1 \oplus 0 = 1, \quad 1 \oplus 1 = 0\]

Subtraction is mathematically identical to addition: \(1 - 1 = 1 + 1 = 0\). Equal powers cancel completely:

\[x^3 + x^3 = 0, \quad x^4 + x^4 = 0, \quad (x^3 + x + 1) + (x^3 + x + 1) = 0\]

11.4 Step-by-step generator matrix construction

For a \((7,4)\) cyclic code with \(g(x) = x^3 + x + 1\) (\(k=4\) message rows, \(n=7\) columns), place coefficients in row 1 and shift right once per row:

\[\mathbf{G} = \begin{bmatrix} 1 & 1 & 0 & 1 & 0 & 0 & 0 \\ 0 & 1 & 1 & 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & 1 & 0 & 1 & 0 \\ 0 & 0 & 0 & 1 & 1 & 0 & 1 \end{bmatrix}\]

Encoding message \(m = 1011\) via \(\mathbf{c} = \mathbf{m}\mathbf{G}\):

Low-to-high message vector: \(\mathbf{m} = [1, 1, 0, 1]\). Select and XOR rows 1, 2, and 4:

\[\begin{array}{r@{\quad}l} & 1\,1\,0\,1\,0\,0\,0 \quad (\text{Row 1}) \\ \oplus & 0\,1\,1\,0\,1\,0\,0 \quad (\text{Row 2}) \\ \hline & 1\,0\,1\,1\,1\,0\,0 \\ \oplus & 0\,0\,0\,1\,1\,0\,1 \quad (\text{Row 4}) \\ \hline = & \mathbf{1\,0\,1\,0\,0\,0\,1} \quad (\text{Low-to-high}) \end{array}\]

Reversing to standard high-to-low degree representation yields codeword: 1000101 (Practice Question Q9 verified).

11.5 Systematic generator matrix \(\mathbf{G} = [\mathbf{I}_k \mid \mathbf{P}]\)

By performing elementary row operations (Gaussian elimination via XOR), \(\mathbf{G}\) can be reduced so the first \(k\) columns form identity matrix \(\mathbf{I}_k\). For message 1011, the systematic codeword takes the form 1011 | parity, leaving raw message bits directly accessible without decoding circuitry.

Exam alert: Notes flawed example \(g(x) = x^4 - 1, n=4\)

In GF(2), \(g(x) = x^4 + 1\) has degree 4. With \(n=4\), \(k = n - \deg(g) = 4 - 4 = 0\). A \((4,0)\) code carries zero information bits and contains only the trivial zero codeword. A \(4 \times 4\) generator matrix cannot exist for \(k=0\). Always state: \(\deg(g) = n-k \implies k = 0\), matrix has zero rows.
