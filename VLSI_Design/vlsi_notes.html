1.8.3 The Twin-Tub Process

Basic idea

Earlier, CMOS fabrication could use either a p-well or an n-well approach. The twin-tub process is basically an extension of these approaches. Instead of creating only one type of well, we start with a high-resistivity n-type substrate and create both:

  • an n-well
  • a p-well
Twin-tub = both n-well and p-well are created on the same substrate.

Why do this?

The main advantage is that the n-transistor and p-transistor can be optimized separately. This means we don't have to sacrifice the performance of one type of transistor just to obtain good performance from the other. The text specifically says this process allows us to:

  • preserve the performance of n-transistors
  • avoid compromising the performance of p-transistors
  • obtain better doping control
  • relax some manufacturing tolerances
  • improve the situation concerning latch-up
Twin-tub allows separate optimization of n- and p-transistors.

1.9 Thermal Aspects of Processing

Now the text shifts from how devices are fabricated to an important issue during fabrication: Temperature.

Different MOS technologies require different sequences of high-temperature processing. The text compares the thermal sequences of nMOS and CMOS processes in Figure 1.15.

Important example: CMOS p-well process

The CMOS p-well process requires a high-temperature p-well diffusion. The temperature mentioned is 1100–1250°C. The nMOS process does not have this particular requirement.

CMOS p-well → requires high-temperature p-well diffusion
nMOS → does not require this particular high-temperature diffusion

Why was nMOS historically important?

The text points out that nMOS circuits have simpler fabrication, easier fabrication, and high density per unit area. Because of these advantages, many earlier IC designs were fabricated using nMOS technology, and many of those designs remained in use. The text therefore expects nMOS and CMOS system designs to coexist for some time.

1.10 BiCMOS Technology

BiCMOS = Bipolar + CMOS

Problem with MOS transistors

MOS transistors have limited load-driving capability — limited current sourcing and sinking ability. Super-buffers can be made from MOS alone, but they don't always compare well with bipolar transistors.

Why are bipolar transistors useful?

Bipolar transistors generally provide higher gain, better noise characteristics, better high-frequency characteristics, and higher output drive capability. BiCMOS gates can therefore be an effective way of speeding up VLSI circuits.

Why not use BiCMOS everywhere?

For subsystems like ALU, ROM, register-file, or barrel shifter, using BiCMOS everywhere does not necessarily improve speed, because most gates don't need to drive large capacitive loads — no speed advantage results.

You cannot judge BiCMOS only by looking at individual logic gates. The whole functional entity must be considered.

CMOS vs Bipolar

CMOSBipolar
Low static power dissipationHigh power dissipation
High input impedance → low drive currentLow input impedance → high drive current
Scalable threshold voltageLow-voltage-swing logic
High noise margin—
High packing densityLow packing density
High delay sensitivity to load → fan-out limitationsLow delay sensitivity to load

Low Km, gm ∝ VinHigh Km, gm ∝ eVin; high fT at low currents

Key picture of CMOS: low static power + high input impedance + high packing density + good noise margin, but limited output drive and greater delay sensitivity to load.

Key picture of bipolar: higher power dissipation and lower packing density, but high output drive, lower load sensitivity, and high-frequency performance.

Why BiCMOS?

BiCMOS = use CMOS where CMOS is advantageous + use bipolar where bipolar is advantageous.

Cost: additional processing steps → increased fabrication complexity, higher cost, some loss of packing density.

How is a bipolar transistor added to CMOS?

During p-well and n-well CMOS fabrication, parasitic bipolar transistors are inadvertently formed. The idea is to deliberately fabricate a useful bipolar transistor by adding extra layers. For an npn bipolar transistor, standard n-well CMOS is extended by adding:

  1. an n⁺ subcollector
  2. a p⁺ base

Formation of the BiCMOS npn transistor

The npn transistor is formed inside an n-well. The p⁺ base region sits inside the n-well, forming the p-base of the bipolar transistor. The buried n⁺ subcollector (BCCD) is added to reduce the resistance of the n-well (collector), improving the bipolar transistor's quality/performance.

n-well → collector region  |  p⁺ base → base region  |  n⁺ regions → emitter/collector-related regions  |  buried n⁺ subcollector (BCCD) → reduces collector/n-well resistance

BiCMOS is not simply "better CMOS" — it is a trade-off designed to obtain particular advantages from both technologies.

Another advantage: Analog amplifiers

The text proposes using CMOS transistors for input circuitry (high input impedance) and bipolar transistors for the remaining stages and output drivers (stronger drive characteristics), exploiting the strengths of each within the same amplifier.

Possible mixture of technologies in a silicon system

  • CMOS → logic
  • BiCMOS → I/O and driver circuits
  • ECL → critical high-speed parts

1.11 Production of E-beam Masks

Traditionally, many masks were produced using optical techniques involving photolithography. As device dimensions shrink and it becomes desirable to process several different chip designs on one wafer, other techniques become useful — one is E-beam mask making (electron beam).

E-beam Mask Production — Basic Sequence

Step 1 — Starting material

A chrome-plated glass plate coated with an E-beam-sensitive resist.

Step 2 — Load mask data

The E-beam machine is loaded with the mask description data called MEBES.

Step 3 — Electron-beam exposure

Plates are loaded into the E-beam machine; the electron beam exposes the patterns specified by the customer's mask data.

Step 4 — Development

Plates are placed into a developer, revealing the patterns produced by the E-beam in the resist coating.

Step 5 — Bake and plasma de-scumming

A bake cycle followed by plasma de-scumming removes remaining resist residue.

Step 6 — Chrome etching

The chrome is etched; remaining E-beam resist is stripped, leaving the final mask with the required pattern.

Advantages of E-beam Masks

  1. Tighter layer-to-layer registration — different mask layers align more precisely
  2. Smaller feature sizes can be produced
E-beam masks → better registration + smaller features

Two E-beam Machine Approaches

Raster scanning

The electron beam scans all possible locations (compared to how a television display scans). A bit map controls whether the beam is ON (location exposed) or OFF (not exposed).

Vector scanning

The beam is directed only toward locations that need to be exposed.

Vector scanning is inherently faster, but the data handling is more complex.

⭐ Summary

Twin-tub: Both n-well and p-well are created → nMOS and pMOS can be separately optimized.

Thermal processing: Different technologies have different high-temperature sequences. Key example: CMOS p-well → 1100–1250°C p-well diffusion.

BiCMOS: CMOS + bipolar. CMOS gives low static power and high input impedance; bipolar gives high output drive and better high-frequency characteristics. BiCMOS combines both, at the cost of extra fabrication steps → higher cost + reduced packing density.

BiCMOS bipolar addition: Normal CMOS extended with buried n⁺ layer (BCCD) + deep n⁺ collector + p⁺ base.

E-beam masks: Used when smaller features and tighter layer-to-layer registration are required. Raster → scans all locations, bit map controls exposure. Vector → scans only locations to be exposed, faster but more complex data handling.
