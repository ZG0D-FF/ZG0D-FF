2.8 Pull-up / Pull-down Ratio — nMOS Inverter via Pass Transistors

Setup: Inverter 1 → pass transistor(s) → Inverter 2.

Problem: Does Inverter 2 still see a valid logic 1 after passing through the switch?

Voltage Loss

VC = VDD − Vtp

Even with many pass transistors in series, loss is only one Vtp — no static current means no extra drop.

Deriving the New Ratio

Equating outputs of both inverters (Vout1 = Vout2) yields:

Zpu2 / Zpd2 = (Zpu1 / Zpd1) × (VDD − Vt) / (VDD − Vtp − Vt)

Typical Values

Vt = 0.2 VDD    Vtp = 0.3 VDD    →    0.8 / 0.5 = 1.6×

Design Rules

SituationZpu : Zpd
Directly driven inverter4 : 1
Driven through pass transistor(s)8 : 1

EXAM TRAP Only Inverter 2 (the driven one) changes its ratio. Inverter 1 stays at 4:1.

2.9 Alternative Pull-Up Forms

1. Resistor

  • Simple circuit
  • ❌ Large silicon area
  • ❌ Wastes power

2. nMOS Depletion-mode

  • ✅ Better charging at start of transition (acts as low-R)
  • Switches when Vin > Vt
  • ❌ High static power (current from VDD to GND when input = 1)

3. nMOS Enhancement-mode

  • ❌ Output never reaches full VDD
  • ✅ Clocked VGG reduces power
  • VGG > VDD needs extra supply rail

4. CMOS (pMOS pull-up)

  • ✅ No static current at stable states
  • ✅ Full logic levels (0 to VDD)
  • ⚠ pMOS is slower than nMOS for equal dimensions

Symmetrical Switching Point

When βn = βp and Vtn = −Vtp:

Vin = 0.5 VDD

Why pMOS Must Be Wider

Wp/Lp ≈ 2.5 × Wn/Ln

Hole mobility is lower than electron mobility, so pMOS needs ≈2.5× the W/L ratio to match nMOS strength.

Mobility Correction

μ = μz(1 − φ(Vgs − Vt))    where φ ≈ 0.05

βn = βp is exact only near Vin = Vout = 0.5 VDD.
