🏛️ 1. Intel 8051 Hardware Architecture & Pinout

HARVARD ARCH

The 8051 is a Harvard-architecture microcontroller integrating an 8-bit ALU, 128 bytes on-chip scratchpad RAM, 4 KB ROM/Flash, 32 I/O lines across four 8-bit ports (P0–P3), two 16-bit timers (T0/T1), and a full-duplex UART.

Fig 1.2: 40-Pin DIP Color Pinout
Fig 1.3: 11.0592 MHz XTAL Circuit
Fig 1.4: Port 0 Demux via 74LS373
💡 Mechanical Insight: Port 0 Time-Division Multiplexing To conserve pin count on the 40-pin DIP package, Port 0 multiplexes the lower address byte ($A_0-A_7$) and data byte ($D_0-D_7$). During the first half of a machine cycle, ALE pulses HIGH, latching $A_0-A_7$ into the external 74LS373 latch. When ALE falls LOW, Port 0 switches bidirectional to float or drive the 8-bit data bus.

💾 2. Internal RAM Spaces, Register Banks & SFRs

128B RAM + SFR

The 128 bytes of internal data RAM ($00\text{H}-7F\text{H}$) are partitioned into 4 Register Banks ($00\text{H}-1F\text{H}$), 16 bytes of Bit-Addressable RAM ($20\text{H}-2F\text{H}$, bits $00\text{H}-7F\text{H}$), and 80 bytes of general-purpose scratchpad RAM ($30\text{H}-7F\text{H}$).

Verified Keil Assembly & Opcodes 100% Executable 
        ORG 8000H
        MOV A, #55H        ; 74 55 (2B, 1MC) ACC = 01010101b
        MOV R1, #10H       ; 79 10 (2B, 1MC) Outer loop = 16
LOOP2:  MOV R2, #70H       ; 7A 70 (2B, 1MC) Inner loop = 112
LOOP1:  CPL A              ; F4    (1B, 1MC) Toggle all 8 bits
        DJNZ R2, LOOP1     ; DA FD (2B, 2MC) Inner decr & loop
        DJNZ R1, LOOP2     ; D9 F9 (2B, 2MC) Outer decr & loop
        LJMP 03            ; 02 00 03 Return to kit monitor
        END
⚠️ Lab Trap 1: The Hexadecimal Count Error
In student record sheet Page 4, the student writes MOV R1, #10H and MOV R2, #70H intending to loop 700 times. However, in hexadecimal, $10\text{H} = 16_{10}$ and $70\text{H} = 112_{10}$. The loop executes $16 \times 112 = \mathbf{1792\text{ times}}$, not 700! For true 700 loops, load decimal counters #10 and #70 (which assemble to #0AH and #46H).
⚠️ Lab Trap 2: DJNZ Instruction Size
In the rough notes (`experiment_1_annotated.jpg`), the student labeled `DJNZ` as 3 bytes. In 8051 ISA, `DJNZ Rn, rel` is strictly a 2-byte instruction (`D8-DF` followed by relative signed offset).

PAGES 10 & 11 RECORD
AIM: Write an 8051 assembly program to add two 8-bit numbers (producing a carry) and store the lower sum and carry into two distinct external RAM locations (8020H and 8021H).
Student Handwritten Record (Pages 10–11) Docs 3.1 & 3.2 
Address  Mnemonics         Comments
8000     MOV A, #F1H       Copied F1H to accumulator
8002     MOV R0, #30H      Copied 30H to register R0
8004     MOV R1, #00H      Copied 00H to register R1
8006     ADD A, R0         Add R0 to accumulator
8007     JNC 800A          Jump if no carry to loop 1
8009     INC R1            Increment R1 by 1
800A     MOV DPTR, #8020H  DPTR holds ext RAM address
800D     MOVX @DPTR, A     Store sum at 8020H
800E     MOV A, R1         Load carry into A

Verified Keil Assembly & Opcodes 100% Executable 
        ORG 8000H
        MOV A, #0F1H       ; 74 F1 (Keil 0-prefix rule)
        MOV R0, #30H       ; 78 30 (2B, 1MC)
        MOV R1, #00H       ; 79 00 (2B, 1MC) Carry count = 0
        ADD A, R0          ; 28    (1B, 1MC) F1H+30H=121H (CY=1)
        JNC SKIP_CARRY     ; 50 01 (2B, 2MC) Jump if CY=0
        INC R1             ; 09    (1B, 1MC) R1 = 01H
SKIP_CARRY:
        MOV DPTR, #8020H   ; 90 80 20 (3B, 2MC) DPTR = 8020H
        MOVX @DPTR, A      ; F0    (1B, 2MC) Write 21H to 8020H
        MOV A, R1          ; E9    (1B, 1MC) A = 01H
        INC DPTR           ; A3    (1B, 2MC) DPTR = 8021H
        MOVX @DPTR, A      ; F0    (1B, 2MC) Write 01H to 8021H
        LJMP 03            ; 02 00 03 Return to monitor

; Student worksheet: 1208H + A56DH
Address  Mnemonics         Comments
8000H    MOV 40H, #08H     08H data copy to 40H
8003H    MOV 41H, #12H     12H data copy to 41H
8006H    MOV 42H, #6DH     6DH data copy to 42H
8009H    MOV 43H, #A5H     A5H data copy to 43H
800CH    MOV A, 40H        Load 08H into ACC
800EH    MOV R0, 42H       Buffer 6DH into R0
8010H    ADD A, R0         08H + 6DH = 75H
8011H    MOV 44H, A        Store lower sum at 44H

Official Syllabus: Series Addition via @R0 Doc 4.2 Algorithm 
        ORG 8000H
        MOV R2, #05H       ; Array length N = 5
        MOV R0, #50H       ; Pointer R0 = base RAM 50H
        CLR A              ; Running Sum = 00H
        MOV R3, #00H       ; Carry count = 00H
SUM_LOOP:
        ADD A, @R0         ; Add RAM[@R0] to ACC
        JNC SKIP_INC       ; If CY=0, skip carry
        INC R3             ; Increment carry counter
SKIP_INC:
        INC R0             ; Point to next element
        DJNZ R2, SUM_LOOP  ; Loop until R2 == 0
        MOV 60H, A         ; Save lower sum byte
        MOV 61H, R3        ; Save carry count byte
        LJMP 03            ; Return to monitor

🔬 Experiment 7: Multiplication of Two Numbers in 8051 (MUL AB)

PAGES 20–21 RECORD
AIM: Write a program to multiply two numbers using 8051 microcontroller kit (Operands: $20\text{H} \times 30\text{H} = 0600\text{H}$).
Student Handwritten Record (Pages 20–21) Docs 7.1 & 7.2 
Address  Mnemonics         Comments
8000     MOV A, #20H       Load 20H to A
8002     MOV R0, #30H      Load 30H to R0 (Student typo!)
8004     MUL A, R0         Multiply A by B (Student typo!)
8005     LJMP 03           Stop program

Page 21 Result:
Input: A = 20H, B = 30H → Output: 06H 00H (upper, lower)
Conclusion: "performed using MUL AB instruction"
Verified Keil Assembly & Opcodes 100% Executable 
        ORG 8000H
        MOV A, #20H        ; 74 20 (2B, 1MC) Multiplicand
        MOV B, #30H        ; 75 F0 30 (3B, 2MC) SFR 0F0H
        MUL AB             ; A4    (1B, 4MC) 20H * 30H = 0600H
                           ; Low byte (00H) in A, High byte (06H) in B
        MOV 60H, A         ; F5 60 (2B, 1MC) Store 00H in RAM 60H
        MOV 61H, B         ; 85 F0 61 (3B, 2MC) Store 06H in RAM 61H
        LJMP 03            ; 02 00 03 Return to monitor
        END
⚠️ Lab Trap: The "MUL A, R0" Fallacy
In the student's notebook table on Page 20, they wrote MOV R0, #30H and MUL A, R0. In 8051 hardware, instructions like MUL A, Rn do not exist! The multiplier is hardwired strictly to Accumulator and register B via MUL AB (`A4H`). Notice on Page 21, the student corrects this: "Multiplication ... performed using MUL AB instruction, the 16 bit product was obtained in Register A & B."

🔬 Experiment 10: Keil µVision Simulator Tool Workflow & Debugging Guide

IDE WORKFLOW
AIM: Master the end-to-end simulation cycle using Keil µVision5 IDE targeting Atmel AT89C51 / AT89S52.
Workflow Phase Keil Action Crucial Student Pitfall
1. Project Setup Project → New µVision Project → Select Microchip → AT89C51 When prompted "Copy STARTUP.A51?", click NO for pure assembly projects.
2. Source File File → New → Save as main.asm → Right click Source Group → Add Existing Always include the mandatory END directive on the last line, or Keil throws PREMATURE END OF FILE.
3. Hex Output Options for Target (Alt+F7) → Output → Check 'Create HEX File' Hex code will NOT generate unless this checkbox is explicitly ticked!
4. Debugging Ctrl+F5 to enter debug → F11 single-step → View Registers To watch RAM variables, enter D:0x50 into Memory window (typing plain 50H defaults to Code ROM C:0x50!).
