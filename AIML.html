Q13 · REGRESSION MATH
Linear vs. Logistic Regression
  • Linear Regression (Predicting a Number): Draws the perfect straight line through a scatterplot.
    Hypothesis: $h_\theta(x) = \theta_0 + \theta_1 x$
    Cost Function (MSE): $$J(\theta_0, \theta_1) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x_i) - y_i)^2$$

Q14 · SVM
Support Vector Machines (4 Key Terms)

SVM finds the optimal boundary to separate different classes of data, aiming for the absolute maximum breathing room between categories.

  • Hyperplane: The decision boundary separating the classes (a line in 2D, a flat plane in 3D).
  • Support Vectors: The critical data points that sit closest to the hyperplane. Moving them shifts the boundary; deleting other points does nothing.
  • Margin: The perpendicular distance between the support vectors of class A and class B. The goal of SVM is to maximize this margin.
  • The Kernel Trick: A mathematical function that maps non-linear data into a higher-dimensional space, allowing a flat hyperplane to slice between them.

Q10 · SEARCH ALGORITHMS
Robot Navigation — BFS vs DFS

Graph: S→(P, R) · P→(C, H) · R→(E) · E→(G) · C: dead end · H→(G)

▸ GRAPH REFERENCE
◈ BFS — BREADTH-FIRST SEARCH (Queue)
Level 0: Visit S
Level 1: Visit P, Visit R
Level 2: From P → visit C, H. From R → visit E
Level 3: From C → dead end. From H → visit G ✓
PATH: S → P → H → G
◈ DFS — DEPTH-FIRST SEARCH (Stack)
Start at S, go deep to P
From P, deep to C → Dead end
Backtrack to P → go to H
From H → reach G ✓
PATH: S → P → C → (back) → H → G
MEMORY EFFICIENT?
DFS wins. It only stores the current path on its stack. BFS must store every node at the current depth level — massive RAM usage in large graphs.
SHORTEST PATH?
BFS wins. In an unweighted graph, BFS guarantees the shortest path — it checks all paths of length 1, then 2, etc. DFS may find a long winding path first.
Q10.5 · HEURISTIC SEARCH
A* Search Algorithm (Graph Traversal)

Instead of blindly searching (BFS) or diving down dead ends (DFS), A* evaluates the "best" next move by combining known distance with an educated guess to the goal.

$$T(n) = g(n) + h(n)$$
$g(n)$ = Actual cost from start  ·  $h(n)$ = Heuristic (estimated cost to goal)

Exam Strategy: Always calculate $T(n)$ for all available branches at your current level, and physically move your pen to the node with the lowest $T(n)$ value.

  • Path S → A → C: Cost is $(1+5) + 1 = 7$
  • Path S → B → C: Cost is $(4+2) + 1 = 7$
  • Path S → A → D: Cost is $(1+12) + 0 = 13$

A search algorithm is a method used to explore possible solutions in a problem space to find the best or goal solution.

A state space is the set of all possible states (configurations) that a system can possibly be in.

  • Goal State: The desired solution.
  • Transitions: The available moves or actions between states.

Q4 · EFFICIENCY
Role of Heuristics in Search Algorithms

A heuristic is a rule, function, or "educated guess" that estimates how close a specific state is to the goal.

  • Speeds up the search process exponentially.
  • Reduces unnecessary exploration of dead-end paths.
  • Heavily used in informed algorithms like A* Search.
👉 Example: Using straight-line (Euclidean) distance on a map to guess the driving distance.
Q5 · SEARCH PARADIGMS
Local Search vs Classical Search
Local Search
  • Focuses only on the current state and its immediate neighbors.
  • No path tracking (doesn't care how it got there).
  • Used for pure optimization.
  • Example: Hill Climbing.
Classical Search
  • Explores full paths from the start.
  • Maintains a strict search tree in memory.
  • Cares about the journey and the destination.
  • Examples: BFS, DFS, A*.
Q6 · LOCAL SEARCH
Concept of Hill-Climbing Search

A greedy local search algorithm that:

  1. Starts from an initial random state.
  2. Moves to the neighbor with a better value (higher elevation).
  3. Stops completely when no immediate neighbor offers an improvement.
The Fatal Flaw (Problems): It easily gets stuck in Local Maxima (a small hill that isn't the true peak) or Plateaus (flat areas with no clear direction).
Q7 · OPTIMIZATION
Simulated Annealing Algorithm

Inspired by metallurgy (the cooling process of metals to strengthen them).

  • Starts with high randomness (high "temperature").
  • Gradually reduces randomness as time goes on.
  • Crucial feature: It can occasionally accept worse solutions early on to bounce out of traps.
Key Idea: Escapes local optima to find the true global optimum.
Q8 · EVOLUTIONARY ALGORITHMS
Genetic Algorithms in AI

Inspired by Charles Darwin's theory of natural selection.

1. Initialize: Create a random starting population.
2. Selection: Pick the "fittest" best individuals.
3. Crossover: Combine their "DNA" to make child solutions.
4. Mutation: Introduce random changes to maintain diversity.

Used for complex optimization, machine learning tuning, and heavy scheduling problems.

Q9 · PROBLEM FORMULATION
Constraint Satisfaction Problem (CSP)

A type of problem where variables must be assigned values that satisfy specific, rigid rules.

Three Core Components:

  • Variables: The things that need assigning (e.g., regions on a map).
  • Domains: The pool of possible values (e.g., Red, Green, Blue).
  • Constraints: The rules (e.g., "No two adjacent regions can have the same color").

👉 Classic Examples: Sudoku, Map Coloring.

Q10 · GAME THEORY
Adversarial Search

Used specifically when there is direct competition between agents acting against each other (Zero-Sum Games). The AI must plan for an opponent who is actively trying to ruin its plans.

  • Examples: Chess, Tic-Tac-Toe, Checkers.
  • Primary Techniques: Minimax Algorithm (assume the worst from the opponent) and Alpha-Beta Pruning (ignore moves that are already mathematically proven to be worse than a previously found move).

Q11 · GAME THEORY
Define the Minimax Algorithm & its Purpose

The Minimax algorithm is used in decision-making for two-player games.

  • MAX: One player tries to maximize the score.
  • MIN: The opponent tries to minimize the score.
Purpose: To consistently choose the best possible move under the assumption that the opponent is also playing optimally.

Definition: A technique where data is split into multiple parts to train and test the model multiple times.

Q39 · CLASSIFICATION LOGIC
Majority Classification Minimizes Absolute Error

At a decision tree leaf, we must assign one single class to all remaining data points. Given $p$ = positive examples and $n$ = negative examples:

◈ CASE 1: Predict Positive
If we label the leaf "Positive"...
Every negative example is classified wrong.
Error = $n$
◈ CASE 2: Predict Negative
If we label the leaf "Negative"...
Every positive example is classified wrong.
Error = $p$

To minimize total error, we must logically choose the class with the fewest errors.

If $p > n \rightarrow$ predict Positive (error = $n$)
If $n > p \rightarrow$ predict Negative (error = $p$)

Absolute Error = $\min(p, n)$

EVALUATION PARADOX

Leave-One-Out Cross-Validation (LOOCV)

Q43 · THE LOOCV PARADOX
Why does a Majority Classifier score 0% on a balanced dataset?

The Setup: You have a perfectly balanced dataset consisting of exactly 100 Positive and 100 Negative examples (200 total). You plan to use Leave-One-Out Cross-Validation (LOOCV) against a simple majority classifier.

The Mechanics:

In LOOCV, you train on 199 examples and test on the 1 left out. Because the dataset is exactly evenly split, removing just one example completely flips the majority in the training set to the opposite class of the test example.

◈ SCENARIO 1
Leave out a Positive example.
Training Set: 99 Positive, 100 Negative
Majority Class: Negative
Prediction: Negative (WRONG)
◈ SCENARIO 2
Leave out a Negative example.
Training Set: 100 Positive, 99 Negative
Majority Class: Positive
Prediction: Positive (WRONG)
THE CONCLUSION

In every single iteration, the training set will have a majority of the class opposite to the one being tested. Consequently, the simple majority classifier will be wrong 100% of the time, resulting in a score of exactly zero.

Sequential Decision List Learning

Q46 · RULE SELECTION PROTOCOL
The 3 Strict Rules for Selecting Tests

To build the decision list, the algorithm must iteratively evaluate tests to isolate pure subsets, adhering to these strict rules in order:

1. Smallest Tests First

Prefer single attributes over pairs of attributes. Always check size-1 tests before size-2, etc.

2. Greatest Coverage (Tie-Breaker #1)

If multiple tests have the exact same size, pick the one that correctly classifies the largest number of examples.

3. Lowest Index (Tie-Breaker #2)

If multiple tests have the same size AND cover the same number of examples, pick the one using the lower attribute index (e.g., prefer $A_1$ over $A_2$).

L1 vs L2 Loss Minimization (KNN)

Q51 · MINIMIZING L2 LOSS
Mathematical Proof for L2 Loss (The Mean)

We want to find the value $\hat{y}$ that minimizes the Sum of Squared Errors ($L_2$ loss). Let our dataset be $Y = \{y_1, y_2, ..., y_n\}$.

$$L_2(\hat{y}) = \sum_{i=1}^{n} (y_i - \hat{y})^2$$

To find the minimum, we take the derivative of the loss function with respect to $\hat{y}$ and set it to zero.

◈ STEP 1: Take the Derivative
Using the chain rule:
$$\frac{d}{d\hat{y}} L_2(\hat{y}) = \sum_{i=1}^{n} 2(y_i - \hat{y})(-1) \quad \Rightarrow \quad -2 \sum_{i=1}^{n} (y_i - \hat{y})$$
◈ STEP 2: Set Derivative to 0
$$-2 \sum_{i=1}^{n} (y_i - \hat{y}) = 0 \quad \xrightarrow{\text{Divide by -2}} \quad \sum_{i=1}^{n} (y_i - \hat{y}) = 0$$
◈ STEP 3: Solve for $\hat{y}$
Split the summation:
$$\sum_{i=1}^{n} y_i - \sum_{i=1}^{n} \hat{y} = 0$$
Since $\hat{y}$ is a constant, summing it $n$ times is just $n\hat{y}$:
$$n\hat{y} = \sum_{i=1}^{n} y_i \quad \Rightarrow \quad \hat{y} = \frac{1}{n} \sum_{i=1}^{n} y_i$$
Conclusion: This is the exact formula for the Arithmetic Mean. For the dataset $\{4, 6, 7, 7, 8, 11, 100\}$, this results in $143 / 7 \approx \mathbf{20.43}$.
Q51 · MINIMIZING L1 LOSS
Mathematical Proof for L1 Loss (The Median)

We want to find the value $\hat{y}$ that minimizes the Sum of Absolute Errors ($L_1$ loss).

$$L_1(\hat{y}) = \sum_{i=1}^{n} |y_i - \hat{y}|$$

Unlike squared errors, absolute value functions have a sharp corner (they are not differentiable at exactly $y_i = \hat{y}$). However, we can use the derivative everywhere else, defined by the sign function: $\text{sgn}(x) = 1$ if $x > 0$, and $-1$ if $x < 0$.

◈ STEP 1: Take the Derivative
$$\frac{d}{d\hat{y}} L_1(\hat{y}) = \sum_{i=1}^{n} -\text{sgn}(y_i - \hat{y})$$
◈ STEP 2: Set Derivative to 0
$$\sum_{i=1}^{n} \text{sgn}(y_i - \hat{y}) = 0$$
◈ STEP 3: Interpret the Result
For the sum of these signs to equal exactly zero, the number of $+1$s must perfectly cancel out the number of $-1$s.
In plain English: The number of data points greater than $\hat{y}$ must exactly equal the number of data points less than $\hat{y}$.
Conclusion: By definition, the value that has an equal number of data points above and below it is the Median. Sorting your data $\{4, 6, 7, \mathbf{7}, 8, 11, 100\}$, the value that balances the left and right sides is $\mathbf{7}$.

MODULE 1 & 2 · BASICS
What is Machine Learning & Its Types?

Machine Learning (ML) is a subset of AI that focuses on developing algorithms that enable computers to learn from data and make predictions without being explicitly programmed.

  • Supervised Learning: Data is labeled by humans. Categorized into Regression (continuous) and Classification (discrete).
  • Unsupervised Learning: Non-labeled data. System automatically detects patterns (e.g., Clustering).
  • Reinforcement Learning: An agent learns by interacting with an environment to maximize cumulative rewards through trial and error.
  • Dimensionality Reduction: PCA (Linear, gives global representation) and t-SNE (Non-linear, gives local representation).
MODULE 3 · REGRESSION
Linear, Polynomial & Logistic Regression
  • Linear Regression: Fits a straight line. Hypothesis: $h_\theta(x) = \theta_0 + \theta_1 x$.
    Cost Function (MSE): $$J(\theta_0, \theta_1) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x_i) - y_i)^2$$
  • Polynomial Regression: Models non-linear patterns using an $n$-th order polynomial (e.g., $y = \beta_0 + \beta_1 x + \beta_2 x^2$). Drawback: Higher orders cause overfitting.
  • Logistic Regression: A classification technique using a Sigmoid function: $y = \frac{1}{1 + e^{-z}}$. Separates data points using a Decision Boundary.
MODULE 3 · CLASSIFICATION
SVM, KNN & Decision Trees
  • Support Vector Machine (SVM): Finds the optimal hyperplane to separate classes, maximizing the margin between Support Vectors. Uses the Kernel Trick for non-linear data.
  • K-Nearest Neighbors (KNN): Classifies based on the majority class of its $k$ closest neighbors. Calculates distance using:
    Euclidean: $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
    Manhattan: $\sum |x_i - y_i|$
  • Decision Trees: Maps a tree-like structure (Internal nodes = tests, branches = values, leaves = decision). Relies on calculating Entropy and Information Gain (IG).
EVALUATION
Performance Metrics & Confusion Matrix

Confusion Matrix: A table (TP, TN, FP, FN) for evaluating classification performance.

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$
  • Precision: $\frac{TP}{TP + FP}$
  • Recall: $\frac{TP}{TP + FN}$
  • F1-Score: Harmonic mean of precision and recall ($2 \times \frac{P \times R}{P + R}$).
  • ROC Curve & AUC: Trade-off between True Positive Rate (TPR) and False Positive Rate (FPR).
  • Kappa Statistics: Measures agreement between classifiers for unbalanced data ($K = \frac{P_o - P_e}{1 - P_e}$).
DATA & TUNING
Pre-Processing, Game Theory & Clustering
  • Covariance & Orthogonality: Covariance measures relationships between variables; Orthogonality ensures features don't interfere with each other.
  • Outliers: Detected using IQR bounds: $Q1 - 1.5 \times IQR$ and $Q3 + 1.5 \times IQR$.
  • Hyperparameter Tuning: Optimizing external configuration parameters (e.g., learning rate) using Grid Search or Randomized Search.
  • K-Means Clustering: Partitions data into $k$-clusters by their centroids, minimizing variance within the cluster.
  • Game Theory (Min-Max): Max tries to maximize gain, Min minimizes it. Uses Alpha-Beta pruning for best move strategy.
PROBLEM 06 · K-MEANS CLUSTERING
Calculate Cluster Assignments (K=2)

The Concept: In unsupervised learning, K-Means groups non-labeled data by dropping $k$ "centroids" onto a graph, assigning points to the closest centroid, and shifting those centroids to minimize variance within the cluster.

GIVEN
5 Customers (Age, Amount Spent):
C1: (20, 50)  ·  C2: (40, 1000)  ·  C3: (30, 800)  ·  C4: (18, 300)  ·  C5: (35, 1400)

Task: Group the customers into $K=2$ clusters using Euclidean distance: $\sqrt{(x-x_1)^2 + (y-y_1)^2}$

STEP 1 — ASSIGN INITIAL CENTROIDS

Use the first two customers as the starting center points.

  • Centroid 1: C1 (20, 50)
  • Centroid 2: C2 (40, 1000)
STEP 2 — MEASURE & ASSIGN NEXT POINT (C3)

Calculate C3 (30, 800) distance to both centroids:

Distance to C1: $\sqrt{(30-20)^2 + (800-50)^2} = \sqrt{100 + 750^2} \approx 750$

Distance to C2: $\sqrt{(30-40)^2 + (800-1000)^2} = \sqrt{100 + (-200)^2} \approx 200$

Result: Since 200 < 750, C3 is closer to C2. C3 joins Cluster 2.

STEP 3 — UPDATE THE CENTROID

Cluster 2 gained a member, so its center of gravity shifts. Average the coordinates of C2 and C3:

$$New Centroid 2: (\frac{40+30}{2}, \frac{1000+800}{2}) = (35, 900)$$

STEP 4 — MEASURE & ASSIGN NEXT POINT (C4)

Calculate C4 (18, 300) distance to C1 and the new C2:

Distance to C1 (20, 50): $\sqrt{(18-20)^2 + (300-50)^2} \approx 250$

Distance to New C2 (35, 900): $\sqrt{(18-35)^2 + (300-900)^2} \approx 600$

Result: Since 250 < 600, C4 joins Cluster 1.

STEP 5 — UPDATE THE CENTROID AGAIN

Cluster 1 gained a member. Average C1 and C4:

$$New Centroid 1: (\frac{20+18}{2}, \frac{50+300}{2}) = (19, 175)$$

THE CORE LOGIC LOOP: Measure Distance $\rightarrow$ Assign to Closest $\rightarrow$ Average Coordinates $\rightarrow$ Repeat

PROBLEM 10 · DECISION TREES
Calculate Information Gain (IG)

The Concept: A Decision Tree calculates Information Gain to decide which feature splits the data best. The goal is to choose the split that removes the most "impurity" (Entropy) from the dataset.

GIVEN
12 Total Days: 7 "Yes" (Play), 5 "No" (Don't Play).
Splitting by "Weather":
- Sunny (5 days): 3 Yes, 2 No
- Cloudy (3 days): 1 Yes, 2 No
- Rainy (4 days): 3 Yes, 1 No

Task: Calculate Total Entropy, Branch Entropy, and finally the Information Gain for "Weather".

STEP 1 — TOTAL ENTROPY OF THE DATASET

Probability of Yes = 7/12. Probability of No = 5/12.

$$E_{total} = - \left( \frac{7}{12} \log_2 \frac{7}{12} \right) - \left( \frac{5}{12} \log_2 \frac{5}{12} \right) \approx 0.98$$

STEP 2 — ENTROPY OF THE "WEATHER" BRANCHES

Sunny (3 Yes, 2 No): $$E_{sunny} = - \left( \frac{3}{5} \log_2 \frac{3}{5} \right) - \left( \frac{2}{5} \log_2 \frac{2}{5} \right) \approx 0.97$$

Cloudy (1 Yes, 2 No): $$E_{cloudy} \approx 0.92$$

Rainy (3 Yes, 1 No): $$E_{rainy} \approx 0.81$$

STEP 3 — CALCULATE INFORMATION GAIN

Subtract the weighted average of the branch entropies from the Total Entropy:

$$IG = 0.98 - \left( \frac{5}{12} \times 0.97 \right) - \left( \frac{3}{12} \times 0.92 \right) - \left( \frac{4}{12} \times 0.81 \right)$$

$$IG = 0.98 - (0.404) - (0.23) - (0.27) \approx 0.08$$

✓   IG for Weather ≈ 0.08
Repeat for other features. The tree will pick the feature with the highest Information Gain to split the root node.

Decision List vs Decision Tree

Q55 · MATHEMATICAL PROOF (PART A)
Proof: Lists can represent Trees
Claim: A decision list can represent the exact same function as a decision tree using at most as many rules as there are leaves.

Proof Construction Idea:

  • Every leaf in a decision tree corresponds to exactly one unique path from the root.
  • That path is just a mathematical conjunction (AND) of conditions.
◈ THE CONVERSION ALGORITHM
  1. For each leaf, take the exact path from the root to that leaf.
  2. Convert it into a rule: IF (conditions along path) → leaf output.
  3. Add these rules in sequence to form a decision list.
  4. Add a final default ELSE rule if necessary to catch edge cases.

Why it works: Every input follows exactly one path in the tree. That path becomes one rule in the list. Therefore, the list checks rules in order and returns the exact same output. The number of rules $\le$ number of leaves. Hence proved. ✅

Q56 · COMPARATIVE EXAMPLE (PART B)
Fewer Rules than a Tree: $f(A, B) = A \text{ OR } B$
◈ DECISION TREE REPRESENTATION
       A
     /   \
   0       1
  /         \
 B           [1]
/ \
[0] [1]
  • (A=0, B=0) → 0
  • (A=0, B=1) → 1
  • (A=1, *) → 1
Total Leaves = 3
◈ DECISION LIST REPRESENTATION
IF A = 1 → 1
ELSE IF B = 1 → 1
ELSE → 0
  • Evaluates A first. If true, stops.
  • If false, evaluates B. If true, stops.
  • Avoids drawing redundant branches.
Total Rules = 2
👉 Observation: The decision list strictly uses fewer rules (2 < 3 leaves) because it avoids repeating similar conditions on redundant sub-branches.
⭐ EXAM CONCLUSION ⭐
The Compression Advantage

A decision list can dynamically simulate any decision tree by converting each root-to-leaf path into an isolated rule, mathematically ensuring at most the same number of rules as leaves. However, in heavily overlapping logic cases (like the OR function), decision lists become vastly more compact and require strictly fewer computational rules than the corresponding minimal decision tree.

Q38 · PARAMETER ESTIMATION
Parametric Estimation & MLE

Definition: Assume data follows a known distribution (e.g., Gaussian), then estimate its governing parameters ($\mu, \sigma^2$).

◈ MAXIMUM LIKELIHOOD ESTIMATION (MLE)

Choose the exact parameters that maximize the probability/likelihood of the observed data occurring.

$$\theta = \arg\max_\theta \; P(\text{Data} \mid \theta)$$
Example (Gaussian Distribution):

Given data $x_1, x_2, ..., x_n$, the MLE precisely estimates:

$$\mu = \frac{1}{n}\sum x_i$$
$$\sigma^2 = \frac{1}{n}\sum (x_i - \mu)^2$$
👉 These calculated values mathematically maximize the probability of observing your specific dataset.
Q39 · ADVANCED DENSITY
Kernel Density Estimation (KDE)

Concept: A smooth, non-parametric way to estimate probability density. It places a kernel (a mathematical "bump") at every single data point and sums them all together.

$$\hat{f}(x) = \frac{1}{nh} \sum K\left(\frac{x - x_i}{h}\right)$$

Where $K$ = kernel function, and $h$ = bandwidth.

1. The Kernel ($K$)
  • Common Types: Gaussian, Uniform, Epanechnikov.
  • Effect: Has a surprisingly minor effect.
  • Gaussian creates smooth curves, Uniform creates rough edges.
2. The Bandwidth ($h$)
  • Effect: The MOST important factor.
  • Small $h$: Too wiggly (Overfitting).
  • Large $h$: Too flat (Oversmoothing).
⭐ THE GOLDEN RULE ⭐
Kernel shape matters less; bandwidth exclusively controls the quality.

Q43 · ENSEMBLE LEARNING
How a Random Forest is Built
1. Bootstrap Sampling (Bagging)
  • Multiple random samples (with replacement) are created from the original dataset.
  • Each sample trains a separate tree (Bootstrap Aggregating).
  • 👉 Effect: Reduces variance and actively avoids overfitting.
2. Training Multiple Trees
  • A Decision Tree is trained independently for each bootstrap sample.
  • Trees are usually grown fully (deep trees) without pruning.
3. Random Feature Selection
  • At each split, instead of considering all features, only a random subset is used.
  • 👉 Effect: Makes the trees less correlated and improves overall ensemble performance.
4. Aggregation (Voting)
  • For Classification: Each tree votes for a class.
  • Final Output: Majority vote wins.
Q44 · HYPERPARAMETER TUNING
How Random Forest is Optimized

Optimization strictly focuses on tuning hyperparameters using methods like Grid Search or Random Search:

  • 1. Number of Trees (n_estimators)
    More trees → better performance. Too many → slower computation.
  • 2. Maximum Depth (max_depth)
    Deep trees → low bias, high variance. Shallow trees → higher bias.
  • 3. Features per Split (max_features)
    Small value → more randomness, less overfitting. Large value → stronger trees but more correlation.
  • 4. Min Samples per Split / Leaf
    Prevents individual trees from growing too complex (controls overfitting).
Key Advantages: Handles large datasets & high dimensions effortlessly. Highly robust to noise/overfitting. Automatically provides feature importance scores.
⭐ FINAL EXAM SUMMARY ⭐
The "Write This" Paragraph

A Random Forest classifier is built by training multiple decision trees on different bootstrap samples of the dataset, using random subsets of features at each split. The final prediction is made by majority voting. It is optimized by tuning parameters like number of trees, tree depth, and number of features using methods such as Grid Search and Random Search to carefully balance bias-variance and maximize performance.

The choice of metric fundamentally depends on the specific application and the relative importance of different types of errors.

MOD 4 — Support Vector Machine (Deep Dive)

Q49 · CORE CONCEPT
The Concept of SVM & Optimal Hyperplane

A Support Vector Machine is a supervised learning algorithm that separates data into classes using a Hyperplane (a line in 2D, a flat plane in 3D, and a hyperplane in higher dimensions).

👉 Key Idea: Maximum Separation

The goal is not just to separate the data, but to find the hyperplane that maximizes the margin (distance) between the two classes.

The Optimal Hyperplane
  • Maximizes the absolute distance from the nearest data points of both classes.
  • These critical, closest points are known as Support Vectors.
Why Maximum Margin?
  • A larger margin mathematically ensures better generalization.
  • Heavily reduces overfitting.
  • Makes the model highly robust to noise.
Q50 · SVM MATHEMATICS
Mathematical Form & Optimization Goal
◈ THE EQUATIONS

Hyperplane Equation:

$$w \cdot x + b = 0$$

Margin Maximization:

$$\text{Maximize Margin} = \frac{2}{\|w\|}$$
◈ THE OPTIMIZATION PROBLEM

To maximize $\frac{2}{\|w\|}$, we mathematically invert it to a minimization problem for computational ease:

Minimize:
$$\frac{1}{2}\|w\|^2$$
Subject to:
Correct classification constraints.
Q51 · ADVANCED DATA HANDLING
The Kernel Trick (Very Important)

Real-world data is extremely rarely linearly separable (you can't just draw a straight line through it).

👉 How it works:

The Kernel Trick maps data points into a higher-dimensional space where they do become linearly separable, and it does so mathematically without explicitly computing that heavy transformation (making it highly memory & compute efficient).

Common Kernels:
  • Linear Kernel: For natively linearly separable data.
  • Polynomial Kernel: Creates curved boundaries.
  • RBF (Gaussian) Kernel: Creates complex, highly flexible island-like boundaries.
Classic Example:
  • Suppose Class A forms a circle, completely surrounded by a ring of Class B.
  • In 2D: Cannot be separated by a straight line ❌.
  • With Kernel Trick: Map to 3D (a cone shape). Now separable by a flat plane ✅.
⭐ FINAL EXAM SUMMARY ⭐
The "Write This" Paragraph

Support Vector Machine (SVM) is a supervised learning algorithm that finds the optimal hyperplane to separate classes by maximizing the margin between them. The closest points to the hyperplane, called support vectors, determine the decision boundary. SVM solves an optimization problem to maximize this margin, greatly improving generalization. For non-linearly separable data, the kernel trick is heavily used to map data into a higher-dimensional space where it becomes linearly separable, using functions such as linear, polynomial, or RBF kernels.

Key Advantages: Highly effective in high-dimensional spaces, creates complex boundaries, and is memory efficient (only relies on support vectors).

MOD 4 — Advanced SVM Mathematics

Q52 · ADVANCED OPTIMIZATION
Soft Margin SVM & Slack Variables ($\xi$)

Instead of forcing perfect separation (which causes severe overfitting on noisy data), a Soft Margin SVM mathematically allows some violations by introducing Slack Variables ($\xi_i \ge 0$).

◈ THE SOFT MARGIN OPTIMIZATION FUNCTION
$$\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C \sum_{i} \xi_i$$

Subject to the constraints:

$$y_i(w \cdot x_i + b) \ge 1 - \xi_i$$
The Role of $C$: It controls the trade-off.
  • Large $C$: Heavy penalty for $\xi$. Fewer violations allowed (risk of overfitting).
  • Small $C$: Low penalty. Wider margin, more tolerance (better generalization).
Q53 · NON-LINEAR BOUNDARIES
The Formal Mathematical Kernel Trick

For intrinsically non-linear patterns, SVM maps the input $x$ to a higher-dimensional feature space $\phi(x)$ and learns a linear separator there.

The Efficiency Secret:

It computes inner products directly via a Kernel function $K$, avoiding the computationally explosive need to explicitly compute $\phi(x)$.

$$K(x_i, x_j) = \phi(x_i) \cdot \phi(x_j)$$
Common Kernel Functions:
  • Linear: $K(x, z) = x \cdot z$
  • Polynomial: $K(x, z) = (x \cdot z + c)^d$
  • RBF (Gaussian): $K(x, z) = \exp(-\gamma \|x - z\|^2)$
👉 The choice of kernel mathematically dictates the shape and complexity of the final decision boundary.
⭐ FINAL EXAM SUMMARY ⭐
Advanced SVM (The "Write This" Paragraph)

For non-linearly separable data, SVM uses a soft margin to allow some misclassification and introduces slack variables ($\xi$) controlled by a regularization parameter $C$. Additionally, it applies the kernel trick to implicitly map data into a higher-dimensional space where it becomes linearly separable. Kernel functions such as linear, polynomial, and RBF compute inner products in this transformed space without explicit mapping. For example, data arranged in concentric circles cannot be separated linearly in 2D, but using an RBF kernel, SVM can form a circular decision boundary and achieve correct classification.

8Schedule, Meeting, Project0
Total Emails: 8
Spam Emails: 5 (IDs 1, 2, 4, 6, 7)
Not Spam Emails: 3 (IDs 3, 5, 8)

Task: Calculate the probability of an email with the words "Free" and "Win" being spam.

I) COMPUTE THE PRIOR PROBABILITIES

The prior probability is simply the ratio of each class in the total dataset.

  • $P(\text{Spam}) = 5 / 8 = \mathbf{0.625}$
  • $P(\text{Not Spam}) = 3 / 8 = \mathbf{0.375}$
II) COMPUTE THE LIKELIHOOD PROBABILITIES

We calculate the likelihood by counting how many emails in a specific class contain the word, divided by the total number of emails in that class (Document Frequency).

For Spam (out of 5 emails):
  • "Free" appears in 4 emails (IDs 1, 2, 4, 7) → $P(\text{Free} | \text{Spam}) = 4 / 5 = \mathbf{0.8}$
  • "Win" appears in 3 emails (IDs 1, 4, 7) → $P(\text{Win} | \text{Spam}) = 3 / 5 = \mathbf{0.6}$
For Not Spam (out of 3 emails):
  • "Free" appears in 0 emails → $P(\text{Free} | \text{Not Spam}) = 0 / 3 = \mathbf{0}$
  • "Win" appears in 0 emails → $P(\text{Win} | \text{Not Spam}) = 0 / 3 = \mathbf{0}$
III) USE THE NAÏVE BAYES FORMULA

The theorem states that the probability of a class given a set of features is proportional to the prior probability of the class multiplied by the likelihood of each feature.

1. Calculate the score for Spam:

$P(\text{Spam} | \text{Free, Win}) \propto P(\text{Spam}) \times P(\text{Free} | \text{Spam}) \times P(\text{Win} | \text{Spam})$

Spam Score = $0.625 \times 0.8 \times 0.6 = \mathbf{0.3}$

2. Calculate the score for Not Spam:

$P(\text{Not Spam} | \text{Free, Win}) \propto P(\text{Not Spam}) \times P(\text{Free} | \text{Not Spam}) \times P(\text{Win} | \text{Not Spam})$

Not Spam Score = $0.375 \times 0 \times 0 = \mathbf{0}$

3. Normalize the Probabilities:

To get the final percentage, divide the score by the sum of all scores.

  • $P(\text{Spam}) = \frac{0.3}{0.3 + 0} = \mathbf{1.0} \text{ (or 100\%)}$
  • $P(\text{Not Spam}) = \frac{0}{0.3 + 0} = \mathbf{0.0} \text{ (or 0\%)}$

(Note: In real-world apps, "Laplace Smoothing" is used to prevent 0 probabilities from wiping out the score, but based on raw formulas, the result is exactly 0).

IV) DETERMINE THE CLASSIFICATION
Because the probability score for Spam ($1.0$) is strictly greater than the score for Not Spam ($0.0$), the email containing the words "Free" and "Win" is classified as SPAM.

GIVEN CONFUSION MATRIX

Task: i) Define components (TP, TN, FP, FN).   ii) Compute Accuracy, Precision, Recall, and F1-Score.   iii) Interpret the model's performance.

I) DEFINE THE COMPONENTS (POSITIVE CLASS = 1)

A Confusion Matrix compares predicted classifications against actual true labels. For Class = 1:

  • True Positive (TP): Correctly predicted positive (Actual 1, Predicted 1) → 35
  • True Negative (TN): Correctly predicted negative (Actual 0, Predicted 0) → 50
  • False Positive (FP): Incorrectly predicted positive (Actual 0, Predicted 1) → 10 (Type I Error)
  • False Negative (FN): Incorrectly predicted negative (Actual 1, Predicted 0) → 5 (Type II Error)

Total Observations ($N$) = $35 + 50 + 10 + 5 = \mathbf{100}$

II) COMPUTE THE METRICS
1. Accuracy

Proportion of total correct predictions.

$\frac{TP + TN}{N} = \frac{35 + 50}{100} = \mathbf{0.85 \text{ (85\%)}}$

2. Precision

Proportion of positive predictions that were correct.

$\frac{TP}{TP + FP} = \frac{35}{35 + 10} \approx \mathbf{0.7778 \text{ (77.8\%)}}$

3. Recall (Sensitivity)

Proportion of actual positives correctly identified.

$\frac{TP}{TP + FN} = \frac{35}{35 + 5} = \mathbf{0.875 \text{ (87.5\%)}}$

4. F1-Score

Harmonic mean of Precision and Recall.

$2 \times \frac{0.7778 \times 0.875}{0.7778 + 0.875} \approx \mathbf{0.8235 \text{ (82.35\%)}}$

III) INTERPRET THE MODEL'S PERFORMANCE
  • Strong Recall (87.5%): The model is highly effective at identifying positive cases, missing only 5 out of the 40 actual instances.
  • Moderate Precision (77.8%): While good at finding positives, it is slightly "trigger-happy." When it flags something as positive, it is wrong about 22% of the time.
  • Solid Balance (F1-Score 82.35%): Confirms a healthy balance. It prioritizes finding positives without sacrificing too much accuracy in its positive predictions.
  • Good Overall Accuracy (85%): With 85/100 correct predictions, it is a solid baseline classifier, assuming the cost of a False Positive is not catastrophic.

Impact on Unsupervised Learning
  • Harder to detect natural groupings.

MOD 5 — Missing Data & Hierarchical Clustering

CONCEPT 1 · PREPROCESSING
Handling Incomplete / Missing Data

In unsupervised learning, many algorithms (like K-Means) strictly assume complete data. When data is missing, it can severely distort clustering, making preprocessing critical.

1. Imputation (Most Common)

Replace missing values with statistical estimates:

  • Mean: Replace missing income with the average income.
  • Median: Used if the data has extreme outliers.
2. Distance-Based Handling

Used actively during clustering:

  • Compute the distance metric (like Euclidean) using only the available features for that specific pair of points.
3. Model-Based Approaches
  • Use probabilistic algorithms like EM (Expectation-Maximization) to mathematically estimate the missing values based on the distribution of the rest of the data.
4. Ignoring Missing Values
  • Delete the entire row containing missing entries.
  • Warning: Highly discouraged for small datasets as you lose vital information.
CONCEPT 2 · ALGORITHM ARCHITECTURE
Agglomerative vs. Divisive Clustering

Hierarchical clustering builds a tree-like structure called a Dendrogram.

◈ AGGLOMERATIVE (BOTTOM-UP)

Start with each data point as its own cluster, then recursively merge the closest clusters.

  • Step 1: {A} {B} {C} {D}
  • Step 2: {A,B} {C} {D}
  • Step 3: {A,B,C} {D}
  • Step 4: {A,B,C,D}
✔ Simple & widely used
✔ Greedy approach (no backtracking)
◈ DIVISIVE (TOP-DOWN)

Start with all data inside one massive cluster, then recursively split it.

  • Step 1: {A,B,C,D}
  • Step 2: {A,B} {C,D}
  • Step 3: {A} {B} {C} {D}
✔ More accurate (global view)
✖ Computationally expensive
CONCEPT 3 · DISTANCE METRICS
Linkage Criteria in Hierarchical Clustering

When deciding whether to merge two clusters, we need a mathematical rule to measure the exact distance between them.

  • A) Single Linkage (Nearest Neighbor)
    $d(A,B) = \min(\text{distance between points})$

    Distance between the closest points of two clusters.

    • Shape: Long, chain-like clusters.
    • Sensitivity: High noise sensitivity (Chaining effect).
  • B) Complete Linkage (Farthest Neighbor)
    $d(A,B) = \max(\text{distance})$

    Distance between the farthest points of two clusters.

    • Shape: Tight, spherical, compact clusters.
    • Sensitivity: Highly sensitive to outliers.
  • C) Average Linkage
    $d(A,B) = \frac{1}{n \times m} \sum \text{distances}$

    Average distance between all possible pairs of points across the two clusters.

    • Shape: Balanced approach.
    • Sensitivity: Moderate/Less sensitive to noise.
⭐ FINAL INSIGHT ⭐
Exam Summary Checklist
  • Handling missing data via imputation or algorithm modification is mathematically crucial before clustering.
  • Agglomerative is bottom-up (practical, widely used).
  • Divisive is top-down (theoretically better global view, but computationally expensive).
  • The choice of Linkage (Single, Complete, Average) heavily dictates the final cluster shape and structural accuracy.

MOD 5 — Spectral Clustering (Deep Dive)

Q21 · GRAPH-BASED CLUSTERING
The Core Idea & Step-by-Step Working

Spectral Clustering is a powerful graph-based algorithm designed to detect complex, non-convex cluster shapes—something traditional distance-based methods like K-means fundamentally struggle with.

👉 The Core Idea:

Instead of working directly in the original feature space, it treats data points as nodes of a graph, uses similarity as weighted edges, and relies on Eigenvalues/Eigenvectors to transform the data into a new space where clusters become easily separable.

◈ THE 6-STEP ALGORITHM
  1. Construct Similarity (Affinity) Matrix ($W$): Create matrix $W$, where $W_{ij}$ is the similarity between points. Commonly uses Gaussian similarity:
    $$W_{ij} = e^{-\frac{||x_i - x_j||^2}{2\sigma^2}}$$
  2. Compute Degree Matrix ($D$): A diagonal matrix containing the sum of weights for each node:
    $$D_{ii} = \sum_{j} W_{ij}$$
  3. Compute Graph Laplacian ($L$): The core graph matrix.
    $$L = D - W$$
  4. Compute Eigenvalues & Eigenvectors: Find the smallest $k$ eigenvalues and take their corresponding $k$ eigenvectors (these capture the structure of the graph).
  5. Form New Feature Space: Each data point is now represented strictly using these eigenvectors, transforming complex shapes into linearly separable clusters.
  6. Apply K-means: Run standard K-means on this newly transformed data.
Q22 · MATHEMATICS & LIMITATIONS
Why Eigenvalues? & Computational Complexity
Why do Eigenvalues help?
  • They directly capture the connectivity of the graph.
  • They mathematically identify natural partitions.
  • They minimize connections between distinct clusters.
  • Insight: This solves the "Graph Cut" problem—dividing the graph with minimal edge loss.
Computational Complexity

Spectral Clustering is highly expensive:

  • Similarity Matrix: $O(n^2)$
  • Eigen Decomposition: $\mathbf{O(n^3)}$ (Dominant Term)
  • K-Means step: $O(nkt)$
👉 Final Complexity: $O(n^3)$
Not suitable for very large datasets.

MOD 5 — Principal Component Analysis (PCA)

CONCEPT 1 · DIMENSIONALITY REDUCTION
The Core Idea & 5-Step Process

PCA transforms high-dimensional data into a lower-dimensional space while strictly preserving as much variance (information) as possible.

The Core Idea: Data often has redundant/correlated features. PCA finds new axes (principal components) that are completely uncorrelated (orthogonal) and capture the maximum mathematical variance.
◈ HOW PCA REDUCES DIMENSIONALITY (THE 5 STEPS)
  1. Standardize Data: Convert all features to the same scale (mean = 0, variance = 1).
  2. Compute Covariance Matrix: Shows mathematically how features vary together.
  3. Compute Eigenvalues & Eigenvectors: Extracts the core components of the matrix.
  4. Sort Components: Arrange the eigenvalues in descending order and select the top $k$ components.
  5. Project Data: The original data is mapped onto the selected eigenvectors, reducing dimensions from $n \rightarrow k$.
👉 Result: A lower-dimensional representation with minimal information loss.
CONCEPT 2 · LINEAR ALGEBRA
The Role of Eigenvalues & Eigenvectors
Eigenvectors ($v$)
  • Define the new axes (the principal components).
  • Show the exact direction of maximum variance.
Eigenvalues ($\lambda$)
  • Indicate the importance (magnitude) of each component.
  • Larger eigenvalue → More information captured.
👉 The First Principal Component (PC1) = Direction with the highest variance.
CONCEPT 3 · VARIANCE PRESERVATION
Explained Variance Ratio (EVR)

The Explained Variance Ratio tells you the exact percentage of total variance mathematically captured by each individual component.

$$EVR_i = \frac{\lambda_i}{\sum_{j} \lambda_j}$$
Example Calculation:
Component Eigenvalue EVR
PC1 5 50%
PC2 3 30%
PC3 2 20%

👉 Selecting PC1 + PC2 retains exactly 80% of the information.

Selecting Components:

How many components should you keep?

  • Choose a number of components such that the Cumulative EVR $\ge$ 90% (or 95%).
  • This systematically reduces dimensions while keeping the most useful information for the ML model.
⭐ FINAL INSIGHT ⭐
Advantages, Limitations & Conclusion
Advantages
  • Removes redundancy (correlated features).
  • Drastically reduces computation cost.
  • Helps in 2D/3D visualization of complex data.
Limitations
  • Loses human interpretability (axes are no longer "Age" or "Income", just math).
  • Assumes strict linear relationships.
  • Highly sensitive to scaling.
The Exam Summary: PCA = Variance Maximization + Dimensionality Reduction. Eigenvectors provide the directions, Eigenvalues provide the importance, and the EVR mathematically dictates exactly how many components you must keep to retain the dataset's integrity.

MOD 5 — DBSCAN & Generative Models

CONCEPT 9 · DENSITY-BASED CLUSTERING
DBSCAN: Parameters & Point Types

DBSCAN groups together points that are closely packed and explicitly marks isolated points as noise. Unlike K-means, it absolutely does not require the number of clusters ($K$) in advance.

The Key Parameters
  • $\varepsilon$ (Epsilon): The neighborhood radius.
  • MinPts: The minimum number of points required within $\varepsilon$ to form a dense region.
The 3 Point Types
  • Core Point: Has at least MinPts within its $\varepsilon$ radius. (Expands cluster)
  • Border Point: Has fewer than MinPts, but lies within $\varepsilon$ of a Core point. (Attaches to cluster)
  • Noise Point: Not reachable from any core point. (Ignored/Outlier)
◈ DBSCAN WORKFLOW
  1. Pick an unvisited point and check its $\varepsilon$-neighborhood.
  2. If Core: Form a cluster. Expand it by recursively adding neighbors.
  3. If Not: Mark as noise (Note: It may later be reclassified as a border point if a nearby core point expands to it).
  4. Repeat until all points are processed.

Two distinct neural networks mathematically compete against each other in a zero-sum game.

◈ THE DISCRIMINATOR

Evaluates inputs and acts as a detective. Its sole goal is to accurately classify data as "Real" (from the dataset) or "Fake" (from the Generator).

MOD 5 — t-SNE Mathematics & Hypothesis Spaces

CONCEPT 11.1 · THE CORE MAGIC
t-SNE: Converting Distances into Probabilities

Unlike PCA which preserves exact distances, t-SNE preserves neighborhood relationships. It does this by converting physical distances into mathematical probabilities.

◈ STEP 1: HIGH-DIMENSIONAL WORLD (GAUSSIAN)

For each pair of points $x_i, x_j$, compute the probability that they are neighbors using a Gaussian distribution:

$$p_{j|i} = \frac{\exp(-||x_i - x_j||^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-||x_i - x_k||^2 / 2\sigma_i^2)}$$

Interpretation: If $x_j$ is close to $x_i$, probability is high. If far, probability is tiny. This is then symmetrized into $p_{ij}$.

◈ STEP 2: LOW-DIMENSIONAL WORLD (STUDENT-t)

In the reduced space (e.g., 2D), compute similarities using a Student-t distribution:

$$q_{ij} = \frac{(1 + ||y_i - y_j||^2)^{-1}}{\sum_{k \neq l} (1 + ||y_k - y_l||^2)^{-1}}$$
Why Student-t? It has heavy tails, which mathematically prevents the "crowding problem" (everything collapsing together).
◈ STEP 3: MATCHING WORLDS (KL DIVERGENCE)

t-SNE uses Gradient Descent to minimize the Kullback-Leibler (KL) Divergence, forcing the low-dim $q_{ij}$ to mimic the high-dim $p_{ij}$:

$$KL(P||Q) = \sum p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

MOD 5 — Clustering Evaluation, Distances & K-PCA Math

CONCEPT 13 · EVALUATING CLUSTERING
Silhouette, DBI, and ARI Metrics

Clustering is unsupervised, so judging it is like critiquing abstract art without knowing the artist’s intent. We rely on internal and external metrics.

  • 1. Silhouette Score

    Measures how well a point fits within its cluster ($a$) vs outside it ($b$).

    $$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$
    • Range: $+1$ (Perfect) → $0$ (Overlapping) → $-1$ (Wrong assignment).
    • Use When: No ground truth labels exist. Works best for well-separated, non-spherical clusters.
  • 2. Davies-Bouldin Index (DBI)

    Measures cluster compactness ($\sigma$) vs separation ($d$).

    $$DB = \frac{1}{k} \sum_{i=1}^{k} \max_{j \neq i} \left( \frac{\sigma_i + \sigma_j}{d(c_i, c_j)} \right)$$
    • Interpretation: Lower is better. Penalizes large spread clusters and closely spaced clusters.
    • Use When: Comparing multiple models, assuming clusters are spherical.
  • 3. Adjusted Rand Index (ARI)

    Compares clustering results directly with ground truth labels by counting agreements and disagreements, adjusted for chance.

    • Range: $1$ (Perfect match) → $0$ (Random) → $<0$ (Worse than random).
    • Use When: True labels exist (benchmarking).
👉 Quick Metaphors:
Silhouette = “Do I belong here?” | DBI = “Are clusters neat and far apart?” | ARI = “Did we match the answer key?”
CONCEPT 14 · ADVANCED DISTANCE METRICS
Mahalanobis Distance in Clustering
Why Euclidean Fails

Euclidean treats all features as equally important and uncorrelated. If Height & Weight are correlated, Euclidean double-counts that effect.

Why Mahalanobis Works

Accounts for variance, removes redundancy between correlated variables, and scales data automatically without manual normalization.

◈ THE MATHEMATICAL FORMULA
$$D_M(x) = \sqrt{(x - \mu)^T S^{-1} (x - \mu)}$$

Where $\mu$ = Mean vector, and $S$ = Covariance matrix.

CONCEPT 15 · MATHEMATICAL FOUNDATIONS
The Derivation of Kernel PCA

Standard PCA relies on the Covariance matrix $C = \frac{1}{n} X^T X$, which only captures linear relationships. Kernel PCA steps into elegant math territory to fix this.

◈ STEP-BY-STEP DERIVATION
  1. Map the Data: Map data into a higher-dimensional space:
    $$x \rightarrow \phi(x)$$
  2. Covariance in Feature Space: Compute the covariance matrix in that new space:
    $$C = \frac{1}{n} \sum \phi(x_i)\phi(x_i)^T$$
  3. Eigenvalue Problem: Solve for the principal components:
    $$C v = \lambda v$$
🚨 The Problem: The feature space $\phi(x)$ may be mathematically infinite-dimensional, making Step 2 computationally impossible.
✨ The Kernel Trick (The Magic Portal)

Instead of computing $\phi(x)$, we use a Kernel function to compute the inner products directly, giving us the Kernel Matrix $K$:

$$K(x_i, x_j) = \phi(x_i)^T \phi(x_j)$$

Final Eigenvalue Problem: $K\alpha = \lambda\alpha$

Final Projection: $y_k(x) = \sum_{i=1}^{n} \alpha_i^{(k)} K(x_i, x)$

Feature Standard PCA Kernel PCA
Complexity / Flexiblity Low / Limited High / Very High
Best For Linear Data Nonlinear (Spirals, Images)
👉 Intuition: PCA = flattening a crumpled paper | Kernel PCA = unfolding it first, then flattening.

It provides an optimal, recursive mathematical algorithm for estimating the true state of a linear dynamic system from a series of incomplete and noisy measurements.

    Does not need to store past history. Only uses the current state estimate and current uncertainty to calculate the next state (highly efficient for real-time).

Q3 · VALUE APPROXIMATION
TD Learning Parameter Update Equations

In Temporal Difference (TD) learning with linear function approximation, the estimated utility function $\hat{U}(s)$ is represented as a linear combination of features $f_i(s)$ and weights $\theta_i$.

◈ THE FOUNDATIONAL MATH

1. The Specific Utility Function:

$$\hat{U}(x, y) = \theta_0 + \theta_1 x + \theta_2 y + \theta_3 \sqrt{(x - x_g)^2 + (y - y_g)^2}$$

2. The TD(0) Update Rule:

$$\theta_i \leftarrow \theta_i + \alpha \delta \frac{\partial \hat{U}(x, y)}{\partial \theta_i}$$
  • $\alpha$: Learning rate.
  • $\delta$: TD Error → $\delta = R(x, y) + \gamma \hat{U}(x', y') - \hat{U}(x, y)$
The Partial Derivatives: Because the function is strictly linear with respect to $\theta$, the derivative $\frac{\partial \hat{U}}{\partial \theta_i}$ is simply the corresponding feature $f_i(x, y)$!
Explicit Parameter Update Equations:
  • For $\theta_0$:   $\theta_0 \leftarrow \theta_0 + \alpha \delta (1)$
  • For $\theta_1$:   $\theta_1 \leftarrow \theta_1 + \alpha \delta x$
  • For $\theta_2$:   $\theta_2 \leftarrow \theta_2 + \alpha \delta y$
  • For $\theta_3$:   $\theta_3 \leftarrow \theta_3 + \alpha \delta \sqrt{(x - x_g)^2 + (y - y_g)^2}$
Q4, Q5 · COGNITIVE SCIENCE
RL in Evolution & Animal Behavior
RL as a Model for Evolution (Q4)

RL is not a perfect model for evolution itself (Genetic Algorithms are a closer fit, operating on populations across generations). RL models a single agent learning within its own lifetime.

Hardwired Rewards vs. Fitness: Evolution has hardwired local reward signals (pleasure of eating, pain of touching fire). When an RL agent (or animal) maximizes these daily rewards, it is indirectly maximizing the long-term evolutionary fitness (survival/reproduction) that the species was shaped to achieve.
Modeling Human & Animal Behavior (Q5)

RL actually originated from animal behavior psychology (Pavlov, Skinner) before becoming a computer science discipline.

  • Dopamine & TD Error: The firing rates of midbrain dopamine neurons in mammals perfectly encode the Reward Prediction Error (the $\delta$ term). Unexpected reward = dopamine spike ($+\delta$). Predicted reward fails = dopamine drop ($-\delta$).
  • Psychopathology: RL models are used to study conditions like addiction (drugs artificially hijack the reward prediction error, forcing $\theta$ to continuously increase) and depression (discount factor $\gamma$ is skewed or reward sensitivity is dulled).

CONCEPT 1 · REVERSE ENGINEERING
Inverse Reinforcement Learning (IRL)
The Core Concept: Learn the underlying reward function by strictly observing an expert's behavior.

The Reversal:

  • Standard RL: An agent is given a specific reward function and must learn the optimal policy (how to act).
  • Inverse RL: The agent is given a policy or successful trajectories demonstrated by an expert (e.g., a human driving a car), and it must deduce what reward function the expert is actively trying to maximize.

👉 Highly useful when it is mathematically difficult to explicitly code what makes a behavior "good" (like driving gracefully), but easy to just provide human examples.

CONCEPT 2 · STATE ESTIMATION
Localization for the Vacuum World

Localization is the problem of a robot determining its exact current location on a grid when its initial starting position is completely unknown.

◈ THE BELIEF STATE MECHANISM
  • The Problem: Sensors are limited (only detecting bumps or dirt). Because of this, many grid squares look absolutely identical to the robot.
  • The Solution: The robot maintains a Belief State — a mathematical probability distribution of all possible squares it could currently be in.
  • The Update: As it moves, bumps walls, and senses dirt, it continuously updates this belief state, systematically ruling out impossible locations until the probability securely converges on a single, certain location.
CONCEPT 3 · PROBABILISTIC NETWORKS
The Sleep DBN and HMM Formulation

Variables: State Variable $S_t$ (Enough Sleep), Observation 1 $R_t$ (Red Eyes), Observation 2 $C_t$ (Sleeping in Class).

Dynamic Bayesian Network (DBN)

Observations are kept entirely separate.

  • Prior: $P(S_0 = T) = 0.7$
  • Transition Model:
    $P(S_t=T \mid S_{t-1}=T) = 0.8$
    $P(S_t=T \mid S_{t-1}=F) = 0.3$
  • Observation Models:
    $P(R_t=T \mid S_t=T) = 0.2$
    $P(C_t=T \mid S_t=T) = 0.1$
Hidden Markov Model (HMM)

Strictly requires a single joint observation variable ($O_t$).

  • TT: Red Eyes AND Sleeping
  • TF: Red Eyes AND Awake
  • FT: Clear Eyes AND Sleeping
  • FF: Clear Eyes AND Awake
◈ THE HMM EMISSION TABLE

Because $R_t$ and $C_t$ are conditionally independent given $S_t$, we simply multiply them. Example: $P(O_t=TT \mid S_t=T) = P(R_t=T \mid S_t=T) \times P(C_t=T \mid S_t=T) = 0.2 \times 0.1 = \mathbf{0.02}$

CONCEPT 4 · KINEMATICS & FILTERING
What is EKF? (Extended Kalman Filter)
The Problem: A standard Kalman Filter optimally tracks linear systems. However, real-world physics and robot kinematics (like turning in arcs or accelerating) are intrinsically highly non-linear.

The EKF Solution:

  • The EKF physically solves this by linearizing the non-linear transition and observation models around the current state estimate.
  • It does this using advanced calculus — specifically, the Jacobian Matrix (which contains the first partial derivatives).
  • This mathematical bridge allows standard linear Kalman tracking math to be reliably applied to complex, non-linear environments!

SVC(kernel='rbf')
SVC = Support Vector Classifier. 'rbf' = Radial Basis Function kernel. Instead of drawing a straight line boundary, RBF uses a Gaussian function to create curved, complex decision boundaries.
C=1.0
The regularization parameter. C=1.0 is balanced. High C: the model tries to correctly classify every training point (may overfit). Low C: allows some misclassifications to get a wider margin (may underfit).
gamma='scale'
Controls how far the influence of a single training point reaches. 'scale' automatically sets gamma = 1/(n_features × var(X)), which is a sensible default. High gamma = points only influence nearby region.
df.drop(columns=['target'])
Removes the 'target' column from the feature matrix X. We can't include the answer as an input feature — that would be cheating and cause trivial 100% accuracy.
svm_model.fit(X_train, y_train)
Finds the optimal hyperplane (in high-dimensional RBF space) that maximizes the margin between malignant and benign tumor classes. Only the support vectors (points closest to the boundary) influence the final boundary.
confusion_matrix(y_test, y_pred)
Shows TP (cancer caught), TN (benign confirmed), FP (false alarm), FN (missed cancer). For medical applications, minimizing FN (missed cancers) is the highest priority.
