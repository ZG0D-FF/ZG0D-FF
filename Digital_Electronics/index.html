Chapter 01

Logic Gates & Universal Synthesis

A logic gate is an idealized or physical electronic device implementing a Boolean function, performing a logical operation on one or more binary inputs and producing a single binary output. At the physical layer (CMOS / TTL), logic states are represented by defined voltage ranges.

1.1 Standard Logic Gates & Electrical Truth Tables

In standard positive logic convention, a higher potential represents Logic 1 (HIGH), while a lower potential represents Logic 0 (LOW).

Gate Type Standard Boolean Equation A=0, B=0 A=0, B=1 A=1, B=0 A=1, B=1 Algebraic Behavior / Inversion
AND $Y = A \cdot B$ 0 0 0 1 Output HIGH only when all inputs are 1.
OR $Y = A + B$ 0 1 1 1 Output HIGH when at least one input is 1.
NOT (Inverter) $Y = \bar{A}$ 1 (A=0) — 0 (A=1) — Bitwise complement; double negation $\bar{\bar{A}} = A$.
NAND $Y = \overline{A \cdot B}$ 1 1 1 0 Universal. Complement of AND.
NOR $Y = \overline{A + B}$ 1 0 0 0 Universal. Complement of OR.
XOR (Modulo-2) $Y = A \oplus B = \bar{A}B + A\bar{B}$ 0 1 1 0 Odd-detector. Output 1 when inputs differ.
XNOR (Equivalence) $Y = A \odot B = AB + \bar{A}\bar{B}$ 1 0 0 1 Even-detector. Output 1 when inputs are equal.

1.2 Universal Gate Theorem & Minimum Synthesis Proofs

A logic family is defined as functionally complete or universal if any arbitrary Boolean switching function can be synthesized using only that single gate type without requiring external inverters. Both NAND and NOR gates possess functional completeness.

Target Gate Operation Minimum NAND Count NAND Synthesis Topology Minimum NOR Count NOR Synthesis Topology
NOT ($\bar{A}$) 1 $\overline{A \cdot A}$ 1 $\overline{A + A}$
AND ($A \cdot B$) 2 $\overline{(\overline{AB}) \cdot (\overline{AB})}$ 3 $\overline{(\overline{A+A}) + (\overline{B+B})}$
OR ($A + B$) 3 $\overline{(\overline{AA}) \cdot (\overline{BB})}$ 2 $\overline{(\overline{A+B}) + (\overline{A+B})}$
XOR ($A \oplus B$) 4 $\text{NAND}(A, \text{NAND}(A,B))$ & $\text{NAND}(B, \text{NAND}(A,B))$ fed into final NAND 5 Requires 5 NOR gates ($A+B$, intermediate cross-terms)
XNOR ($A \odot B$) 5 Invert output of 4-NAND XOR (or dual cross structure) 4 Symmetric 4-NOR topology (dual of 4-NAND XOR)
💡 Mechanical & Intuitive Breakdown: XOR Minimum 4-NAND Structure

To implement $Y = \bar{A}B + A\bar{B}$ with only 4 NANDs, define the shared intermediate term $T_1 = \overline{AB}$. Then branch $T_1$ to two second-stage gates: $T_2 = \overline{A \cdot T_1} = \overline{A \cdot \overline{AB}} = \bar{A} + AB = \bar{A} + B$, and $T_3 = \overline{B \cdot T_1} = \overline{B \cdot \overline{AB}} = \bar{B} + A$. Feeding $T_2$ and $T_3$ into the fourth NAND produces: $$Y = \overline{T_2 \cdot T_3} = \overline{(\bar{A} + B)(\bar{B} + A)} = \overline{\bar{A}\bar{B} + AB} = A \oplus B$$ This single shared term $T_1$ eliminates the need for 5 gates.

⚠️ Exam Trap: Non-Associativity of Universal Gates

While AND, OR, XOR, and XNOR are strictly associative, NAND and NOR are NOT associative: $$(A \text{ NAND } B) \text{ NAND } C \neq A \text{ NAND } (B \text{ NAND } C)$$ Proof: Let $A=0, B=0, C=0$. LHS: $(\overline{0 \cdot 0}) \text{ NAND } 0 = 1 \text{ NAND } 0 = 1$. RHS: $0 \text{ NAND } (\overline{0 \cdot 0}) = 0 \text{ NAND } 1 = 1$. Now let $A=1, B=1, C=0$. LHS: $(\overline{1 \cdot 1}) \text{ NAND } 0 = 0 \text{ NAND } 0 = 1$. RHS: $1 \text{ NAND } (\overline{1 \cdot 0}) = 1 \text{ NAND } 1 = 0$. Since $\text{LHS} \neq \text{RHS}$, cascading NAND or NOR gates without proper inversion logic yields invalid multi-input switching networks.

Chapter 02

Boolean Algebra, Canonical Forms & Karnaugh Maps

Boolean algebra provides the axiomatic mathematical framework for two-valued switching circuits. Minimizing switching functions directly reduces hardware silicon area, dynamic switching capacitance, and propagation latency.

2.1 Fundamental Axioms & Essential Theorems

1. Idempotent Laws: $A + A = A \quad\Longleftrightarrow\quad A \cdot A = A$
2. Boundedness (Dominance): $A + 1 = 1 \quad\Longleftrightarrow\quad A \cdot 0 = 0$
3. Involution (Double Negation): $\overline{\overline{A}} = A$
4. Absorption Laws: $A + AB = A \quad\Longleftrightarrow\quad A(A + B) = A$
5. Elimination Law: $A + \bar{A}B = A + B \quad\Longleftrightarrow\quad A(\bar{A} + B) = AB$
6. De Morgan's Laws: $\overline{A + B} = \bar{A} \cdot \bar{B} \quad\Longleftrightarrow\quad \overline{A \cdot B} = \bar{A} + \bar{B}$
7. Consensus Theorem: $AB + \bar{A}C + BC = AB + \bar{A}C$
    Dual: $(A + B)(\bar{A} + C)(B + C) = (A + B)(\bar{A} + C)$
💡 Rigorous Proof: Consensus Theorem ($AB + \bar{A}C + BC = AB + \bar{A}C$)

Expand the redundant term $BC$ using the complementary identity $(A + \bar{A}) = 1$:

$$AB + \bar{A}C + BC = AB + \bar{A}C + BC(A + \bar{A})$$ $$= AB + \bar{A}C + ABC + \bar{A}BC$$ $$= (AB + ABC) + (\bar{A}C + \bar{A}BC)$$ $$= AB(1 + C) + \bar{A}C(1 + B)$$ Since $(1 + X) = 1$: $$= AB(1) + \bar{A}C(1) = AB + \bar{A}C \quad \blacksquare$$ The term $BC$ is the consensus of $AB$ and $\bar{A}C$ and is completely redundant.

2.2 Canonical Forms: SOP ($\Sigma m$) vs POS ($\Pi M$)

For $n$ binary variables, exactly $2^n$ distinct minterms and $2^n$ distinct maxterms exist. The total number of distinct switching functions possible with $n$ variables is $2^{2^n}$.

  • Minterm ($m_i$): A product term containing every variable in true or complemented form that evaluates to 1 for exactly one input combination.
  • Maxterm ($M_i$): A sum term containing every variable in true or complemented form that evaluates to 0 for exactly one input combination.
  • Fundamental Duality: $m_i = \overline{M_i}$ and $\sum m(k_1, k_2, \dots) = \prod M(k_{\text{remaining}})$.

2.3 Karnaugh Map (K-Map) Optimization & Implicants

A K-Map is an array of cells where each cell represents one minterm. Adjacency between adjacent cells corresponds to a Hamming distance of exactly 1 bit, enforced using Gray code sequencing ($00, 01, 11, 10$).

💡 Prime Implicants vs Essential Prime Implicants

Implicant: Any group of $2^k$ ($1, 2, 4, 8, \dots$) adjacent cells containing 1s.
Prime Implicant (PI): A maximal group of 1s that cannot be combined with any adjacent group to form a larger group of size $2^{k+1}$.
Essential Prime Implicant (EPI): A Prime Implicant containing at least one '1' that is not covered by any other Prime Implicant. All EPIs must be included in the minimal sum.

⚠️ Exam Trap: Don't Care Conditions ($d$ or $X$)

Don't care terms represent input combinations that can never occur physically (e.g., states 1010–1111 in BCD code) or whose outputs do not affect circuit operation. Rule: Treat $X$ as '1' only if it enlarges a group of 1s (halving gate inputs); never create a group consisting entirely of don't cares.

Chapter 03

Combinational Logic Circuits

Combinational circuits have outputs determined strictly by the present state of the inputs; they possess no feedback loops and no internal memory states.

3.1 Arithmetic Blocks: Adders & Subtractors

Circuit Block Inputs Outputs Standard Boolean Equations Gate Level Count & Delays

$C = AB$		 1 XOR, 1 AND
$t_{pd} = \max(t_{XOR}, t_{AND})$
Full Adder (FA) $A, B, C_{in}$ $\text{Sum } S, \text{Carry } C_{out}$ $S = A \oplus B \oplus C_{in}$
$C_{out} = AB + (A \oplus B)C_{in} = AB + BC_{in} + AC_{in}$		 2 XOR, 2 AND, 1 OR (or 9 NANDs)

⚡ Ripple Carry Adder (RCA) Worst-Case Propagation Latency

In an $N$-bit Ripple Carry Adder constructed from $N$ cascaded Full Adders, the carry output $C_i$ of stage $i$ ripples to the carry input of stage $i+1$. The worst-case latency occurs when a carry generated in bit 0 propagates all the way to bit $N-1$: $$t_{RCA} = t_{FA(carry\_init)} + (N - 1) \cdot t_{carry\_ripple}$$ For identical gate delays: $t_{RCA} = 2t_g + (N-1) \cdot 2t_g = 2N \cdot t_g$. For 32-bit addition with $t_g = 1\text{ ns}$, $t_{RCA} \approx 64\text{ ns}$, restricting clock frequencies to under $15\text{ MHz}$. Modern ALUs use Carry Lookahead Adders (CLA) where $C_i = G_i + P_i C_{i-1}$, generating carries in 2 gate levels independent of $N$.

3.2 Multiplexers (Data Selectors) as Universal Function Generators

A $2^n$-to-1 Multiplexer routes one of $2^n$ data inputs ($I_0 \dots I_{2^n-1}$) to a single output line $Y$, steered by $n$ select lines ($S_{n-1} \dots S_0$).

4:1 MUX Equation: $Y = \bar{S}_1\bar{S}_0 I_0 + \bar{S}_1 S_0 I_1 + S_1\bar{S}_0 I_2 + S_1 S_0 I_3$
Tree Expansion: To build a $2^n$-to-1 MUX from $2:1$ MUX primitives requires exactly: $$M = 2^n - 1 \quad \text{primitive 2:1 MUX units}$$ E.g., a 16:1 MUX requires $16 - 1 = 15$ two-to-one multiplexers.
💡 Shannon's Expansion Theorem: Implementing Any $(n+1)$-Variable Function with $2^n:1$ MUX

Any Boolean function $F(A, B, C, D)$ of 4 variables can be implemented directly using an 8:1 MUX without any external logic gates:

  1. Assign 3 variables ($A, B, C$) directly to select lines ($S_2, S_1, S_0$).
  2. Express the 4th variable ($D$) on the data inputs ($I_0 \dots I_7$) in terms of $\{0, 1, D, \bar{D}\}$.
  3. If an external inverter is prohibited, connect the complemented variable to an unused input channel configured as an inverter.
Chapter 04

Sequential Logic Fundamentals & Flip-Flops

Sequential circuits possess internal memory; their output is a function of both the current input vector and the past history of states stored in bistable memory elements.

4.1 Latches vs. Flip-Flops

  • Latch: Level-triggered, asynchronous. Transparent while the enable/clock is at an active level (changes on data inputs propagate directly to outputs).
  • Flip-Flop: Edge-triggered, synchronous. Samples inputs and alters internal state only during a discrete voltage transition (positive or negative clock edge).

4.2 Characteristic Equations & Excitation Tables

The Characteristic Table defines next-state $Q^+$ given current state $Q$ and inputs. The Excitation Table reverses this mapping, defining the input vector required to force a transition from $Q_n \to Q_{n+1}$.

Flip-Flop Type Characteristic Equation Transition $0 \to 0$ Transition $0 \to 1$ Transition $1 \to 0$ Transition $1 \to 1$
S-R $Q^+ = S + \bar{R}Q \quad (\text{Constraint: } SR = 0)$ $S=0, R=X$ $S=1, R=0$ $S=0, R=1$ $S=X, R=0$
J-K $Q^+ = J\bar{Q} + \bar{K}Q$ $J=0, K=X$ $J=1, K=X$ $J=X, K=1$ $J=X, K=0$
D (Delay) $Q^+ = D$ $D=0$ $D=1$ $D=0$ $D=1$
T (Toggle) $Q^+ = T \oplus Q$ $T=0$ $T=1$ $T=1$ $T=0$

4.3 Physical Breakdown: The Race-Around Condition & Master-Slave Elimination

⚡ The Race-Around Condition Explained

In a level-triggered JK flip-flop, when $J = 1$ and $K = 1$, the device operates in toggle mode: $Q^+ = \bar{Q}$. If the clock pulse width ($t_w$) exceeds the internal propagation delay of the gates ($t_{pd}$): $$t_w > t_{pd}$$ The output toggles $0 \to 1$. Because the clock remains HIGH, this new output feeds back to the gates, toggling it again $1 \to 0$, racing repeatedly back and forth throughout $t_w$. When the clock finally falls LOW, the terminal state of $Q$ is indeterminate (metastable oscillation).

💡 Master-Slave JK Architecture: How the Feedback Loop is Broken

The Master-Slave configuration cascades two distinct latches driven by complementary clock phases:

  • Phase 1: Clock = 1 (HIGH). The Master latch is active and samples inputs $J$ and $K$, updating internal node $Y$. The Slave latch is held disabled by an inverted clock ($\overline{\text{CLK}} = 0$). Output $Q$ remains completely stable; because $Q$ cannot change, no feedback reaches the Master.
  • Phase 2: Clock = 0 (LOW). The Master latch is isolated and disabled ($\text{CLK} = 0$). The Slave latch becomes active ($\overline{\text{CLK}} = 1$) and copies the state from $Y$ to output $Q$.

Physical Guarantee: Because data is sampled on one clock phase and transferred to the output on the opposite phase, input-to-output feedthrough never exists simultaneously. The race condition is eliminated.

4.4 Dynamic Switching Parameters: Setup & Hold Times

  • Setup Time ($t_s$): The minimum duration before the active clock transition during which data input $D$ must remain stable. Violating $t_s$ causes internal feedback transistors to fail to achieve saturation, trapping the flip-flop in a metastable state.
  • Hold Time ($t_h$): The minimum duration after the active clock edge during which data must remain stable.
  • Propagation Delay ($t_{PLH}, t_{PHL}$): Time elapsed between 50% point of clock transition and 50% point of output state change.
Chapter 05

Sequential Machines: Counters & Shift Registers

Counters and registers form the backbone of processor timing units, memory addressing, frequency synthesis, and serial communications protocols.

5.1 Asynchronous (Ripple) vs. Synchronous Counters

Design Metric Asynchronous (Ripple) Counter Synchronous Counter
Clocking Topology First flip-flop clocked externally; subsequent FFs clocked by output ($Q$ or $\bar{Q}$) of preceding stage. Common system clock connected simultaneously to the clock pin of every flip-flop.
Maximum Operating Frequency Low: $f_{\max} = \frac{1}{N \cdot t_{pd} + t_s}$ (delays accumulate through $N$ stages). High: $f_{\max} = \frac{1}{t_{pd\_FF} + t_{comb\_gate} + t_s}$ (independent of $N$).
Decoding Glitches / Spikes Severe. Transient intermediate states appear during ripple transitions (e.g., $011 \to 010 \to 000 \to 100$). Minimal. All flip-flops transition simultaneously within one clock period.
Hardware Complexity Minimal. Requires zero additional combinational steering gates. Moderate. Requires AND gating networks on $T$ or $J, K$ inputs to enable toggling.

5.2 Ring Counter vs. Johnson (Twisted-Ring) Counter

Both are shift-register based counters that do not require external decoding logic to identify individual states.

Feature / Parameter Ring Counter Johnson Counter (Mobius / Twisted Ring)
Feedback Connection Output $Q$ of final stage fed back to $D$ of first stage ($D_0 = Q_{N-1}$). Inverted output $\bar{Q}$ of final stage fed back to $D$ of first stage ($D_0 = \bar{Q}_{N-1}$).
Number of Valid States $N$ states (One-hot encoding: $1000 \to 0100 \to 0010 \to 0001$). $2N$ states (E.g., for $N=4$: 8 states: $0000 \to 1000 \to 1100 \dots$).
Unused States $2^N - N$ unused states. Susceptible to lockup without self-correcting logic. $2^N - 2N$ unused states. Requires single two-input gate for self-recovery.
Decoding Hardware None: each output pin directly represents one decoded timing state. Minimal: any state decoded using a single 2-input AND/NOR gate.

5.3 Shift Register Topologies

• SISO (Serial-In Serial-Out): Slowest transfer. Takes $N$ clocks to write $N$ bits, and $(N - 1)$ clocks to read out.
• SIPO (Serial-In Parallel-Out): Takes $N$ clock pulses to load data; all $N$ bits read instantaneously in 0 clock cycles.
• PISO (Parallel-In Serial-Out): Loaded in 1 clock pulse (or asynchronously via preset); read out serially over $(N - 1)$ clocks.
• PIPO (Parallel-In Parallel-Out): Fastest transfer. 1 clock pulse writes all bits; instantaneous read.
• Universal Shift Register (e.g., 74194): Controlled by mode select pins $S_1 S_0$: $$S_1 S_0 = 00 \implies \text{Hold} \quad|\quad 01 \implies \text{Shift Right} \quad|\quad 10 \implies \text{Shift Left} \quad|\quad 11 \implies \text{Parallel Load}$$
Chapter 06

Number Systems, Signed Arithmetic & Data Converters

Digital processors compute in binary domains, while physical sensor signals exist as continuous real-world analog potentials. Interfacing between them requires high-speed, high-resolution mixed-signal conversion.

6.1 Signed Number Representations & Arithmetic Overflow

In an $n$-bit binary system, unsigned integers span $[0, 2^n - 1]$. Signed representations partition the numerical range:

Representation Numerical Range (for $n$ bits) Zero Representations Key Mathematical Property
Sign-Magnitude $-(2^{n-1} - 1) \dots +(2^{n-1} - 1)$ Two: $+0$ ($00\dots0$) and $-0$ ($10\dots0$) MSB = sign bit ($0=+$, $1=-$); remaining $(n-1)$ bits indicate magnitude.
1's Complement $-(2^{n-1} - 1) \dots +(2^{n-1} - 1)$ Two: $+0$ ($00\dots0$) and $-0$ ($11\dots1$) Invert every bit. Requires end-around carry addition.
2's Complement $-2^{n-1} \dots +(2^{n-1} - 1)$ Single unique zero: $00\dots0$ Formed by: $(\text{1's Complement} + 1)$. Subtraction becomes pure addition without end-around carry.
⚠️ Exam Trap: Signed Arithmetic Overflow Condition

Arithmetic overflow occurs when the result of adding two numbers of the same sign produces a result of the opposite sign (e.g., adding two positive numbers yields a negative sign bit). Hardware Rule: In a 2's complement adder, overflow $V$ is detected by the exclusive-OR of the carry into the MSB ($C_{in}$) and the carry out of the MSB ($C_{out}$): $$V = C_{\text{into MSB}} \oplus C_{\text{out of MSB}}$$ If $V = 1$, an arithmetic overflow has occurred, corrupting the sign bit.

6.2 Digital-to-Analog Converters (DAC)

A DAC converts an $n$-bit digital binary word $D = b_{n-1} 2^{n-1} + \dots + b_0 2^0$ into an equivalent analog output voltage $V_{out}$.

Step Size (Resolution): $\Delta V = \frac{V_{FS}}{2^n - 1} \quad (\text{or ideal } \frac{V_{ref}}{2^n})$
Analog Output Voltage: $V_{out} = \Delta V \times D_{10}$
Percentage Resolution: $\% \text{Resolution} = \frac{1}{2^n - 1} \times 100\%$
DAC Architecture Circuit Schematic Principles Component Spread Ratio Practical Limitations
Binary Weighted Resistor Summing amplifier with input resistors weighted as $R, 2R, 4R, \dots, 2^{n-1}R$. Severe: $\frac{R_{\max}}{R_{\min}} = 2^{n-1}$. For 12-bit DAC, ratio is $2048:1$. Fabricating precision resistors over a $2048:1$ dynamic range on silicon is impossible due to temperature coefficient mismatches.
R-2R Ladder Network Repetitive resistive ladder network using only two resistance values: $R$ and $2R$. Ideal: $2:1$ ratio only. Industry standard. Very easy to trim precisely on integrated circuit silicon.

6.3 Analog-to-Digital Converters (ADC)

ADCs perform sampling, quantization, and binary encoding of continuous real-world voltages.

ADC Type Conversion Time Hardware Complexity Key Advantages & Ideal Use Cases
Flash (Simultaneous) $1 \text{ clock cycle}$ ($t_{pd}$ of comparator) Massive: $2^n - 1$ comparators and $2^n \times n$ priority encoder Fastest possible. Used in gigahertz digital oscilloscopes, radar, and RF software-defined radio.
Successive Approximation (SAR) Fixed: $n \text{ clock cycles}$ Moderate: 1 comparator, 1 DAC, and SAR logic Excellent balance of speed, resolution (12–16 bits), and low power. Standard in microcontrollers (ATmega328P, STM32).
Dual-Slope Integrating Variable: $2 \times 2^n \text{ clock cycles}$ Low: 1 integrator, 1 comparator, counter Slowest, but highest accuracy and complete rejection of $50/60\text{ Hz}$ line noise. Standard in digital multimeters.
Counter-Ramp (Tracking) Variable: up to $2^n \text{ clock cycles}$ Low: 1 counter, 1 DAC, 1 comparator Slow for step inputs; conversion time depends directly on input voltage amplitude.
