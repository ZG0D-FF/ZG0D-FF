Q1. Explain the purpose of the WR signal during a memory write operation.

Mapped to Notes ↗

The WR (Write) signal is an active-low control signal generated by the 8085 timing and control unit. During a memory write machine cycle, WR goes low during state T2 and remains low through T3. It signals the addressed external memory chip that the data currently placed on the data bus (AD0–AD7) is stable and valid, strobing the memory latch to write the byte into the selected location.

🧠 How to Remember in Exam (Shortcut)

Memory Write Timing Rule: Address in T1, Data placed in T2, WR is active during T2 & T3. Memory latches data on the rising edge (0 ➔ 1) of WR at the end of T3!

Q2. Explain the organization and addressing capability of a 128 × 4 memory chip.

Inline Complete Solution 💡
Click to view mathematical organization breakdown
  • Register Capacity: The chip contains 128 registers (words).
  • Word Width: Each register stores 4 bits (a nibble).
  • Total Memory Cells: Total Storage = 128 × 4 = 512 memory cells (flip-flops/bits) = 64 bytes.
  • Address Bus Capability: To uniquely address 128 locations:
    2k = 128 &implies; k = 7 address lines (A0 to A6).
  • Data Bus Lines: Requires 4 bidirectional data lines (D0–D3).
  • Control Lines: Chip Select (CS), Read (RD), and Write (WR).
  • System Integration Note: Because the 8085 has an 8-bit data bus, two such 128 × 4 chips are placed in parallel to form a 128 × 8 byte-wide memory system (one chip for D0–D3 and one for D4–D7).
🧠 How to Remember in Exam (Formula Shortcut)

For any memory chip N × M:
• Address Pins = log2(N) → log2(128) = 7 pins.
• Data Pins = M → 4 pins.
• Total Bits = N × M → 128 × 4 = 512 bits.

Q3. Why is an appropriate memory word size necessary in an 8085 system?

Mapped to Notes ↗

The 8085 is an 8-bit microprocessor with an 8-bit internal data bus and 8-bit internal registers. An appropriate memory word size (specifically 8 bits / 1 byte per addressable memory location) ensures that each memory read or write transfers an entire fundamental CPU operand in a single machine cycle (3 to 4 T-states). A mismatch (e.g. 4-bit memory) would require the MPU to perform two distinct memory access cycles per byte, cutting effective bus throughput by 50% and requiring external bus multiplexing hardware.

Q4. Explain the function of the Program Counter (PC) during opcode fetching. What happens to the PC after fetching an opcode from address 2057H?

Inline Complete Solution 💡
Click to view Program Counter fetch sequence
  1. Function during Opcode Fetch: The Program Counter is a 16-bit register that holds the memory address of the next instruction code to be fetched. At the start of the Opcode Fetch machine cycle (T1), the 8085 places the contents of the PC onto the address bus (A8–A15 on high bus, AD0–AD7 on low bus).
  2. Content after Fetching from 2057H: While the opcode byte located at 2057H is read into the Instruction Register (IR) during T2 and T3, the internal hardware increments the PC by 1. Therefore, immediately after fetching the opcode from address 2057H, the Program Counter contains 2058H.
🧠 How to Remember in Exam (Golden Rule)

PC always auto-increments during the fetch state: The moment a byte is fetched from address Addr, PC automatically becomes Addr + 1! (2057H → 2058H).

Q5. Explain how the clock frequency affects the execution speed of an 8085 microprocessor.

Mapped to Notes ↗

The execution speed is strictly inversely proportional to the duration of each clock state (T-state):

T-state Duration (T) = 1 / fCLK

The 8085 crystal frequency (fXTAL) is internally divided by 2 to yield the operational CPU clock (fCLK = fXTAL / 2). For a standard 6.144 MHz crystal, fCLK = 3.072 MHz, giving T = 325.5 ns. If clock frequency increases (e.g., using an 8085A-2 rated for 5 MHz clock), the period T shrinks to 200 ns, proportionally accelerating instruction execution and increasing computational throughput per second.

Q8. Explain the different interrupt signals supported by the 8085 and their functions.

Mapped to Notes ↗

The 8085 provides 5 hardware interrupts arranged in strict priority order:

  1. TRAP (Priority 1 - Highest): Non-maskable, edge-and-level triggered hardware interrupt. Vectored to address 0024H. Used for catastrophic events (power failure, emergency shutdown).
  2. RST 7.5 (Priority 2): Maskable, positive edge-triggered. Vectored to 003CH. Contains an internal flip-flop to latch pulses.
  3. RST 6.5 (Priority 3): Maskable, high-level triggered. Vectored to 0034H.
  4. RST 5.5 (Priority 4): Maskable, high-level triggered. Vectored to 002CH.
  5. INTR (Priority 5 - Lowest): General-purpose maskable, level-triggered, non-vectored interrupt. Requires external peripheral to supply opcode via INTA strobe.
🧠 How to Remember in Exam (Vector Address Formula)

For any restart interrupt RST N, its hex vector address is N × 8 in Hex:
• RST 7.5 → 7.5 × 8 = 60 decimal = 003CH.
• RST 6.5 → 6.5 × 8 = 52 decimal = 0034H.
• RST 5.5 → 5.5 × 8 = 44 decimal = 002CH.
• TRAP is RST 4.5 → 4.5 × 8 = 36 decimal = 0024H!

Q9. Explain the purpose and operation of the following 8085 control/status signals: ALE, IO/M, RD, WR.

Mapped to Notes ↗
  • ALE (Address Latch Enable): Positive pulse emitted during T1 of every machine cycle. Strobes external 74LS373 latch to capture address lines A0–A7 from AD0–AD7.
  • IO/M: Status output distinguishing between I/O and Memory access: logic high (1) = I/O operation; logic low (0) = Memory operation.
  • RD (Read): Active-low output indicating that the selected memory or I/O device is to be read and data bus is ready for input.
  • WR (Write): Active-low output indicating that the data on the data bus is to be written into the selected memory or I/O location.

Q10. Describe the memory read machine cycle of the 8085 with the sequence of control signals involved.

Mapped to Notes ↗

A Memory Read cycle consists of 3 clock states (T1, T2, T3):

  1. State T1: 8085 asserts IO/M = 0, S1 = 1, S0 = 0. Places high-order address on A8–A15 and low-order address on AD0–AD7. Emits positive pulse on ALE to latch A0–A7.
  2. State T2: CPU asserts RD = 0. The bus AD0–AD7 enters high-impedance (tri-state) so external memory can drive data.
  3. State T3: The memory chip places the data byte onto AD0–AD7. The CPU reads and latches data into its internal register. RD returns high.

  1. Clock Frequency (f) = 5 MHz = 5 × 106 Hz
  2. Time Period of 1 T-state (T) = 1 / f = 1 / (5 × 106) = 0.2 × 10-6 s = 0.2 μs (200 ns)

Q13. Explain memory-mapped I/O and list the control signals required for its operation.

Mapped to Notes ↗

In memory-mapped I/O, external I/O ports are assigned unique addresses within the 16-bit physical memory space (0000H–FFFFH) instead of a separate 8-bit I/O space. The CPU accesses I/O ports using standard memory instructions (LDA, STA, MOV M, R, ADD M). The 64KB memory map is shared between RAM/ROM and ports.

Required Control Signals: MEMR (Memory Read) and MEMW (Memory Write), derived by gating IO/M = 0 with RD and WR.

Q18. Explain why the lower-order address and data lines of the 8085 require address latching using the ALE signal.

Mapped to Notes ↗

To reduce the physical IC pin count from 48 down to an economical 40-pin Dual In-line Package (DIP), Intel time-division multiplexed the lower 8 bits of the address bus (A0–A7) and the 8 data lines (D0–D7) onto 8 shared physical pins (AD0–AD7).

During state T1, these pins carry the address lines. In T2–T3, they must carry data. Without latching, the address would disappear from the bus before memory chips could access the location. The 8085 emits the active-high ALE strobe in T1 to latch A0–A7 into an external 74LS373 latch, holding the address lines stable across the entire machine cycle.

1. 8085 Opcode Fetch & Memory Read Machine Cycle Timing Graph

CLK : __/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_ | T1 | T2 | T3 | T4 (Fetch only) ALE : ___/‾‾‾‾\__________________________ A8-A15 : ===< Higher Order Address (PC_H) >=== AD0-AD7 : ===< Address A0-A7 >==X===< Data from Memory >=== RD (bar) : ‾‾‾‾‾‾‾‾‾‾‾‾\_______________/‾‾‾‾‾ IO/M (bar): ___________________________________ (Logic 0 for Memory) S1, S0 : ===< S1=1, S0=0 (Read) or S1=1, S0=1 (Fetch) >===

Understanding Paragraph: The Opcode Fetch and Memory Read cycles are the foundational bus transactions of the 8085. The CPU synchronizes the address latching, tri-state bus handover, and memory data transfer across discrete clock pulses (T-states).

  1. Step 1 (T1 - Address Emission & Latching): The MPU outputs status signals (IO/M = 0 for memory). High-order address bits are driven onto A8–A15. Low-order address bits are driven onto AD0–AD7. Simultaneously, ALE pulses high to strobe the external 74LS373 latch.
  2. Step 2 (T2 - Bus Floating & Read Strobe): ALE drops low, locking A0–A7 in the latch. The MPU pulls AD0–AD7 into high-impedance (floats the bus) to avoid bus contention. Then, RD transitions low, enabling the selected memory chip's output buffers.
  3. Step 3 (T3 - Data Transfer): The external memory places the addressed opcode or data byte onto AD0–AD7. The MPU reads and latches this byte into its internal registers. RD returns high.
  4. Step 4 (T4 - Internal Opcode Decode): Used exclusively during an Opcode Fetch cycle (4T). While external buses are idle, internal instruction decoder translates the opcode and prepares ALU execution controls.

2. 8085 Memory Write Machine Cycle Timing Graph

CLK : __/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_ | T1 | T2 | T3 | ALE : ___/‾‾‾‾\___________________ A8-A15 : ===< Higher Order Address >=== AD0-AD7 : ===< Address A0-A7 >==< Data from CPU >=== WR (bar) : ‾‾‾‾‾‾‾‾‾‾‾‾\_________/‾‾‾‾ IO/M (bar): ____________________________ (Logic 0 for Memory) S1, S0 : ===< S1=0, S0=1 (Write Status) >===

Understanding Paragraph: During a memory write cycle (3T: T1–T3), the CPU provides both the address and the data to be written into external memory.

  1. Step 1 (T1 - Address Setup): IO/M is held low, status lines assert S1 = 0, S0 = 1 (Write). Target address is placed on A8–A15 and AD0–AD7, latched by the falling edge of ALE.
  2. Step 2 (T2 - Data Placement & Write Assertion): Rather than floating the bus, the CPU directly drives the data byte from its internal register (e.g. Accumulator) onto AD0–AD7. Once data is stable, WR transitions low.
  3. Step 3 (T3 - Memory Latch): WR remains low to provide adequate write setup time. On the rising edge of WR at the end of T3, external memory latches the data.

3. ADC0804 Analog-to-Digital Conversion & Handshake Cycle

WR (bar) : ‾‾‾\_______/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾ (Start Pulse >= 100ns) INTR (bar) : ‾‾‾‾‾‾‾‾‾‾‾\___________________/‾‾‾‾‾‾‾‾‾‾‾ (Conversion 64-73 Clocks) RD (bar) : ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_______/‾‾‾ (Read Enable) DATA BUS : ================================< Valid Digital Byte >===

Understanding Paragraph: The ADC0804 is an 8-bit successive approximation analog-to-digital converter. It interfaces with the 8051 or 8085 through an active handshaking protocol:

  1. Step 1 (Trigger Conversion): The CPU asserts WR low for at least 100 ns. This resets the internal Successive Approximation Register (SAR).
  2. Step 2 (Conversion In Progress): On the rising edge of WR, conversion begins. The ADC pulls INTR high, signaling that conversion is actively running.
  3. Step 3 (End of Conversion Alert): The internal SAR compares the analog input against reference voltages across 64 to 73 internal clock cycles (~100 μs). When conversion finishes, the ADC drives INTR low.
  4. Step 4 (Digital Read): Detecting INTR = 0, the microcontroller pulses RD low, enabling the internal tri-state output buffers to place the 8-bit result onto the data port.

4. DAC0808 / R-2R Ladder Conversion & Step-Voltage Generation Cycle

DIGITAL DATA : ==< 00H >==|==< 01H >==|==< 02H >== ... ==< FFH >==|==< 00H >== | | | ANALOG V_OUT : ___________/‾‾‾‾‾‾‾‾‾‾‾ ... ‾‾‾‾\ ___________/ \__________ (0.00 V) (+19.5 mV) (+4.98 V) (0.00 V) |<- t_settle ->|

Understanding Paragraph: The DAC0808 digital-to-analog converter operates on an internal R-2R binary ladder. It accepts an 8-bit digital byte and produces a proportional analog output current \(I_{\text{out}} = I_{\text{ref}} \times \left(\frac{D_7}{2} + \frac{D_6}{4} + \dots + \frac{D_0}{256}\right)\), which an external op-amp (LM741) converts to voltage.

  1. Step 1 (Port Output): The microprocessor writes an 8-bit digital word to the output port connected to DAC pins A1–A8 (MSB to LSB).
  2. Step 2 (Ladder Current Division): The R-2R ladder routes weighted binary fractions of \(I_{\text{ref}}\) through NMOS switches into the output bus pin \(I_{\text{out}}\).
  3. Step 3 (Settling Time Period): The internal current output stabilizes within the converter's settling time (\(t_{\text{settling}} \approx 150\,\text{ns}\)).
  4. Step 4 (I-to-V Op-Amp Conversion): Current flows across external feedback resistor \(R_{\text{f}}\) into the inverting input of the operational amplifier, generating stable analog step voltage \(V_{\text{out}} = -(I_{\text{out}} \times R_{\text{f}})\).

5. 16×2 LCD 4-Bit Mode Nibble Transfer & Enable (E) Clock Cycle

RS / RW : ============================================================= (Stable) |<- t_AS ->| DATA (D4-D7) : ==============< Upper Nibble (D7-D4) >====X====< Lower Nibble (D3-D0) >=== |<- t_DSW ->| |<- t_DSW ->| E (Pulse) : ______________/‾‾‾‾‾‾‾‾‾‾‾\_______________/‾‾‾‾‾‾‾‾‾‾‾\________ | t_PWE | | t_PWE |

Understanding Paragraph: In 4-bit interfacing mode, an 8-bit character or command byte is split into two successive 4-bit nibbles sent across data pins D4–D7. Each nibble requires an active-high Enable (E) strobe for the HD44780 controller to latch the data.

  1. Step 1 (Register Select & Direction): The CPU asserts RS (0 for command register, 1 for data register) and sets R/W = 0 for write. Address setup time (\(t_{\text{AS}} \ge 40\,\text{ns}\)) is provided before pulsing E.
  2. Step 2 (Send Upper Nibble): The upper 4 bits (D7–D4) are driven onto the port lines. After data setup time (\(t_{\text{DSW}} \ge 80\,\text{ns}\)), Enable pin E is pulled high for pulse width \(t_{\text{PWE}} \ge 230\,\text{ns}\).
  3. Step 3 (Latch on Falling Edge of E): On the high-to-low transition of E, the LCD controller internally latches the upper nibble into its temporary buffer.
  4. Step 4 (Send Lower Nibble): The lower 4 bits (D3–D0) are placed on D4–D7. E is pulsed high and dropped low again, allowing the LCD controller to assemble the full 8-bit byte and execute the operation.

Problem 3: Connect a temperature sensor (LM35) to ADC and 8051. Convert ADC reading to temperature in °C and display on LCD. Add threshold alarm feature.

Inline Complete Solution 💡

Inline Complete Solution 💡
Click to view concise exam answers for Questions 12 to 33 and 3 to 8
  • Q12 (3rd vs 2nd Gen): Integrated Circuits (ICs) combined multiple discrete transistors onto a single silicon substrate, drastically cutting propagation delay, size, power consumption, and production cost.
  • Q15 (First Microprocessor): Intel 4004, introduced in November 1971 (4-bit CPU, 2,300 transistors, 740 kHz).
  • Q17 (Intel 8086 Significance): First 16-bit microprocessor (1978), 29,000 transistors, 1MB address bus, introduced pipelining with EU/BIU and established the enduring x86 instruction set architecture.
  • Q20 (VLSI vs ULSI): VLSI (Very Large Scale Integration: 104–105 transistors); ULSI (Ultra Large Scale Integration: > 106 transistors enabling multi-core superscalar microprocessors).
  • Q28 (ARM 7 Role): Established the dominant RISC architecture for energy-efficient mobile, embedded, and battery-operated handheld devices.
  • 5-Mark Q3 (Moore's Law): Gordon Moore (1965) observed that the number of transistors on a microchip doubles roughly every two years with falling cost per transistor. Trajectory: Intel 4004 (2,300) → 8086 (29,000) → Pentium (3.1M) → Core i7 (731M) → Modern CPUs (tens of billions). Approaching physical quantum tunneling limits.
  • 5-Mark Q4 (Intel 4004 vs 8086):
    • 4004: 4-bit ALU, 2,300 transistors, 740 kHz, 640 bytes addressing, calculator focus.
    • 8086: 16-bit ALU, 29,000 transistors, up to 10 MHz, 1MB addressing, pipelined EU/BIU, PC industry standard.

4. MICROPROCESSORS, MICROCOMPUTERS & MEMORY SYSTEM QUESTIONS (1 TO 30)

Hardware Architecture & Memory System Problem Solutions

Inline Complete Solution 💡
Click to view exact mathematical & conceptual answers for Q1 to Q30
  1. Q1 & Q2 (Computer Components): CPU (control & arithmetic execution), Memory (stores program instructions and binary data), I/O (interfaces system with outside world via ports), System Bus (connects address, data, and control lines).
  2. Q3 (Microprocessor vs CPU): A CPU is the conceptual control and execution unit of a computer; a microprocessor is a complete CPU fabricated onto a single integrated circuit chip.
  3. Q4 (Microprocessor vs Microcomputer): A microprocessor contains only the CPU (ALU, registers, control); a microcomputer integrates a microprocessor with RAM, ROM, clock, and I/O ports on a board.
  4. Q5 (SSI, MSI, LSI): SSI (<10 gates), MSI (10–100 gates), LSI (100–10,000 gates), VLSI (>10,000 gates).
  5. Q6 & Q7 (Word Definition): A bit is 0 or 1; a byte is 8 bits; a word is the native data size manipulated by the CPU in a single cycle. For a 32-bit word, Bytes = 32 / 8 = 4 bytes.
  6. Q10 (Compiler vs Interpreter): A compiler translates the entire high-level program into machine code before execution; an interpreter translates and executes line-by-line.
  7. Q15 (4 Operations performed by MPU): 1. Memory Read, 2. Memory Write, 3. I/O Read, 4. I/O Write.
  8. Q18 (Why Data Bus is Bidirectional): The CPU must both read binary information from memory/ports into its registers and write processed results from its registers out to memory/ports.
  9. Q23 (Why PC and SP are 16-Bit): Because the 8085 physical memory address space is 64KB (216 = 65,536 locations), every pointer addressing memory must be 16 bits wide.
  10. Q27 (Address Lines for 2K Byte Memory): 2048 = 211 &implies; 11 address lines (A0–A10).
  11. Q28 (4K Memory Map Starting at 2000H):
    • Capacity = 4096 = 1000H. Last address = 2000H + 1000H - 1 = 2FFFH.
    • Pages in chip: 4096 / 256 = 16 pages.
  12. Q29 (1K Chip with Last Address FBFFH):
    • Capacity = 1024 = 0400H. Starting address = FBFFH - 0400H + 1 = F800H.
  13. Q30 (8K Chip with Last Address FFFFH):
    • Capacity = 8192 = 2000H. Starting address = FFFFH - 2000H + 1 = E000H.

Master Formulas:
• Last Address = Start + Capacity - 1
• Start Address = End - Capacity + 1
• Common Hex Sizes: 1K = 0400H | 2K = 0800H | 4K = 1000H | 8K = 2000H | 16K = 4000H | 64K = 10000H.

7. MEMORY SYSTEMS, SRAM VS DRAM & ARCHITECTURAL TRADEOFFS

Review Questions on Memory Architecture (Q19 to Q28)

Inline Complete Solution 💡
Click to view memory architecture analysis
  • Q19 & Q23 (Von Neumann vs Harvard):
    • Von Neumann: Shares a single physical bus and memory space for both code and data. Creates the "Von Neumann Bottleneck" because CPU cannot read an instruction and read/write data simultaneously.
    • Harvard: Physically separate memory and buses for code and data (e.g. 8051). Allows simultaneous instruction fetch and operand read/write, yielding significantly higher instruction throughput.
  • Q21 (Role of Cache Memory): High-speed SRAM situated directly between the CPU core and slower main DRAM. Exploits temporal locality (recently accessed data reused soon) and spatial locality (adjacent data accessed soon) to bridge the speed disparity between GHz processors and slower memory buses.
  • Q22 & Q27 (SRAM vs DRAM):
    FeatureStatic RAM (SRAM)Dynamic RAM (DRAM)
    Cell Structure6-transistor (6T) flip-flop circuit.1 transistor + 1 storage capacitor (1T-1C).
    Refresh RequirementNo refreshing needed as long as power is applied.Capacitor charge leaks; requires periodic refresh cycles (~64 ms).
    SpeedExtremely fast (1 to 5 ns access time).Slower (15 to 50 ns access time).
    Density & CostLow density, high cost per bit (used for CPU Cache).High density, inexpensive per gigabyte (used for Main Memory).
  • Q25 (PROM vs EPROM): PROM (Programmable ROM) is OTP (One-Time Programmable) via fusible links burned permanently; EPROM (Erasable PROM) is reusable, erased by exposure to ultraviolet (UV) light through a quartz window.
  • Q26 (Volatile Memory): Memory that loses stored data when electrical power is removed. RAM (both SRAM and DRAM) is volatile. ROM, PROM, EPROM, and Flash are non-volatile.
  • Q28 (8085 EPROM Address Range): In typical 8085 systems, EPROM (containing reset initialization code) resides at the start of the memory map: 0000H to 1FFFH (for an 8KB EPROM chip like 2764), because the 8085 program counter always wakes up at address 0000H upon hardware reset!
